和失智長輩玩一場好遊戲，看起來不像比賽。看起來是兩個人靠在一起坐著，指著圖片、為一句俗語笑一笑，聊聊想到的任何事。遊戲只是一起度過時光的理由。

這份指南說明怎麼準備、怎麼掌握遊戲的步調、事情「出錯」時該說什麼、怎麼讓任何遊戲變簡單或稍微難一點、怎麼把它變成聊天，以及怎麼知道什麼時候該停。它適用於我們的[遊戲](/games/)，也適用於您家裡已經有的紙牌、拼圖和桌遊。

## 和失智長輩玩遊戲，最好的方式是什麼？

把重點放在樂趣，而不是成就。這是[美國阿茲海默症協會關於活動的指引](https://www.alz.org/help-support/caregiving/daily-care/activities)的核心建議：運用長輩仍然擁有的技能、幫他起頭、困難的部分由您完成，也不要批評或糾正無傷大雅的活動。

實際上，這代表：

- **坐在他旁邊，不要坐在對面。**並肩坐著，你們都看得到螢幕或桌面，幫忙也感覺像是團隊合作，而不是監督。
- **一次只提供一個遊戲。**一整排選項，可能在開始之前就讓人覺得像考試。
- **跟著他的方向走。**如果他想照自己的順序點圖片、對著一張圖片聊十分鐘，或玩了兩輪就停，那就是今天的遊戲。
- **算的是美好的片刻，不是完成了幾局。**一個微笑、一個故事或平靜的半小時，就是您要的結果。

## 開始之前該怎麼準備？

花幾分鐘準備，就能避免大部分被怪到遊戲本身的挫折。

1. **挑他一天中狀況最好的時段。**[美國國家老化研究院（NIA）關於調整活動的指引](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)建議，把外出和活動安排在長輩狀況最好的時段。對很多人來說是上午。傍晚常常比較困難；請看[傍晚的平靜活動](/caregiving/late-day-restlessness/)。
2. **讓房間安靜下來。**關掉電視和收音機，可以的話把門關上。[美國家庭照顧者聯盟](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建議在開口交談之前，先減少噪音和干擾。
3. **先確認他舒不舒服。**旁邊放杯水、先去一趟洗手間、一張舒服的椅子，並戴上眼鏡和助聽器。
4. **讓空間光線充足。**明亮、均勻、螢幕不反光的光線，讓圖片更容易看清楚。
5. **坐下之前先把遊戲準備好。**由您自己打開遊戲、選好設定、調好音量，再把螢幕轉向他。平板的設定訣竅，請看[設定平板或手機](/caregiving/tablets-and-screens/)。
6. **把裝置立起來。**用支架或保護套讓平板直立，這樣誰都不用一直拿著，也比較容易用手指。

## 怎麼邀請他而不給壓力？

讓邀請輕鬆隨意，也容易拒絕。一些常常效果不錯的說法：

- 「我找到一些花園的圖片。要不要和我一起看？」
- 「可以幫我拼這個拼圖嗎？我卡住了。」
- 「今天想看花還是看鳥？」（二選一比開放式問題容易回答）
- 「我在做一張卡片給您妹妹。這裡要用什麼顏色？」

美國阿茲海默症協會建議說明活動的目的，例如為朋友做一張卡片，因為有理由，活動就有了意義。請他幫忙也很有效，因為這能讓長輩覺得自己有用。

如果他說不要，就接受。晚一點再試，或提供別的選擇。我們關於[長輩說不要時該怎麼辦](/caregiving/when-they-say-no/)的指南有更多說明。

## 一個遊戲要玩多久？速度要多快？

讓長輩決定步調，並安排短一點的時間。一起玩的遊戲，並沒有以證據為基礎的理想長度。平靜的兩到五分鐘，就可以是一項完整的活動。

- **等待的時間比您覺得自然的再長一點。**美國國家老化研究院建議給長輩更多時間回應，盡量不要打斷他。在幫忙之前，先在心裡數到十。
- **一次一個步驟。**給一個簡短的指示（「點一張圖片」），然後等待。用示範代替解釋：指給他看要點哪裡。
- **想停就停。**如果他停下來聊某張圖片，遊戲可以等。不需要趕。
- **讓他在旁邊看。**美國國家老化研究院提到，有些人比較喜歡在旁邊看，這也是一個合理的選擇。

## 應該糾正錯誤的答案嗎？

不應該。一再溫和地糾正一個人，即使出於好意，也是在告訴他：他做不好。美國阿茲海默症協會建議，不要批評或糾正無傷大雅的活動。在遊戲中，幾乎每個錯誤都是無傷大雅的。

| 與其說 | 試試說 |
| --- | --- |
| 「不對，錯了。」 | 「我們試試這樣。」（美國國家老化研究院舉的例子） |
| 「這兩張不一樣。再看一次。」 | 什麼都不說，換您玩下一輪；或說「喔，這兩張都是紅色的。」 |
| 「您還記得這是誰嗎？」 | 「跟我說說這張圖片。」 |
| 「那一個您已經做過了。」 | 「這個很好。我們再做一次。」 |
| 「拜託，您明明知道的。」 | 「要不要我顯示結尾？」 |

如果某個錯誤明顯讓他感到挫折，就安靜地幫忙。指出正確的圖片、換您玩一輪，或下一局讓遊戲變簡單。如果一句俗語被接了一個好笑的錯誤結尾，就跟著一起笑。他的結尾說不定更好。

## 怎麼讓遊戲變簡單或變難？

依照長輩當天的狀況調整遊戲，而不是依照階段的標籤。同一個人在晚上可能需要比早上更簡單的版本。美國國家老化研究院的第一個建議，就是讓活動配合長輩能做的事，並確保他感到成功。

| 遊戲 | 讓它簡單一點 | 讓它稍微難一點 |
| --- | --- | --- |
| [圖片配對](/games/picture-pairs/) | 從 4 張圖卡開始，讓圖片一直顯示 | 多一點圖卡，或在感覺自在時隱藏圖片 |
| [找相同](/games/find-the-same/) | 2 個選項 | 最多 4 個選項 |
| [一起分類](/games/sort-together/) | 由您拿著圖片，他指出籃子 | 由他自己點圖片和籃子 |
| [圖片拼圖](/games/picture-puzzle/) | 4 片，先聊聊整張圖片 | 9 片 |
| [接俗語](/games/finish-the-saying/) | 先顯示結尾，再一起說出來 | 讓他先說出結尾再點選 |
| [大字找字](/games/word-search/) | 印出來，一起找一個詞，指出它的第一個字 | 讓他選下一個要找的詞 |
| [著色畫](/games/coloring/) | 由您挑兩種顏色，讓他二選一 | 所有顏色都由他選 |
| [聊天卡](/games/conversation-cards/) | 只是一起看看圖片 | 使用卡片上的開放式話題 |
| [照片配對](/games/photo-pairs/) | 幾張家人喜愛的家庭照片 | 加入更多照片 |
| [圖片賓果](/games/picture-bingo/) | 每位玩家旁邊坐一位幫手 | 玩家自己在卡上做記號 |
| [平靜呼吸](/games/calm-breathing/) | 只是一起坐著看 | 跟著慢慢呼吸 |

遊戲太難的跡象：停頓很久，看起來是擔心而不是在思考、一再說「我不會」、把裝置推開，或錯誤讓他難過。可能太簡單的跡象：覺得無聊，或他說這很幼稚。如果發生這種情況，請尊重他，換成感覺適合大人的活動，例如大字找字、用真實照片做的拼圖，或聊聊一張和他以前工作有關的圖片。

## 怎麼把遊戲變成聊天？

把每一張圖片都當成聊天的邀請，不論他說什麼，都當成好答案。對很多家庭來說，這是玩遊戲最美好的部分。

- **問開放式、沒有錯誤答案的問題。**「您注意到什麼？」「您喜歡哪一張？」「跟我說說像這樣的廚房。」
- **自己先分享。**「我阿嬤以前也養過一隻像這樣的狗。」您的故事讓他更容易分享自己的故事。
- **順著話題岔出去。**如果一張汽車的圖片帶出一段開車旅行的故事，那個故事就是活動。讓遊戲暫停就好。
- **不要查證事實。**在懷舊時，愉快的對話比細節正確更重要。如果故事和上次說的不一樣，就享受這個新版本。
- **使用內建的話題提示。**[接俗語](/games/finish-the-saying/)在每句俗語之後都有一個聊天提示，[聊天卡](/games/conversation-cards/)正是為此設計的。[照片配對](/games/photo-pairs/)使用您自己的家庭照片，常常能引出最豐富的故事。

更多點子，請看我們的[懷舊活動](/activities/reminiscence/)和[溝通技巧](/caregiving/communication-tips/)指南。

## 什麼時候該停？

一出現疲累或不開心的跡象就停下，最好再早一點。美國阿茲海默症協會建議，在注意力減退或挫折感升高時，停下或換一項活動。

留意這些跡象：

- 打哈欠、身體往下滑，或眼睛不再看螢幕；
- 坐立不安、站起來，或說想離開；
- 嘆氣、回答變得很短，或說「我不行啦」；
- 隨便亂點，或把裝置推開；
- 想哭、煩躁，或心情突然改變。

怎麼好好地結束：

- **用簡單的事結尾。**最後一個他能配對成功的，或最後一張可以一起欣賞的圖片。
- **把理由放在自己身上。**「我想喝杯茶。我們先到這裡好嗎？」這樣就不會暗示他做得不好。
- **轉換成動動身體或讓人放鬆的事。**短短散個步、吃點小點心、摺衣服或聽音樂。
- **說句溫暖的話。**「我很喜歡和您一起做這件事。」不要稱讚他「答對了」，只要表達對這段相處時光的喜悅。

早點結束、改變計畫，或放下遊戲、只是一起坐著，都是好結果。

## 可以在團體中或透過視訊一起玩嗎？

可以，只要多做一點準備。團體活動時，人數少一點，讓需要協助的人旁邊坐著一位幫手，並選擇有明確共同焦點的遊戲。[圖片賓果](/games/picture-bingo/)有可列印的卡片和適合團體的螢幕叫號器。更多內容請看[照護機構的團體活動](/activities/care-home-groups/)。

透過視訊時，視訊另一頭的人可以描述一張圖片，由房間裡的人幫忙指和點。通話要短，內容要熟悉。我們的[電話與視訊](/activities/phone-and-video-calls/)指南有更多訣竅。

## 如果遊戲就是不順利怎麼辦？

有些日子做什麼都不對勁，這不代表您或他做得不好。把遊戲收起來，換一天中的另一個時段、換一個遊戲，或完全不玩遊戲。很多好活動和螢幕一點關係都沒有：聽音樂、摺毛巾、翻翻相簿，或短短散個步。更多點子，請瀏覽我們的[活動點子](/activities/ideas/)。
