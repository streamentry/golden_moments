「我要回家。」對很多家庭來說，這是最難聽到的一句話，尤其當您照顧的長輩就坐在自己的客廳裡。這很常見，可能出現在失智症的任何階段，而且有平靜、實用的方法可以回應。這份指南說明這句話常常代表什麼、該怎麼說、當下有哪些活動可能有幫助，以及如何確保安全。

## 失智長輩為什麼一直說要回家？

通常，「家」比較像一種感覺，而不是一個地方。英國阿茲海默症協會（Alzheimer's Society）把它形容為一種舒適和安全的感覺，或是過去的家，而不是眼前這棟房子。失智症可能讓熟悉的房間看起來很陌生，長輩也可能覺得自己活在人生較早的時期，那時的家是童年的老家，或是養大孩子的地方。

這句話也可能是在表示現在有別的地方不對勁：他餓了、渴了、想上廁所、會痛、太熱或太冷、累了、孤單、害怕，或被噪音弄得不知所措。[美國國家老化研究院](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/coping-agitation-aggression-and-sundowning)把疼痛、噪音、孤單、作息改變和藥物，列為造成躁動不安的原因。

## 他說要回家時，我該說什麼？

回應感受，而不是字面上的話。[美國家庭照顧者聯盟](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建議，不要試圖說服長輩他是錯的：他的感受是真實的，所以先用安慰和讓他安心來回應，然後再溫和地轉移注意力。

常常有幫助的說法：

- **說出他的感受。**「聽起來您很想家。」
- **讓他安心。**「您在這裡很安全，我會陪著您。」[美國阿茲海默症協會](https://www.alz.org/help-support/caregiving/stages-behaviors/anxiety-agitation)建議用簡單的一句「您在這裡很安全」。
- **邀請他說說回憶。**「跟我說說您的家吧。您家的廚房是什麼樣子？」問很久以前的事，通常比問今天的事讓他自在。
- **提議一起做點什麼。**「我們先喝杯茶吧」，或「可以幫我摺這些毛巾嗎？」

溫暖的語氣，加上輕輕搭在手臂上的手（如果他喜歡被碰觸），有時比話語更能傳達心意。

## 有哪些事要避免？

- **爭辯或解釋。**「您現在住這裡」或「這裡已經是您的家 40 年了」，是要他接受失智症讓人難以接受的事，也可能讓他覺得自己被說錯了。
- **考他。**「您不記得了嗎？」或「地址是什麼？」只會增加壓力。
- **生氣地擋住門。**如果他往外走，請保持冷靜，陪他一起走。一起短短散個步，常常就能讓這股衝動平復。
- **催促。**先給他時間聊聊家，再轉換話題。

## 當下有哪些活動可能有幫助？

接住他的感受之後，一個平靜、熟悉的活動，可以在不否定他的情況下轉移注意力。

1. **看家和家人的照片。**一頁一頁翻，說說您的感想（「看看那座花園」），而不是問問題。在手機或平板上，[照片配對](/games/photo-pairs/)可以把您自己的家庭照片變成溫和的配對遊戲，而且照片只留在您的裝置上。
2. **聊聊家。**[聊天卡](/games/conversation-cards/)提供關於房子、廚房、鄰居和節日的開放式話題，沒有標準答案。
3. **播放他喜愛的音樂。**美國國家老化研究院把輕柔的音樂列為安撫躁動的方法之一。請看我們的[音樂活動](/activities/music/)。
4. **吃點心或喝點東西。**飢餓和口渴可能看起來像坐立不安。一杯茶或愛吃的點心，也是在家裡的小小儀式。
5. **出去走走，或坐在戶外。**活動身體和曬太陽都有幫助，尤其是在一天的早些時候。
6. **請他做一件熟悉的事。**摺衣服、整理餐具或澆花，可以喚回持家的感覺。
7. **把一切放慢。**關掉電視，減少噪音和刺眼的光線，試試一起做一段[平靜呼吸](/games/calm-breathing/)。

如果某個點子沒有效果，晚一點再試另一個。靜靜坐在一起，也是好結果。

## 檢查可以解決的原因

| 檢查 | 可以試試 |
| --- | --- |
| 餓或渴 | 提供飲料和一點小點心 |
| 需要上廁所 | 平靜、不大驚小怪地帶他去廁所 |
| 疼痛或不舒服 | 留意有沒有皺眉、按著身體某個部位或便祕等跡象，並告訴他的醫師 |
| 太熱或太冷 | 增減衣物或調整室溫 |
| 吵鬧或太擁擠 | 換到比較安靜的房間，關掉電視 |
| 累了或受到太多刺激 | 休息、調暗燈光、播放輕柔的音樂 |
| 傍晚 | 請看下面「日落症候群」的段落 |

英國阿茲海默症協會建議簡短記錄他什麼時候會這樣說，例如用餐前、訪客離開後或黃昏時。找出規律，就更容易事先安排。

## 可以說善意的謊言嗎？

這是一個真實的爭論，用心的家庭也會走向不同的選擇。英國阿茲海默症協會說，沒有單一的正確答案：說不實的話可能讓有些人更起疑，所以請判斷什麼對長輩最好，並保持前後一致。賓州大學記憶中心（Penn Memory Center）的共同主任認為，應該以實話為預設，只有在對方無法消化某個實情時，溫和的不實說法才可以接受，而且絕不要嘲笑他眼中的現實。

很多照顧者發現，折衷的辦法比較行得通：先用誠實的安慰和轉移注意力（「我們今晚就待在這裡，我就在您身邊」），不去爭論家在哪裡。

## 如果每天下午或傍晚都這樣呢？

傍晚開始或加重的不安，常被稱為日落症候群。[美國國家老化研究院](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/coping-agitation-aggression-and-sundowning)建議保持固定的作息、每天曬太陽和活動、減少太晚的午睡，並避免在一天的後段喝含咖啡因的飲料或酒。天黑之前先把燈打開，也可能有幫助。我們的[傍晚平靜活動](/caregiving/late-day-restlessness/)指南有更多說明。

## 他想出門時，如何確保安全

說要回家，可能演變成四處遊走。[美國阿茲海默症協會](https://www.alz.org/help-support/caregiving/stages-behaviors/wandering)估計，每十位失智者中，約有六位至少會走失一次。

**事先準備：**

- 戴上寫有他的姓名和您電話號碼的身分手環或醫療手環，衣服上也縫上標籤。[美國國家老化研究院](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/coping-alzheimers-behaviors-wandering-and)提到美國的 MedicAlert 和阿茲海默症協會 Safe and Found 計畫，可能需要付費。在台灣，可向台灣失智症協會或當地的長照單位詢問有沒有類似的防走失手鍊或登記服務。
- 裝門鈴提示器或警報器，鎖放在高處或低處。絕對不要把他單獨反鎖在屋裡。
- 準備一張近期的清楚大頭照，並列出他可能去的地方，例如以前的住家或工作的地方。
- 告訴信任的鄰居，並給他們您的電話。

**如果他走失了：**立刻開始找；美國阿茲海默症協會指出，很多人是在 1.5 英里（約 2.4 公里）範圍內被找到。在美國，如果 15 分鐘內還沒找到，請打 911 並說明這個人有失智症。在台灣，請立刻向警察報案（110），並說明走失的人有失智症。如果有人處於危險之中，請立刻撥打 119（美國為 911）。

## 什麼時候該請醫師看看？

如果一直要回家或意識混亂是突然開始的，或在幾小時、幾天內明顯加重，請盡快聯絡他的醫師。[美國國家老化研究院](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/alzheimers-caregiving-managing-personality-and)說，行為突然或快速變化，特別是在感染或換藥之後，應該立刻檢查。突然的意識混亂可能是譫妄，[NHS](https://www.nhs.uk/symptoms/confusion/) 指出這需要緊急協助；泌尿道感染是老年人常見的原因。

在下次看診時，也請提一提長期的規律，因為疼痛、情緒低落、睡眠問題或藥物副作用，都可能是原因之一。
