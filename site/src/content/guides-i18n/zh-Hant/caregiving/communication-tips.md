失智症可能讓人更難找到合適的詞語、跟上較長的句子，或在吵雜的環境中專心。但這並不代表對方不再想與人連結。只要在準備談話、說話方式和傾聽方式上做一些小調整，就可能讓彼此的溝通更輕鬆、更平靜。

## 與失智症人士交談時，最重要的技巧是什麼？

先取得對方的注意，把話說得簡單，並保持耐心。如果您只記得五件事：

1. **讓環境安靜並面對對方。** 關掉電視，坐在與對方視線平齊的位置，並稱呼對方的名字。
2. **一次只說一件事。** 用簡短的句子，一次表達一個意思，一次只問一個問題。
3. **提供兩個選項。** 「要喝茶還是咖啡？」比「你想喝什麼？」更容易回答。
4. **多等待一下。** 給對方比平常更長的時間來回應，並盡量不要打斷。
5. **不要爭辯或考問。** 回應對方的感受，而不是糾結事實是否正確。

## 我該如何開始一段對話？

先把環境安排好，讓對方能專心看著您、聽您說話。[Family Caregiver Alliance guide](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/) 建議先減少噪音：關掉收音機或電視、拉上窗簾或關上門，或移動到較安靜的地方。

- **從正面靠近。** 從背後或側面靠近，可能會讓對方受到驚嚇。
- **說明您是誰。** 「爸，你好，我是 Sarah，你的女兒。」這樣可以省去對方努力回想您名字的壓力。
- **讓視線與對方平齊。** 如果對方坐著，您可以坐下或蹲下，讓彼此的眼睛在同一高度。
- **留意您的表情和語氣。** [National Institute on Aging (NIA)](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/communicating-someone-who-has-alzheimers) 建議留意自己的語氣、音量、臉部表情和肢體語言，並以溫和、自然的方式與對方互動。
- **確認眼鏡和助聽器有戴好。** 如果看不清楚或聽不清楚，對話就會更難跟上。

## 我應該怎麼表達？

使用簡單的詞語、簡短的句子，以及平靜、較低沉的聲音。

- **每句話只表達一個意思。** 「我們先穿上外套，然後再出去。」不要把兩件事擠在同一句話裡。
- **多用名字，少用代名詞。** 「Jean 阿姨打來了」比「她打來了」更清楚。
- **聲音放低，不要放大。** Family Caregiver Alliance 建議用較低沉的聲音，而不是提高音量。
- **先重複，再換說法。** 如果對方沒有聽懂，先用同樣的話再說一次。如果還是不行，等一下再用不同的說法。
- **邊說邊示範。** 指著杯子、拿出兩件毛衣讓對方選，或示範第一個步驟。
- **和對方說話，不要把對方當成不在場。** NIA 提醒，不要在對方面前把對方當作不在場一樣談論，也不要用對待小孩的語氣說話。

NIA 建議用更簡單的方式提出常見問題。以下是類似的例子：

| 與其這樣說 | 不如試試這樣說 |
| --- | --- |
| 「你晚餐想吃什麼？」 | 「你想吃魚還是雞肉？」 |
| 「你感覺怎麼樣？」 | 「你覺得累嗎？」 |
| 「你餓嗎？」 | 「晚餐再過五分鐘就好了。」 |
| 「你不是這樣做的。」 | 「我們試試這樣做。」 |
| 「你記得我們去湖邊那次旅行嗎？」 | 「我剛剛想到我們去湖邊的那次旅行。跟我說說你喜歡那次旅行的什麼吧。」 |
| 「我已經跟你說過了。」 | 像第一次一樣，親切地再回答一次。 |

## 我該如何好好傾聽？

傾聽話語背後的意思和感受，而不只是字面上的內容。

- **多等待一下。** 沉默往往是對方思考的時間。在開口前，可以在心裡慢慢數到十。
- **只有在對方卡住時才提供詞語。** Family Caregiver Alliance 表示，當對方明顯感到吃力時，適時提供詞語是可以的。
- **確認您聽到的意思。** [Alzheimer's Association guide to communication](https://www.alz.org/help-support/caregiving/daily-care/communications) 建議留意話語背後的意思，並用自己的話重述一次，確認是否理解正確。例如：「你是在擔心那輛車嗎？」
- **觀察對方的表情和肢體動作。** NIA 指出，當說話變得更困難時，臉部表情可能比言語更清楚地表達難過、生氣或沮喪。
- **認真看待對方的擔心。** 即使擔心是建立在錯誤的事實上，那份感受仍然是真實的。

## 如果對方說的事情不正確，該怎麼辦？

不要爭辯。您很難說服對方，反而可能讓對方感到難堪或害怕。試著先回應對方的感受，再溫和地轉移話題。

Family Caregiver Alliance 建議在轉移話題前，先承認對方的情緒。例如，如果您的媽媽堅持要去學校接小孩：

- 與其說：「媽，你的孩子都長大了，那是四十年前的事了。」
- 不如試試：「你一直都是很關心孩子的媽媽。跟我說說你以前去接他們的事吧。我們要不要先吃點東西？」

Alzheimer's Association 也建議，不要與對方爭論您不同意的說法。選擇重要的時刻：如果一個錯誤的想法不會造成傷害，可以不必糾正。

## 隨著失智症進展，溝通方式會如何改變？

需求會隨時間改變，因此您的方式也需要調整。Alzheimer's Association 描述了三個大致的階段：

| 階段 | 有幫助的做法 |
| --- | --- |
| 早期 | 不要假設對方無法溝通。讓對方參與對話，直接與對方說話，詢問對方希望得到什麼支持，如果合適也可以運用幽默。 |
| 中期 | 在安靜的地方進行一對一交談。放慢語速，保持眼神接觸，使用可以用「是」或「不是」回答的問題，給予一步一步的指示，並避免批評或糾正。 |
| 晚期 | 從正面靠近並說明您是誰。鼓勵對方用指物和手勢表達。運用觸碰、聲音、景象和氣味。不要把對方當作不在場一樣說話。 |

每個人都不同，同一個人也可能有狀態好和狀態不好的日子。請根據對方此刻的狀態來回應，而不是只看某個階段的標籤。

## 圖片和活動能讓對話更容易嗎？

可以。一張一起看的圖片可以減少壓力，也讓你們都有可以觀看和指著討論的內容。

- **圖片提示。** [Conversation Cards](/games/conversation-cards/) 提供附有開放式問題的圖片，不會考問對方。
- **家庭照片。** [Photo Pairs](/games/photo-pairs/) 可以把您挑選的照片變成溫和的配對遊戲，往往也能帶出回憶和故事。
- **熟悉的俗語。** [Finish the Saying](/games/finish-the-saying/) 使用熟悉的美國俗語，並附上引導交談的提示。
- **配對遊戲作為陪襯。** [Picture Pairs](/games/picture-pairs/) 讓雙手有事可做，同時也能輕鬆聊天。

更多內容請參考[如何一起玩遊戲](/caregiving/how-to-play-together/)和[懷舊活動](/activities/reminiscence/)。關於探訪和通話，請閱讀我們的[探訪指南](/activities/visiting/)和[電話與視訊通話指南](/activities/phone-and-video-calls/)。

如果您照顧的人會使用多種語言，請參考我們的[跨語言溝通指南](/caregiving/language-and-dementia-communication/)。

## 如果我失去耐心，該怎麼辦？

這是每個人都可能遇到的情況。NIA 建議，如果您感到挫折，可以先花點時間讓自己冷靜下來。到另一個房間，慢慢深呼吸幾次，等自己比較平靜後再回來。您隨時都可以重新開始對話，而對方也很可能會回應您較平靜的情緒。如果挫折感經常出現，這可能代表您需要更多支持，而不是您做得不夠好。我們的[照顧者自我照顧指南](/caregiving/caregiver-self-care/)提供了一些可以尋求協助的方向。
