失智症可能讓人更難找到詞、跟上一長串的句子，或在背景噪音中專心聽。這些都不代表長輩不想再和人連結。在怎麼安排一場對話、怎麼說話、怎麼傾聽上做一些小小的改變，可以讓談話對你們兩個人來說都更輕鬆、更平靜。

## 和失智長輩說話，最重要的技巧是什麼？

吸引他的注意力，講得簡單，並保持耐心。如果只記得五件事：

1. **讓房間安靜下來，面對他。**關掉電視，坐在和他視線同高的位置，叫他的名字。
2. **一次只說一件事。**短句，一個想法，一個問題。
3. **提供二選一。**「要喝茶還是咖啡？」比「您想喝什麼？」容易回答。
4. **等待。**給他比覺得自然的更長的時間回答，盡量不要打斷。
5. **絕不爭辯或考問。**回應他的感受，而不是事實對不對。

## 怎麼開啟一段對話？

做好安排，讓長輩能專心看著您。[美國家庭照顧者聯盟的指南](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建議先減少噪音：關掉收音機或電視，拉上窗簾或關上門，或換到比較安靜的地方。

- **從正面靠近。**從背後或側面走近，可能會嚇到他。
- **說出您是誰。**「爸，我是小美，您的女兒。」這樣他就不用費力去想您的名字。
- **放低到他的高度。**如果他坐著，您就坐下或蹲下，讓視線在同一個高度。
- **留意您的表情和語氣。**[美國國家老化研究院（NIA）](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/communicating-someone-who-has-alzheimers)建議留意自己的語氣、音量、臉部表情和肢體語言，以溫暖、平實的態度為目標。
- **確認眼鏡和助聽器都戴上了。**如果看不清楚或聽不清楚，就很難跟上對話。

## 我該怎麼措辭？

用簡單的字詞、短句，和平靜、低沉的聲音。

- **一句話一個想法。**「我們來穿外套。然後出去走走。」不要一口氣全說完。
- **用名字，不要用代名詞。**「阿姨打電話來了」比「她打來了」清楚。
- **降低音調，而不是提高音量。**美國家庭照顧者聯盟建議用較低的聲音，而不是提高嗓門。
- **先重複，再換說法。**如果他沒聽懂，先把同樣的話重複一次。如果還是不行，稍等一下，再用不同的詞。
- **邊說邊示範。**指著杯子，舉起兩件毛衣，或示範第一個步驟。
- **對他說話，不要談論他。**NIA 提醒，不要當他不在場一樣談論他，也不要用「哄小孩的口氣」。

NIA 建議把常見的問題換成比較簡單的版本。下面是依這個精神舉的例子：

| 不要這樣說 | 試試看 |
| --- | --- |
| 「晚餐想吃什麼？」 | 「晚餐要吃魚還是雞肉？」 |
| 「您覺得怎麼樣？」 | 「您會累嗎？」 |
| 「您餓了嗎？」 | 「五分鐘後就可以吃飯了。」 |
| 「不是這樣做的。」 | 「我們試試這樣做。」 |
| 「您還記得我們去海邊玩的那次嗎？」 | 「我剛剛想起我們去海邊玩的那次。跟我說說您喜歡那次的什麼。」 |
| 「我已經告訴過您了。」 | 親切地再回答一次，就像第一次回答一樣。 |

## 怎麼好好傾聽？

聽的是意思和感受，不只是字面。

- **等待。**沉默常常是思考的時間。介入之前，慢慢在心裡數到十。
- **只有在他卡住時才提供詞。**美國家庭照顧者聯盟說，當長輩吃力時，建議他一個詞是可以的。
- **確認您聽到的。**[美國阿茲海默症協會的溝通指南](https://www.alz.org/help-support/caregiving/daily-care/communications)建議，找出話語背後的意思，再複述一遍確認您聽懂了。「您是在擔心車子嗎？」
- **觀察他的臉和身體。**NIA 指出，當說話越來越困難時，臉部表情可能比言語更清楚地透露悲傷、憤怒或挫折。
- **認真看待他的擔心。**即使擔心是建立在錯誤的事實上，那份感受是真實的。

## 如果他說的不是事實呢？

不要爭辯。您不太可能贏，長輩反而可能覺得尷尬或害怕。相反地，先連結他的感受，再溫和地轉移。

美國家庭照顧者聯盟建議，在轉移話題之前，先接住那份情緒。例如，如果您的媽媽堅持她得去學校接孩子放學：

- 不要說：「媽，您的孩子都長大了。那是四十年前的事了。」
- 試著說：「您一直是個很疼孩子的媽媽。跟我說說接孩子的事吧。我們要不要先吃點點心？」

美國阿茲海默症協會也建議，對於自己不同意的說法，不要爭辯。挑選時機：如果錯誤的想法無傷大雅，就讓它去。

## 隨著失智症進展，溝通會怎麼改變？

需求會隨時間改變，所以要調整您的方式。美國阿茲海默症協會描述了三個大致的階段：

| 階段 | 什麼有幫助 |
| --- | --- |
| 早期 | 不要假設他無法溝通。讓他參與談話，直接對他說話，問他想要什麼支持，如果有幫助就用幽默。 |
| 中期 | 在安靜的地方一對一交談。說話放慢、保持眼神接觸、用是非題、一步一步給指示，不要批評或糾正。 |
| 後期 | 從正面靠近並說出您是誰。鼓勵他用手指和手勢。運用碰觸、聲音、景象和氣味。絕不要當他不在場一樣說話。 |

每個人都不一樣，同一個人也會有好日子和難熬的日子。回應他現在的狀態，而不是一個標籤。

## 圖片和活動能讓聊天更容易嗎？

可以。一起看的圖片能減輕壓力，也給你們兩個人可以看、可以指的東西。

- **圖片話題。**[聊天卡](/games/conversation-cards/)提供附有開放式問題的圖片，絕不考人。
- **家庭照片。**[照片配對](/games/photo-pairs/)把您選的照片變成溫和的配對遊戲，常常能引出故事。
- **熟悉的俗語。**[接俗語](/games/finish-the-saying/)用大家耳熟能詳的俗語，之後有一個聊天的話題。
- **以配對遊戲當背景。**[圖片配對](/games/picture-pairs/)讓您的手有事可做，同時聊天。

更多內容請看[如何一起玩遊戲](/caregiving/how-to-play-together/)和[懷舊活動](/activities/reminiscence/)。關於探訪和通話，請看我們的[探訪](/activities/visiting/)和[電話與視訊通話](/activities/phone-and-video-calls/)指南。

## 如果我失去耐心怎麼辦？

每個人都會這樣。NIA 建議，如果您覺得挫折，就花一些時間讓自己平靜下來。走到另一個房間，慢慢呼吸幾次，等您可以了再回來。您隨時可以重新開始這場對話，長輩也很可能會回應您比較平靜的心情。如果挫折感變成常態，那是您需要更多支持的訊號，不是您失敗了。我們的[照顧者自我照顧](/caregiving/caregiver-self-care/)指南列出了可以求助的地方。
