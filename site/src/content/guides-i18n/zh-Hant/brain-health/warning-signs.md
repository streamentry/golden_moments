發現自己或所愛的人記憶出現變化，可能令人害怕。這份指南可以幫您判斷何時該預約看診，以及如何準備。它無法告訴您任何人是否有失智症。**只有合格的臨床醫療人員才能診斷失智症**，而且許多造成記憶問題的狀況根本不是失智症。請不要依賴網路上的測驗或自我檢測。

## 失智症的早期徵兆有哪些？

[阿茲海默症協會](https://www.alz.org/alzheimers-dementia/10_signs)列出 10 項早期徵兆，並為每一項附上一個隨年齡增長的典型變化，方便對照。以下用我們自己的話整理：

| 值得檢查的徵兆 | 隨年齡較常見的變化 |
| --- | --- |
| 記憶力退化到影響日常生活，例如忘記最近發生的事，或一再問同樣的事 | 偶爾忘記人名或約定，之後又想起來 |
| 計畫或解決問題變得困難，例如照著熟悉的食譜做菜，或管理帳單 | 偶爾在家裡的帳單上出錯 |
| 難以完成在家、工作或外出時熟悉的事 | 偶爾需要別人幫忙調整微波爐設定，或設定電視錄影 |
| 搞不清楚日期、季節或自己身在何處 | 弄錯星期幾，之後自己想出來 |
| 新出現判斷距離、閱讀或分辨顏色的困難 | 白內障造成的視力變化 |
| 說話或用字出現新的問題，例如說到一半停住，或叫錯東西的名稱 | 偶爾一時想不起適當的詞 |
| 把東西放在不尋常的地方，而且無法循著步驟回想 | 偶爾放錯東西，循著步驟回想就找到了 |
| 判斷力變差，例如在金錢或個人儀容上 | 偶爾做出不太好的決定 |
| 不再參與嗜好、工作或社交活動 | 偶爾不想參加家庭或社交聚會 |
| 情緒或個性改變，例如變得困惑、多疑、害怕或焦慮 | 有自己固定的做事方式，例行作息被打亂時會煩躁 |

只出現一項徵兆，並不代表失智症。重點是**與這個人原本的樣子不同的改變**，尤其是讓日常生活變得更困難的改變。

## 正常老化和失智症有什麼不同？

[美國國家老化研究院（NIA）](https://www.nia.nih.gov/health/memory-loss-and-forgetfulness/memory-problems-forgetfulness-and-aging)說，許多年長者會發現自己回想事情比較慢，或偶爾放錯東西、忘記繳帳單。這些通常是輕微健忘的徵象。**失智症不是老化的正常現象。**嚴重的記憶問題會讓日常活動變得困難，例如開車、用電話或找到回家的路。

NIA 建議，如果有人出現下列情形，可以和醫師談一談：

- 一再問同樣的問題
- 在原本很熟悉的地方迷路
- 難以照著食譜或指示做事
- 對時間、人物和地點越來越混淆
- 不再照顧自己，例如吃得很差、不洗澡，或做出不安全的行為

有些人有**輕度認知障礙（MCI）**。意思是記憶或思考的問題比同年齡的人多，但仍然能處理日常生活。NIA 說，MCI 可能是阿茲海默症的早期徵象，但並不是每個有 MCI 的人都會發展成阿茲海默症。

## 還有什麼會造成記憶問題？

除了失智症，還有許多狀況會影響記憶，其中有些在治療後會好轉。NIA 列出：

- **甲狀腺、腎臟或肝臟問題**
- **藥物副作用**
- **憂鬱和焦慮**
- **維生素 B12 偏低**，或沒有吃足夠健康的食物
- **睡眠問題**
- **酒精或藥物濫用**
- 腦部的**感染、血塊或腫瘤**
- **頭部外傷**，例如腦震盪
- **重大壓力或悲傷**，例如退休或失去配偶

聽力和視力問題，也可能被誤認為意識混亂；請見我們的[聽力指南](/brain-health/hearing/)。這就是醫療檢查很重要的原因。根據[阿茲海默症協會](https://www.alz.org/alzheimers-dementia/diagnosis/visiting-your-doctor)，醫師常會安排抽血檢查，確認有沒有甲狀腺問題、維生素缺乏和感染。良好的[睡眠](/brain-health/sleep/)，以及治療憂鬱，也值得和醫師談談。

## 突然意識混亂是緊急狀況

**在幾小時或幾天內快速出現的意識混亂，需要緊急就醫。**這可能是譫妄。[VA 將譫妄描述](https://www.va.gov/geriatrics/pages/delirium_when_should_i_worry_about_delirium.asp)為醫療緊急狀況，並建議立刻聯絡這個人的醫療人員，或撥打 119（美國為 911）。徵兆包括：

- 思考清楚的能力時好時壞
- 難以集中注意力
- 思緒雜亂無章
- 異常嗜睡，或異常躁動不安

任何人都可能發生，包括原本就罹患失智症的人。根據 [NHS](https://www.nhs.uk/symptoms/confusion/)，常見的原因包括感染（泌尿道感染在年長者和失智症的人身上很常見）、中風、糖尿病患者的低血糖、頭部外傷，以及某些藥物。等待協助的時候，請留在這個人身邊，用簡短、簡單的話安撫他。不要問很多問題，並記下他正在吃的藥。

## 如何為看診做準備？

好的看診從好的記錄開始。[阿茲海默症協會](https://www.alz.org/alzheimers-dementia/diagnosis/visiting-your-doctor)建議帶上：

1. **一份變化清單**，列出記憶、情緒和行為上的變化，附上具體例子和大約從什麼時候開始
2. **過去和現在的健康問題**，包括記憶問題的家族史
3. **所有處方藥和成藥**
4. **所有維生素或保健品**
5. **您的問題**，例如會做哪些檢查、要花多久時間、什麼時候會有結果

也建議帶一位很了解這個人的家人或朋友同行。[NIA 說明](https://www.nia.nih.gov/health/alzheimers-symptoms-and-diagnosis/how-alzheimers-disease-diagnosed)，醫師可能會同時詢問當事人和家屬關於健康、用藥、日常活動和行為變化的問題。醫師也可能：

- 進行記憶、解決問題、注意力、計算和語言的測驗
- 安排血液、尿液和其他檢查，找出其他原因
- 檢查有沒有憂鬱或其他心理健康狀況
- 安排腦部掃描，例如電腦斷層（CT）或磁振造影（MRI）
- 轉介給專科醫師，例如老年醫學科醫師、神經科醫師、老年精神科醫師或神經心理師

NIA 指出，在美國，認知評估是 Medicare 年度健康檢查（Annual Wellness Visit）必備的一部分，這可以是提出擔憂的自然時機。在台灣，也可以趁定期健康檢查或回診時，向醫師提出您的擔憂。即使是醫師使用的簡短測驗，單靠它也不足以診斷失智症。它們是邁向更完整評估的第一步，診斷也可能需要不只一次看診。NIA 建議有記憶問題的人，每 6 到 12 個月回診一次。

## 親切地提起這件事

如果您擔心的是別人，請選一個平靜、私下的時刻。談談您注意到的具體事情，用關心他健康的方式說，而不是批評。建議一起做個一般健康檢查，可能比較不讓人驚慌。讓這個人一起參與決定，用對待成年人的方式和他說話。我們的[溝通技巧指南](/caregiving/communication-tips/)可能會有幫助。

## 請與醫師談談

如果您發現記憶、思考、情緒或日常能力出現新的、而且持續發生的變化，請向家庭醫師或基層醫療的醫師預約看診。如果是突然意識混亂，請立刻聯絡這個人的醫療人員，或撥打 119（美國為 911）。及早檢查，代表可以找出可治療的原因；如果真的是失智症，也有更多時間規劃和尋找支持。在這段過程中也請照顧好自己；請見我們的[照顧者自我照顧指南](/caregiving/caregiver-self-care/)。在台灣，也可以向台灣失智症協會或 1966 長照專線詢問資源。
