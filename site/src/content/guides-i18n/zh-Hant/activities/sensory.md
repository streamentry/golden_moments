感官活動運用五種感官：觸覺、嗅覺、味覺、聽覺和視覺。它們不需要記憶、不需要步驟，也沒有標準答案，所以在任何階段都適用，到了後期更重要。[美國阿茲海默症協會](https://www.alz.org/help-support/caregiving/stages-behaviors/late-stage)提到，在後期，長輩主要是透過感官來體驗世界，您也可以透過碰觸、聲音、視覺、味覺和嗅覺來表達關心。做幾項安全檢查，能讓這些活動對每個人都更放鬆。

## 什麼是失智症的感官活動？

感官活動是圍繞著一種感官設計的簡單體驗，例如摸布料、聞香草或聽雨聲。[英國國民保健署（NHS）](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)說，後期的活動往往需要以感官為主，並提到音樂、可以摸和拿在手上的物品，以及按摩手。[美國阿茲海默症基金會](https://alzfdn.org/therapeutic-activities-for-3-main-stages-of-alzheimers-disease/)提到，後期的長輩可能很需要把東西抱在身邊，獲得安慰。

## 依感官分類的點子

### 觸覺

- **按摩手。**在手裡把一點乳液搓暖，從手腕到指尖慢慢地順著撫摸。[美國國家老化研究院](https://www.nia.nih.gov/health/alzheimers-caregiving/care-last-stages-alzheimers-disease)提到，用無香料的乳液按摩，能帶來舒適感。
- **布料籃。**大塊的絲絨、燈芯絨、刷毛布、緞布和羊毛布，可以摸、摺，也可以聊聊。
- **溫熱的小毛巾。**天冷的時候，用一條溫熱微濕的毛巾敷手。先用您自己的手腕試溫度。
- **活動圍裙或膝上毯。**牢牢縫上大鈕扣、拉鍊、緞帶和有質感的布塊。
- **摺和撫平。**一籃乾淨的小方巾或餐巾，可以摺、疊、再摺。
- **可以抱著的柔軟東西。**一條刷毛毯、一個靠枕，或一隻逼真的柔軟動物玩偶，自然地遞給他，絕對不要當成玩具。

### 嗅覺

- **新鮮香草。**把薄荷、迷迭香、羅勒或薰衣草的葉子在指間搓一搓，遞給他聞。
- **廚房的味道。**煮咖啡、烤吐司、肉桂，或在旁邊剝一顆橘子。
- **花。**從花園或市場帶幾朵新鮮的花進來。
- **熟悉的用品。**他一向使用的肥皂或乳液，前提是他的皮膚能接受。

### 味覺

- **喜愛的味道。**一小匙他愛吃的東西，例如蘋果泥、布丁或冰淇淋，質地要是他能安全吞嚥的。
- **一起烘焙時幫忙。**邊烤邊嚐嚐水果，或一點點糖霜。
- **季節點心。**夏天的西瓜、秋天的熱飲，溫度要安全。

### 聽覺

- **喜愛的音樂。**熟悉的歌曲，音量柔和，請看[音樂活動](/activities/music/)。
- **大自然的聲音。**雨聲、海浪聲或鳥鳴。美國國家老化研究院提到，音樂、白噪音和大自然的聲音，似乎能讓一些人放鬆。
- **您的聲音。**念給他聽、哼歌，或說一個故事。
- **簡單的樂器。**一面手鼓、一個沙鈴或一個小鈴，可以跟著音樂一起搖或敲。

### 視覺

- **在窗邊看。**窗外的餵鳥器、放學回家的孩子，或下雪。
- **魚缸或緩慢的影片。**柔和的動態，沒有很大的聲音。
- **大張的照片。**一次一張清楚的照片，拿在視線高度。
- **顏色和圖案。**把鮮豔的碎布、花或彩色的餐巾分類，或是我們[著色畫](/games/coloring/)系列中簡單的一頁。
- **戶外。**NHS 建議設置感官花園，有香氣的植物、質感和水景。請看[戶外和園藝活動](/activities/outdoor-and-gardening/)。

## 怎麼製作感官盒

1. **選一個和長輩的人生有關的主題：**海邊、花園、廚房、工作間、縫紉。
2. **挑五六樣大而安全的東西，**例如一個大貝殼、一支木湯匙、一條柔軟的圍巾、一個縫死的乾燥薰衣草小香包，或一塊光滑的木塊。
3. **檢查每一樣東西，**看有沒有小零件、尖銳的邊緣、鬆脫的線頭，以及任何容易破的部分。
4. **一次拿出一樣。**遞給他，描述它，讓他自己探索。
5. **結束後把盒子收起來，**讓它保持特別，下次使用前，也要再檢查一遍。

## 安全第一

感官活動很溫和，但有幾項風險很重要。有些失智長輩會把不是食物的東西當成食物，而且吞嚥可能隨著時間變得更困難；美國國家老化研究院警告，後期的吞嚥問題會提高噎到的風險。

| 風險 | 怎麼做 |
| --- | --- |
| 噎到 | 只用大到吞不下去的東西。盒子裡不要有散放的鈕扣、珠子、硬幣、彈珠或小玩具。食物只提供照護團隊說安全的質地。 |
| 看起來像食物的東西 | 美國國家老化研究院建議，把乳液、肥皂、洗髮精和香水鎖起來，因為它們可能看起來或聞起來像食物，也要把仿真的水果拿走。使用過後，把感官用品收起來。 |
| 過敏 | 開始之前，先確認有沒有堅果、乳膠、羊毛、植物或香料的過敏。 |
| 濃烈的氣味 | 避免濃烈的香水和精油，特別是有氣喘或其他呼吸問題的人。淡淡的天然氣味比較安全。 |
| 皮膚 | 按摩之前，先檢查有沒有疼痛、破皮或脆弱的皮膚。力道要輕，如果他皺眉閃躲就停下。 |
| 溫度 | 溫熱的毛巾和飲料，先用您自己的手腕試溫度。 |
| 尖銳或有毒的東西 | 不要有尖銳的工具、玻璃或有毒的手作材料。 |

## 芳香療法有幫助嗎？

可能沒有任何可測量的幫助。一份[Cochrane 對失智症芳香療法的回顧](https://www.cochrane.org/evidence/CD003150_aromatherapy-dementia)檢視了 13 項研究，共 708 人，全都在照護機構裡進行，沒有發現令人信服的益處。那些研究規模小，結果不一致，副作用的記錄也很不完整。如果長輩喜歡淡淡的、熟悉的氣味，像花園裡的薰衣草，那是分享它的好理由。但它不是治療。

## 怎麼提供感官活動

- **選一個安靜的時刻，**把電視關掉。
- **從正面靠近，**叫他的名字，在碰觸之前先問一聲或說一聲：「我有一些乳液，要不要幫您按摩一下手？」
- **一次只提供一樣，**才不會讓人招架不住。
- **觀察反應。**臉變得柔和、雙手放鬆或微笑，都是好的信號。閃躲、皺眉或坐立不安，就代表要停下。
- **保持簡短。**平靜的五分鐘，就是很好的一次活動。

一起暫停下來做個慢慢的呼吸，像[平靜呼吸](/games/calm-breathing/)，可以是溫和的結尾。更多床邊的點子，請看[後期活動](/activities/late-stage/)，傍晚的不安請看[傍晚時的不安](/caregiving/late-day-restlessness/)。
