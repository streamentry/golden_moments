很多失智長輩花了幾十年的時間持家、養育孩子，或把職場整理得井井有條。被請求幫忙真正的家事，能用很少有其他活動做得到的方式，傳達「您還是這個家的一分子」。這一頁說明哪些事通常行得通、怎麼安排、隨著狀況改變怎麼調整，以及怎麼讓廚房和洗衣區保持安全。

## 為什麼日常家事很適合當作活動？

家事之所以有效，是因為它們熟悉，而且有明確的目的。美國國家老化研究院把洗碗、擺碗筷、掃地、撢灰塵、整理信件、摺衣服和資源回收分類，列為[阿茲海默症長輩可能喜歡的日常活動](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)。美國阿茲海默症協會提到，像擺碗筷這樣的事，能幫助長輩[覺得自己是家裡受重視的一分子](https://www.alz.org/help-support/caregiving/daily-care/activities)。

家事也自帶一個開始的理由。「可以幫我摺這些毛巾嗎？」比「要不要做個活動？」更容易讓人答應。

## 哪些家事值得試試看？

從長輩以前做過的事開始，再配合他今天做得到的程度。

### 洗衣和布品

- **摺毛巾和小方巾。**遞給他一籃小而平的東西。毛巾很包容：沒有什麼摺法是錯的。
- **配襪子。**把一堆混在一起的襪子放在桌上。如果成雙的襪子變得難以辨認，就只用兩、三種顏色差很多的。
- **撫平和疊好。**餐巾、枕頭套或擦碗巾，都可以撫平再疊起來。到了後期，當摺衣服步驟太多時，這很適合。

### 餐桌和廚房

- **擺碗筷。**先擺好一組當作示範，讓長輩照著做。如果這樣太多，就一次遞一樣東西：「這是給每個盤子的叉子。」
- **分餐具。**把洗乾淨的叉子、湯匙和奶油刀混在一個盆子裡，讓他分到有隔間的盤子裡。尖銳的刀不要放進去。
- **擦乾碗盤。**塑膠或不會破的碗盤，加上一條柔軟的毛巾，讓這成為安全的任務。
- **擦桌子或流理台。**一塊濕布，和一個清空的檯面。美國阿茲海默症協會建議，如果有人已經在用手摩擦桌面，可以遞給他一塊布，把不安的動作變成有用的動作。

### 家裡各處

- **撢灰塵。**一支柔軟的撢子，和幾個穩固的表面，例如茶几或書架。
- **整理信件。**把廣告信和型錄遞給他，分成幾堆：留著、回收、晚點再拆。真正的帳單和支票放在別的地方。
- **資源回收分類。**把乾淨的罐子、瓶子和紙分到不同的桶子裡。
- **掃地。**如果平衡感穩，在陽台或廚房地板上用小掃把。
- **澆花。**一個小而輕的澆水壺，和幾盆放在伸手可及處的植物。

### 在陪伴下做簡單的烹飪

烹飪能喚起強烈而愉快的感受。美國國家老化研究院建議，讓長輩收集食材、量、攪拌和倒，或只是告訴別人他最愛的食譜怎麼做。適合的任務包括：

- 洗菜或洗水果
- 攪拌麵糊或涼拌菜
- 撕生菜
- 用鈍的刀子在吐司上抹醬
- 把餅乾麵團放到烤盤上
- 在披薩上放配料

如果量東西變得困難，美國阿茲海默症協會建議由您完成量的部分，再遞給他別的步驟，例如攪拌。

## 怎麼安排一件家事，才會順利？

1. **挑對時間。**選一天中長輩通常休息夠了、心情平靜的時段。對很多人來說，是早上。
2. **清出空間。**一件事、一個檯面，桌上沒有多餘的東西。
3. **邀請，不要指派。**「我需要有人幫忙這些」比「該摺衣服了」更有效。
4. **示範第一個。**慢慢摺一條毛巾，再把下一條遞給他。示範比解釋更清楚。
5. **一次給一個步驟。**一次太多指示會讓人不知所措。等一個步驟做完，再說下一個。
6. **並肩一起做。**在彼此旁邊做同一件事，感覺是陪伴，而不是監督。
7. **談任務，不談結果。**「這些好軟喔」或「跟我說說您以前怎麼整理衣櫃」，能開啟對話，又不會考任何人。

## 隨著能力改變，怎麼調整家事？

能力會隨時間改變，甚至每天不同。美國阿茲海默症協會建議，隨著疾病進展，轉向比較簡單、重複性比較高的任務。

| 如果這件事變困難了 | 可以改試試這個 |
| --- | --- |
| 摺大張的床單 | 摺小方巾，或把餐巾撫平 |
| 擺好整桌的餐具 | 在每個座位放一張餐巾 |
| 把信件分成不同類別 | 把信封疊成一堆 |
| 照著食譜做 | 攪拌，或在您煮的時候在旁邊看、嚐味道 |
| 掃整個地板 | 擦一張小桌子 |
| 做這件事本身 | 坐在旁邊，在您做事時陪著您 |

看也算參與。美國國家老化研究院提到，有些人只是喜歡在旁邊看，這也是很好的參與方式。

## 怎麼讓家事保持安全？

安全第一，尤其在廚房。美國國家老化研究院的[阿茲海默症照顧者居家安全小提醒](https://www.nia.nih.gov/health/safety/alzheimers-caregiving-home-safety-tips)包括：

- 把清潔用品鎖起來或移走，包括看起來像糖果的洗衣膠囊。
- 把刀子、剪刀和電動工具存放在上鎖的地方。
- 為爐子加裝安全旋鈕和自動斷火開關。
- 在烤箱、烤麵包機和熨斗附近，放「停」或「非常燙」的標示，並放在不會著火的位置。
- 把熱水器設定在華氏 120 度（約攝氏 49 度），以降低燙傷的風險。
- 移走人造水果和食物造型的磁鐵，因為它們可能看起來可以吃。

還有一些實用的習慣會有幫助：

- 爐子、烤箱或尖銳工具在使用時，請一直待在同一個房間。
- 擦乾碗盤和擺碗筷時，使用不會破的碗盤。
- 掃地或拖地時，保持地板乾燥而且沒有雜物。
- 如果長輩以前會使用工具，美國阿茲海默症協會建議把工作室裡的危險物品移走，這樣像砂磨一塊木頭這種安全的任務，還是能享受。

## 如果他做得「不對」呢？

隨他去吧。一條摺成三等分而不是對半的毛巾，還是一條摺好的毛巾。美國阿茲海默症協會說得很直接：重要的是一起相處，和長輩覺得自己有用，而不是毛巾有沒有摺得標準。如果有東西真的非重做不可，請等到晚一點，在他看不到的地方做。

當場糾正，可能把愉快的任務變成提醒他失去了什麼。「謝謝，幫了我很大的忙」幾乎永遠是對的話。

## 什麼時候該停下來？

當您看到挫折、疲累或失去興趣的跡象，就停下來或換一件事。提早結束是好的結果，不是失敗。您可以：

- 換成比較簡單的步驟
- 轉到讓人放鬆的事，例如聽音樂或喝一杯咖啡
- 晚一點或改天再試
- 就只是坐在一起

如果長輩說不，不要勉強。溫和的回應方式，請看[他說「不要」時該怎麼辦](/caregiving/when-they-say-no/)。

## 比較不費力的小事，適合比較安靜的時刻

當身體上的家事做不到時，分類和配對還是可以坐著做。[一起分類](/games/sort-together/)讓您把圖片點到廚房或花園的籃子裡，而[圖片配對](/games/picture-pairs/)是溫和的配對遊戲，圖片很大，也沒有計時。[聊天卡](/games/conversation-cards/)有關於家和家人的開放式話題，很適合在做完事後，配著一杯咖啡一起聊。
