การสังเกตเห็นความเปลี่ยนแปลงในความจำของตัวคุณเอง หรือของคนที่คุณรัก อาจทำให้รู้สึกกังวลใจได้ หน้านี้ช่วยให้คุณตัดสินใจได้ว่าเมื่อใดควรนัดหมายพบแพทย์ และควรเตรียมตัวอย่างไร หน้านี้ไม่สามารถบอกได้ว่าใครมีภาวะสมองเสื่อมหรือไม่ **มีเพียงแพทย์หรือผู้เชี่ยวชาญที่มีคุณสมบัติเหมาะสมเท่านั้นที่สามารถวินิจฉัยภาวะสมองเสื่อมได้** และภาวะหลายอย่างที่ทำให้เกิดปัญหาความจำก็ไม่ใช่ภาวะสมองเสื่อม โปรดอย่าอาศัยแบบทดสอบออนไลน์หรือการทดสอบด้วยตนเอง

## สัญญาณเริ่มต้นของภาวะสมองเสื่อมมีอะไรบ้าง

[Alzheimer's Association](https://www.alz.org/alzheimers-dementia/10_signs) อธิบายสัญญาณเริ่มต้นสิบประการ โดยเปรียบเทียบแต่ละข้อกับการเปลี่ยนแปลงตามวัยที่พบบ่อย สรุปเป็นภาษาง่าย ๆ ดังนี้

| สัญญาณที่ควรตรวจสอบ | พบได้ทั่วไปมากกว่าเมื่ออายุมากขึ้น |
| --- | --- |
| การหลงลืมที่รบกวนชีวิตประจำวัน เช่น ลืมเหตุการณ์ล่าสุดหรือถามคำเดิมซ้ำแล้วซ้ำอีก | บางครั้งลืมชื่อหรือนัดหมาย แล้วนึกออกทีหลัง |
| มีปัญหาในการวางแผนหรือแก้ปัญหา เช่น ทำตามสูตรอาหารที่คุ้นเคยไม่ได้ หรือจดจำเรื่องค่าใช้จ่ายไม่ได้ | ทำผิดพลาดเป็นครั้งคราวกับบิลค่าใช้จ่ายในบ้าน |
| ทำกิจกรรมที่คุ้นเคยให้เสร็จได้ยากขึ้น ไม่ว่าจะที่บ้าน ที่ทำงาน หรือขณะออกไปข้างนอก | บางครั้งต้องการความช่วยเหลือในการตั้งค่าไมโครเวฟหรือบันทึกรายการโทรทัศน์ |
| สับสนเรื่องวันที่ ฤดูกาล หรือสถานที่ที่อยู่ | จำวันในสัปดาห์ผิด แล้วนึกออกทีหลัง |
| เริ่มมีปัญหาในการตัดสินระยะทาง การอ่าน หรือการแยกแยะสี | การมองเห็นเปลี่ยนไปจากต้อกระจก |
| เริ่มมีปัญหาเกี่ยวกับคำพูด เช่น หยุดพูดกลางคัน หรือเรียกสิ่งของผิดชื่อ | บางครั้งนึกคำที่ต้องการพูดไม่ออก |
| วางสิ่งของไว้ในที่ที่ไม่ปกติและนึกไม่ออกว่าเอาไปไว้ที่ไหน | วางของผิดที่เป็นครั้งคราว แล้วหาพบโดยลองย้อนรอย |
| การตัดสินใจที่ไม่เหมาะสม เช่น เรื่องเงินหรือการดูแลความสะอาดของตนเอง | ตัดสินใจผิดพลาดเป็นครั้งคราว |
| ถอนตัวจากงานอดิเรก งาน หรือกิจกรรมทางสังคม | บางครั้งไม่อยากไปร่วมงานกับครอบครัวหรือกิจกรรมทางสังคม |
| อารมณ์หรือบุคลิกภาพเปลี่ยนไป เช่น สับสน ระแวงกลัว หวาดกลัว หรือวิตกกังวล | มีวิธีทำสิ่งต่าง ๆ ที่เป็นแบบเดิมของตนเอง และหงุดหงิดเมื่อตารางชีวิตเปลี่ยนไป |

การมีสัญญาณเพียงข้อเดียวไม่ได้หมายความว่าเป็นภาวะสมองเสื่อม สิ่งสำคัญคือ **การเปลี่ยนแปลงจากสิ่งที่ปกติสำหรับคนนั้น** โดยเฉพาะเมื่อทำให้ชีวิตประจำวันยากขึ้น

## ความชราตามปกติแตกต่างจากภาวะสมองเสื่อมอย่างไร

[National Institute on Aging (NIA)](https://www.nia.nih.gov/health/memory-loss-and-forgetfulness/memory-problems-forgetfulness-and-aging) ระบุว่าผู้สูงอายุหลายคนสังเกตว่าตนเองนึกถึงเรื่องต่าง ๆ ได้ช้าลง หรือบางครั้งวางของผิดที่หรือลืมจ่ายบิล สิ่งเหล่านี้มักเป็นสัญญาณของการหลงลืมเล็กน้อย **ภาวะสมองเสื่อมไม่ใช่เรื่องปกติของวัยสูงอายุ** ปัญหาความจำที่รุนแรงจะทำให้กิจกรรมในชีวิตประจำวันเป็นเรื่องยาก เช่น การขับรถ การใช้โทรศัพท์ หรือการหาทางกลับบ้าน

NIA แนะนำให้พูดคุยกับแพทย์หากมีคนที่

- ถามคำถามเดิมซ้ำแล้วซ้ำอีก
- หลงทางในสถานที่ที่เคยคุ้นเคยเป็นอย่างดี
- มีปัญหาในการทำตามสูตรอาหารหรือคำแนะนำ
- สับสนมากขึ้นเกี่ยวกับเวลา ผู้คน และสถานที่
- เริ่มดูแลตัวเองน้อยลง เช่น กินอาหารไม่ดี ไม่อาบน้ำ หรือมีพฤติกรรมที่ไม่ปลอดภัย

บางคนอาจมีภาวะ **ความบกพร่องทางการรู้คิดเล็กน้อย (MCI)** หมายถึงมีปัญหาด้านความจำหรือการคิดมากกว่าคนอื่นในวัยเดียวกัน แต่ยังสามารถจัดการชีวิตประจำวันได้ NIA ระบุว่า MCI อาจเป็นสัญญาณเริ่มต้นของโรคอัลไซเมอร์ แต่ไม่ได้หมายความว่าทุกคนที่มี MCI จะเป็นโรคนี้

## อะไรอีกบ้างที่อาจทำให้เกิดปัญหาความจำ

มีหลายสิ่งที่นอกเหนือจากภาวะสมองเสื่อมที่ส่งผลต่อความจำได้ และบางอย่างก็ดีขึ้นได้เมื่อได้รับการรักษา NIA ระบุถึง

- **ปัญหาไทรอยด์ ไต หรือตับ**
- **ผลข้างเคียงของยา**
- **ภาวะซึมเศร้าและความวิตกกังวล**
- **การขาดวิตามินบีสิบสอง** หรือการรับประทานอาหารที่มีประโยชน์ไม่เพียงพอ
- **ปัญหาการนอนหลับ**
- **การใช้แอลกอฮอล์หรือสารเสพติดในทางที่ผิด**
- **การติดเชื้อ ลิ่มเลือด หรือเนื้องอก** ในสมอง
- **การบาดเจ็บที่ศีรษะ** เช่น การกระทบกระเทือนที่สมอง
- **ความเครียดอย่างรุนแรงหรือความโศกเศร้า** เช่น การเกษียณอายุหรือการสูญเสียคู่ชีวิต

ปัญหาการได้ยินและการมองเห็นก็อาจทำให้ดูเหมือนมีอาการสับสนได้ ดูเพิ่มเติมได้ที่[คู่มือเรื่องการได้ยิน](/brain-health/hearing/)ของเรา นี่คือเหตุผลที่การตรวจสุขภาพกับแพทย์จึงมีความสำคัญ ตามข้อมูลจาก [Alzheimer's Association](https://www.alz.org/alzheimers-dementia/diagnosis/visiting-your-doctor) แพทย์มักสั่งตรวจเลือดเพื่อตรวจหาปัญหาไทรอยด์ ภาวะขาดวิตามิน และการติดเชื้อ การนอนหลับที่ดี (ดู[เรื่องการนอนหลับ](/brain-health/sleep/)) และการรักษาภาวะซึมเศร้าก็เป็นเรื่องที่ควรพูดคุยกับแพทย์เช่นกัน

## อาการสับสนที่เกิดขึ้นกะทันหันเป็นภาวะฉุกเฉิน

**อาการสับสนที่เกิดขึ้นอย่างรวดเร็วภายในไม่กี่ชั่วโมงหรือไม่กี่วัน ต้องได้รับการดูแลทางการแพทย์โดยด่วน** อาจเป็นภาวะเพ้อสับสน [VA อธิบายว่าภาวะเพ้อสับสน](https://www.va.gov/geriatrics/pages/delirium_when_should_i_worry_about_delirium.asp)เป็นภาวะฉุกเฉินทางการแพทย์ และแนะนำให้โทรหาผู้ให้บริการด้านสุขภาพของผู้นั้นทันทีหรือโทร 911 สัญญาณที่อาจพบ ได้แก่

- ความสามารถในการคิดอย่างชัดเจนดีขึ้นและแย่ลงสลับกันไปมา
- มีปัญหาในการจดจ่อ
- ความคิดสับสนไม่เป็นระเบียบ
- ง่วงซึมผิดปกติ หรือกระสับกระส่ายและอยู่ไม่สุขผิดปกติ

ภาวะนี้อาจเกิดขึ้นได้กับทุกคน รวมถึงผู้ที่มีภาวะสมองเสื่อมอยู่แล้ว ตามข้อมูลจาก [NHS](https://www.nhs.uk/symptoms/confusion/) สาเหตุที่พบบ่อย ได้แก่ การติดเชื้อ (การติดเชื้อทางเดินปัสสาวะพบบ่อยในผู้สูงอายุและผู้ที่มีภาวะสมองเสื่อม) โรคหลอดเลือดสมอง ระดับน้ำตาลในเลือดต่ำในผู้ที่เป็นเบาหวาน การบาดเจ็บที่ศีรษะ และยาบางชนิด ระหว่างรอความช่วยเหลือ ให้อยู่กับผู้นั้นและพูดให้กำลังใจด้วยคำพูดสั้น ๆ ง่าย ๆ ไม่ควรถามคำถามมากมาย และควรจดบันทึกยาที่ผู้นั้นใช้

## ควรเตรียมตัวอย่างไรก่อนพาไปพบแพทย์

การเตรียมตัวที่ดีช่วยให้การพบแพทย์มีประโยชน์มากขึ้น [Alzheimer's Association](https://www.alz.org/alzheimers-dementia/diagnosis/visiting-your-doctor) แนะนำให้นำสิ่งต่อไปนี้ไปด้วย

1. **รายการการเปลี่ยนแปลง** ด้านความจำ อารมณ์ และพฤติกรรม พร้อมตัวอย่างที่ชัดเจนและช่วงเวลาที่เริ่มสังเกตเห็นโดยประมาณ
2. **ปัญหาสุขภาพในอดีตและปัจจุบัน** รวมถึงประวัติครอบครัวที่เกี่ยวข้องกับปัญหาความจำ
3. **ยาตามใบสั่งแพทย์และยาที่ซื้อเองทั้งหมด**
4. **วิตามินหรืออาหารเสริมทั้งหมด**
5. **คำถามที่คุณต้องการถาม** เช่น จะมีการตรวจอะไรบ้าง ใช้เวลานานเท่าใด และจะทราบผลเมื่อใด

การพาสมาชิกในครอบครัวหรือเพื่อนที่รู้จักผู้นั้นเป็นอย่างดีไปด้วยก็เป็นประโยชน์ [NIA อธิบาย](https://www.nia.nih.gov/health/alzheimers-symptoms-and-diagnosis/how-alzheimers-disease-diagnosed)ว่าแพทย์อาจถามทั้งตัวผู้นั้นและสมาชิกในครอบครัวเกี่ยวกับสุขภาพ ยา กิจกรรมประจำวัน และการเปลี่ยนแปลงของพฤติกรรม แพทย์อาจ

- ทำแบบทดสอบความจำ การแก้ปัญหา การจดจ่อ การนับ และการใช้ภาษา
- สั่งตรวจเลือด ปัสสาวะ และการตรวจอื่น ๆ เพื่อหาสาเหตุอื่น
- ตรวจหาภาวะซึมเศร้าหรือภาวะสุขภาพจิตอื่น ๆ
- สั่งตรวจสแกนสมอง เช่น CT หรือ MRI
- ส่งต่อไปยังแพทย์เฉพาะทาง เช่น แพทย์ผู้เชี่ยวชาญด้านผู้สูงอายุ แพทย์ประสาทวิทยา จิตแพทย์ผู้สูงอายุ หรือนักประสาทจิตวิทยา

NIA ระบุว่าการประเมินด้านการรู้คิดเป็นส่วนหนึ่งที่จำเป็นของการตรวจสุขภาพประจำปีของ Medicare ซึ่งอาจเป็นช่วงเวลาที่เหมาะสมในการพูดคุยเรื่องความกังวล แม้แต่แบบทดสอบสั้น ๆ ที่แพทย์ใช้ก็ยังไม่เพียงพอที่จะวินิจฉัยภาวะสมองเสื่อมได้ด้วยตัวเอง แบบทดสอบเหล่านี้เป็นเพียงขั้นตอนแรกของการประเมินที่ละเอียดขึ้น และการวินิจฉัยอาจต้องใช้เวลามากกว่าหนึ่งครั้ง NIA แนะนำว่าผู้ที่มีปัญหาความจำควรกลับมาพบแพทย์ทุกหกถึงสิบสองเดือน

## การเริ่มพูดคุยอย่างอ่อนโยน

หากคุณเป็นห่วงคนอื่น ให้เลือกช่วงเวลาที่สงบและเป็นส่วนตัว พูดคุยเกี่ยวกับสิ่งที่คุณสังเกตเห็นอย่างชัดเจน โดยแสดงออกถึงความห่วงใยต่อสุขภาพของเขา มากกว่าการตำหนิ การแนะนำให้ไปตรวจสุขภาพทั่วไปอาจทำให้รู้สึกกังวลน้อยกว่า ควรให้ผู้นั้นมีส่วนร่วมในการตัดสินใจและพูดคุยกับเขาในฐานะผู้ใหญ่ที่เขาเป็น [คำแนะนำด้านการสื่อสาร](/caregiving/communication-tips/)ของเราอาจช่วยคุณได้

## พูดคุยกับแพทย์

หากคุณสังเกตเห็นการเปลี่ยนแปลงด้านความจำ การคิด อารมณ์ หรือความสามารถในชีวิตประจำวันที่เป็นเรื่องใหม่และเกิดขึ้นเรื่อย ๆ ควรนัดหมายพบแพทย์เวชปฏิบัติทั่วไป หากมีอาการสับสนเกิดขึ้นอย่างกะทันหัน ให้โทร 911 หรือโทรหาผู้ให้บริการด้านสุขภาพของผู้นั้นทันที การตรวจเช็กตั้งแต่เนิ่น ๆ ช่วยให้พบสาเหตุที่รักษาได้ และหากเป็นภาวะสมองเสื่อม ก็จะมีเวลาในการวางแผนและหาการสนับสนุนมากขึ้น อย่าลืมดูแลตัวเองในช่วงเวลานี้ด้วย ดูเพิ่มเติมได้ที่[คู่มือการดูแลตัวเองของผู้ดูแล](/caregiving/caregiver-self-care/)ของเรา

หน้านี้เป็นข้อมูลทั่วไป ไม่ใช่คำแนะนำทางการแพทย์ ดู[ข้อจำกัดความรับผิดชอบทางการแพทย์](/medical-disclaimer/)ของเรา
