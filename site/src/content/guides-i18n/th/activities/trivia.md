เกมตอบคำถามเป็นหนึ่งในกิจกรรมกลุ่มที่ขอกันมากที่สุดในบ้านพักผู้สูงอายุและศูนย์กลางวัน และหลายครอบครัวก็เล่นกันที่โต๊ะในครัว ถ้าเล่นแบบปกติที่มีแต้มและให้คนเดียวตอบ ผู้มีภาวะสมองเสื่อมอาจรู้สึกว่าถูกจี้ให้ตอบ แต่ถ้าเล่นอย่างอ่อนโยน ก็เป็นวิธีที่สนุกสนานในการฟังเรื่องเล่า ด้านล่างมีคำถามง่าย ๆ 50 ข้อ พร้อมตัวเลือกและหัวข้อชวนคุยของแต่ละข้อ ตามด้วยวิธีจัดกิจกรรม

## จะทำให้เกมตอบคำถามเหมาะกับผู้มีภาวะสมองเสื่อมได้อย่างไร

ให้เป็นเรื่องของการจำได้เมื่อเห็นและการนึกถึงเรื่องเมื่อนานมาแล้ว และต้อนรับทุกคำตอบ

1. **ถามเรื่องในอดีตที่ไกลออกไป** [Alzheimer's Association](https://www.alz.org/alzheimers-dementia/what-is-alzheimers) ระบุว่าอาการเริ่มแรกที่พบบ่อยที่สุดของโรคอัลไซเมอร์คือจำข้อมูลที่เพิ่งเรียนรู้ได้ยาก เพลง สำนวน และชีวิตประจำวันเมื่อหลายสิบปีก่อนมักเป็นพื้นที่ที่ง่ายกว่า
2. **ให้ตัวเลือกเสมอ** การเลือกคำตอบที่ถูกจากสองหรือสามข้อง่ายกว่าการนึกคำตอบขึ้นมาจากความว่างเปล่ามาก
3. **อ่านคำถามออกเสียงและแสดงตัวใหญ่** กระดานไวต์บอร์ดหรือแท็บเล็ตที่ชูให้ดูช่วยผู้ที่ได้ยินไม่ชัด
4. **บอกคำตอบอย่างใจกว้าง** ถ้าไม่มีใครรู้ ให้บอกอย่างอบอุ่นแล้วไปต่อ ห้ามพูดว่า "ไหนลองนึกดูสิ ต้องรู้สิ"
5. **ไม่นับคะแนน** ทั้งรายคนและรายโต๊ะ ถ้าทุกคนอยากได้ตัวเลข ให้นับรวมของทั้งกลุ่มเพียงตัวเดียว
6. **ไม่เรียกถามใครคนเดียว** ให้ใครก็ตอบได้ ถ้าคุยกันตัวต่อตัว ให้ตอบไปด้วยกัน "ฉันว่าเป็นเปียโนนะ คุณว่าไง"
7. **ใช้หัวข้อชวนคุย** คำตอบคือจุดเริ่มต้น ไม่ใช่จุดจบ เรื่องเล่าคือเป้าหมายที่แท้จริง
8. **ให้สั้น** สิบข้อโดยมีเรื่องเล่าคั่นก็เพียงพอ

[National Institute on Aging](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease) สรุปกฎหลักไว้ง่าย ๆ ว่า ให้สังเกตความหงุดหงิด และดูให้ท่านรู้สึกว่าประสบความสำเร็จ [Alzheimer's Foundation of America](https://alzfdn.org/therapeutic-activities-for-3-main-stages-of-alzheimers-disease/) ระบุเกมตอบคำถามไว้ในกิจกรรมสำหรับระยะเริ่มต้น ในระยะกลาง ให้เหลือสองตัวเลือกและพึ่งหัวข้อชวนคุยให้มาก ในระยะหลัง ให้เปลี่ยนไปใช้คำถามแบบอย่างนี้หรืออย่างนั้นด้านล่าง

## คำถามเรื่องดนตรีและความบันเทิง

คำตอบเป็นตัวหนา ปรับให้เข้ากับท่าน ผู้ที่โตมากับเพลงลูกทุ่งจะอยากได้นักร้องคนละกลุ่มกับผู้ที่โตมากับเพลงสุนทราภรณ์

| คำถาม | ตัวเลือก | ชวนคุย |
| --- | --- | --- |
| ใครได้รับสมญานามว่า "ราชาเพลงร็อกแอนด์โรล" | **เอลวิส เพรสลีย์**, แฟรงก์ ซินาตรา, บิง ครอสบี | เคยฟังเพลงของเอลวิสไหม |
| หมอลำเป็นการแสดงพื้นบ้านของภาคใด | ภาคใต้, **ภาคอีสาน**, ภาคเหนือ | เคยดูหมอลำไหม ชอบตอนไหน |
| หนังตะลุงเป็นการแสดงพื้นบ้านของภาคใด | ภาคเหนือ, ภาคกลาง, **ภาคใต้** | เคยดูหนังตะลุงที่ไหนบ้าง |
| เพลงที่ขึ้นต้นว่า "วันเพ็ญเดือนสิบสอง" ร้องกันในเทศกาลใด | สงกรานต์, **ลอยกระทง**, ปีใหม่ | ลองร้องสักท่อนด้วยกัน |
| รำวงเป็นการเต้นรำแบบใด | รำคนเดียวบนเวที, **เดินรำเป็นวงกลมไปตามจังหวะเพลง**, นั่งรำอยู่กับที่ | ไปรำวงที่ไหนมาบ้าง |
| เครื่องดนตรีไทยที่เป่าด้วยปากและมีรูเรียงเป็นแถว คือ | ซอ, **ขลุ่ย**, ฆ้อง | ที่บ้านมีใครเล่นดนตรีบ้างไหม |
| เครื่องดนตรีไทยที่ใช้คันชักสีให้เกิดเสียง คือ | **ซอ**, ขลุ่ย, กลอง | ชอบเสียงดนตรีไทยแบบไหน |
| ถ้าอยากฟังเพลงจากแผ่นเสียง ต้องใช้อะไร | พัดลม, **เครื่องเล่นแผ่นเสียง**, เตารีด | เพลงโปรดที่เคยฟังจากแผ่นเสียงคือเพลงอะไร |
| เครื่องดนตรีชนิดใดมี 88 แป้น | กีตาร์, **เปียโน**, ทรัมเป็ต | ในครอบครัวมีใครเล่นบ้างไหม |
| การเต้นรำแบบใดนับจังหวะ หนึ่ง-สอง-สาม หนึ่ง-สอง-สาม | **วอลทซ์**, ทวิสต์, ทังโก | ไปเต้นรำที่ไหนมาบ้าง |

อ่านเรื่องดนตรีเพิ่มเติมได้ที่[กิจกรรมดนตรีสำหรับผู้มีภาวะสมองเสื่อม](/activities/music/)

## คำถามเรื่องชีวิตประจำวัน

| คำถาม | ตัวเลือก | ชวนคุย |
| --- | --- | --- |
| ก่อนมีตู้เย็น หลายบ้านเก็บกับข้าวไว้ใน... | ตู้เสื้อผ้า, **ตู้กับข้าว**, ตู้รองเท้า | ตู้กับข้าวที่บ้านใส่อะไรไว้บ้าง |
| ใครนำจดหมายมาส่งถึงหน้าบ้าน | ช่างตัดผม, **บุรุษไปรษณีย์**, พ่อค้าขายผลไม้ | นอกจากจดหมาย มีอะไรมาส่งถึงบ้านอีก |
| โทรศัพท์แบบเก่าที่มีจานกลม ต้องโทรออกอย่างไร | กดปุ่ม, **หมุนจานเลข**, พูดใส่เครื่อง | เล่าเรื่องโทรศัพท์ที่บ้านให้ฟังหน่อย |
| รถรับจ้างที่คนปั่นด้วยแรงขาและพาผู้โดยสารนั่งไปด้วย เรียกว่าอะไร | **สามล้อถีบ**, รถไฟ, เรือหางยาว | เคยนั่งสามล้อไปไหนบ้าง |
| ปาท่องโก๋มักกินคู่กับอะไรในมื้อเช้า | น้ำปลา, **น้ำเต้าหู้**, น้ำส้มสายชู | ตอนเช้าที่บ้านกินอะไรกันบ้าง |
| ของเล่นที่สานด้วยหวายเป็นลูกกลม ใช้เตะส่งกัน คือ | ว่าว, **ตะกร้อ**, ลูกข่าง | ตอนเด็กชอบเล่นของเล่นอะไร |
| หนังกลางแปลงคือการดูหนังแบบใด | ในห้องเรียน, **กลางแจ้ง**, บนเรือ | ไปดูกับใคร |
| ตลาดน้ำเป็นตลาดที่ซื้อขายของกันที่ไหน | บนรถไฟ, **บนเรือในแม่น้ำหรือคลอง**, บนภูเขา | เคยไปตลาดน้ำไหม ซื้ออะไรกลับมา |
| เด็ก ๆ ในสมัยก่อนมักหยอดเหรียญเก็บไว้ในอะไร | หม้อข้าว, **กระปุกออมสิน**, กระเป๋าเดินทาง | ตอนเด็กเคยเก็บเหรียญใส่กระปุกไหม |
| เสื้อนักเรียนไทยมักเป็นสีอะไร | แดง, **ขาว**, ดำ | ตอนเด็กเดินทางไปโรงเรียนอย่างไร |

## เทศกาล ธรรมชาติ และสถานที่

| คำถาม | ตัวเลือก | ชวนคุย |
| --- | --- | --- |
| วันสงกรานต์ตรงกับเดือนใด | มกราคม, **เมษายน**, สิงหาคม | สมัยก่อนสงกรานต์ที่บ้านทำอะไรกันบ้าง |
| วันขึ้นปีใหม่ตรงกับวันที่เท่าไร | **1 มกราคม**, 1 มีนาคม, 1 กรกฎาคม | ปีใหม่ที่บ้านทำอะไรกัน |
| ตรุษจีน ผู้ใหญ่มักให้อะไรเด็ก ๆ | ดอกไม้, **อั่งเปา**, ผ้าพันคอ | เคยได้รับอั่งเปาไหม |
| ฤดูฝนของไทยเริ่มราวเดือนใด | ธันวาคม, **พฤษภาคม**, มีนาคม | ฝนแรกของปีที่บ้านทำอะไรกันบ้าง |
| ผลไม้ที่ได้ชื่อว่าราชาแห่งผลไม้ คือ | **ทุเรียน**, ส้ม, กล้วย | ชอบกินผลไม้อะไร |
| แม่น้ำสายสำคัญที่ไหลผ่านกรุงเทพฯ คือ | **แม่น้ำเจ้าพระยา**, แม่น้ำปิง, แม่น้ำโขง | เคยนั่งเรือข้ามแม่น้ำไหม |
| จังหวัดเชียงใหม่ตั้งอยู่ในภาคใด | ภาคใต้, ภาคกลาง, **ภาคเหนือ** | เคยไปเชียงใหม่ไหม |
| ผึ้งทำอะไร | นม, **น้ำผึ้ง**, ไหม | น้ำผึ้งใส่ชา หรือทาบนขนมปัง |
| สัตว์ที่ชาวนาไทยสมัยก่อนใช้ไถนา คือ | **ควาย**, แมว, ไก่ | เคยอยู่ใกล้ทุ่งนาไหม |
| ดอกไม้สูงสีเหลืองที่โด่งดังเรื่องหันหน้าตามดวงอาทิตย์ คือ | กุหลาบ, **ทานตะวัน**, ทิวลิป | ที่บ้านเคยปลูกอะไรไว้บ้าง |
| ปีที่เดือนกุมภาพันธ์มี 29 วัน มีทั้งปีกี่วัน | 365, **366**, 360 | เล่าเรื่องวันเกิดที่จำได้ให้ฟังหน่อย |
| ฤดูต่อจากฤดูหนาวในประเทศไทยคือฤดูอะไร | **ฤดูร้อน**, ฤดูฝน, ฤดูใบไม้ร่วง | ชอบฤดูไหนที่สุด |

## คำถามเรื่องอาหารและกีฬา

| คำถาม | ตัวเลือก | ชวนคุย |
| --- | --- | --- |
| ลูกเกดคือผลไม้ชนิดใดที่ตากแห้ง | ลูกพลัม, **องุ่น**, เชอร์รี | เคยเอาลูกเกดใส่ขนมไหม |
| กล้วยตากทำจากกล้วยที่นำไป... | **ตากแดด**, แช่แข็ง, ทอด | ใครในบ้านชอบกินกล้วยตาก |
| ข้าวเหนียวกับ... เป็นขนมยอดนิยม | **มะม่วง**, หัวหอม, แตงกวา | ชอบข้าวเหนียวมะม่วงหวานมากหรือหวานน้อย |
| น้ำพริกมีส่วนผสมหลักคืออะไร | **พริก**, นม, แป้ง | น้ำพริกที่บ้านกินกับผักอะไร |
| ลอดช่องกินกับน้ำอะไร | น้ำซุป, **น้ำกะทิ**, น้ำชา | ขนมไทยอะไรที่ชอบที่สุด |
| ทีมฟุตบอลลงสนามพร้อมกันกี่คน | 9, **11**, 13 | เชียร์ทีมไหน |
| มวยไทยมีชื่อเสียงเรื่องการใช้ส่วนใดของร่างกาย นอกจากหมัดและเท้า | ฟัน, **ศอกและเข่า**, นิ้วมือ | เคยดูมวยทางโทรทัศน์หรือที่เวทีไหม |
| กีฬาเปตองเล่นด้วยอะไร | ไม้ตี, **ลูกโลหะกลม**, ห่วงยาง | ที่ชุมชนมีใครเล่นเปตองบ้างไหม |
| ลูกที่ใช้ตีในกีฬาแบดมินตันเรียกว่าอะไร | **ลูกขนไก่**, ลูกเหล็ก, ลูกโป่ง | เคยเล่นแบดมินตันไหม |
| กีฬาใดต้องตีลูกให้ข้ามตาข่ายด้วยมือ | **วอลเลย์บอล**, ฟุตบอล, ว่ายน้ำ | ที่โรงเรียนเคยเล่นกีฬาอะไร |

## สำนวนที่คุ้นเคย

การต่อสำนวนให้ครบใช้ภาษาที่เรียนรู้มานานและมักทำได้ง่าย เกม[ต่อสำนวน](/games/finish-the-saying/)ของเรามีอีกมาก และแตะเพื่อดูคำลงท้ายได้

| สำนวน | ตัวเลือก | ชวนคุย |
| --- | --- | --- |
| น้ำขึ้นให้รีบ... | **ตัก**, อาบ, ไป | ชอบไปเที่ยวริมแม่น้ำ ริมคลอง หรือริมทะเลมากกว่ากัน |
| ไก่งามเพราะขน คนงามเพราะ... | ยิ้ม, **แต่ง**, ใจ | ชอบใส่เสื้อผ้าสีอะไรหรือลายแบบไหนที่สุด |
| ตำน้ำพริกละลาย... | ลำคลอง, **แม่น้ำ**, หม้อแกง | ชอบน้ำพริกแบบไหน กินกับผักอะไรอร่อยที่สุด |
| ฝนทั่งให้เป็น... | **เข็ม**, มีด, ตะปู | มีอะไรที่ตั้งใจทำทีละนิดจนสำเร็จบ้าง |
| หนีเสือปะ... | ลิง, ช้าง, **จระเข้** | ถ้าได้ไปสวนสัตว์ อยากดูสัตว์อะไรก่อน |
| ใกล้เกลือกิน... | พริก, **ด่าง**, กะปิ | แถวบ้านมีของอร่อยหรือของดีอะไรบ้าง |
| สิบปากว่าไม่เท่าตา... | ดู, มอง, **เห็น** | มีที่ไหนที่อยากไปเห็นด้วยตาตัวเองสักครั้ง |
| ช้า ๆ ได้พร้า... | เล่มใหม่, **เล่มงาม**, เล่มโต | มีอะไรที่ชอบค่อย ๆ ทำ ไม่ต้องรีบบ้าง |

## คำถามแบบอย่างนี้หรืออย่างนั้น ที่ไม่มีคำตอบผิด

เหมาะกับทุกระยะ รวมถึงระยะหลัง เพราะไม่มีอะไรให้ตอบให้ถูก ถามแล้วฟัง และบอกคำตอบของคุณเองด้วย

- กาแฟหรือชา
- ทะเลหรือภูเขา
- สุนัขหรือแมว
- หน้าร้อนหรือหน้าหนาว
- ขนมไทยหรือเค้ก
- เต้นรำหรือนั่งดู
- พระอาทิตย์ขึ้นหรือพระอาทิตย์ตก
- ระเบียงหน้าบ้านหรือสวนหลังบ้าน
- วิทยุหรือแผ่นเสียง
- ข้าวต้มหรือโจ๊ก
- ดอกกุหลาบหรือดอกมะลิ
- เดินทางด้วยรถไฟหรือรถยนต์

ถ้าอยากได้คำชวนคุยที่มาพร้อมภาพ ลองใช้[การ์ดชวนคุย](/games/conversation-cards/)แบบพิมพ์ได้ของเรา

## จะจัดเกมตอบคำถามในบ้านพักผู้สูงอายุหรือในกลุ่มอย่างไร

1. **จัดที่นั่งให้ทุกคนมองเห็นและได้ยิน** ใส่เครื่องช่วยฟัง สวมแว่น ปิดโทรทัศน์
2. **เกริ่นว่าเป็นการพูดคุย** "ฉันมีคำถามเรื่องสมัยก่อนนิดหน่อย และเชื่อว่าท่านรู้มากกว่าฉันแน่ ๆ"
3. **อ่านแต่ละคำถามสองรอบและแสดงตัวเลือกตัวใหญ่**
4. **ต้อนรับคำตอบจากทุกมุมของห้อง** พูดซ้ำคำตอบดี ๆ เพื่อให้ทุกคนได้ยิน
5. **บอกคำตอบให้ทุกคน** แล้วถามหัวข้อชวนคุยกับทั้งห้อง
6. **ตามพลังของกลุ่ม** ถ้าคำถามเดียวทำให้เกิดเรื่องเล่ากันสิบนาที ก็ปล่อยไป
7. **จบด้วยเพลงหรือรอบอย่างนี้หรืออย่างนั้น** ให้ทุกคนจบด้วยสิ่งที่ง่าย

สำหรับรูปแบบกลุ่มอื่น ๆ รวมถึงบิงโกภาพและการร้องเพลงด้วยกัน ดู[กิจกรรมกลุ่มสำหรับบ้านพักผู้สูงอายุ](/activities/care-home-groups/)

## เมื่อไรควรเปลี่ยนแผน

ถ้าท่านดูกังวล เงียบลง หรือพูดว่า "ไม่รู้" มากกว่าหนึ่งครั้ง ให้ทำให้ง่ายขึ้น ลดเหลือสองตัวเลือก ตอบไปด้วยกัน หรือเปลี่ยนไปใช้คำถามอย่างนี้หรืออย่างนั้น ถ้ากลุ่มอยากคุยกันเรื่องคำถามข้อเดียวทั้งบ่าย นั่นคือความสำเร็จ จุดประสงค์ไม่เคยเป็นคำตอบที่ถูก แต่คือเวลาที่ได้อยู่ท่ามกลางคนที่ดี
