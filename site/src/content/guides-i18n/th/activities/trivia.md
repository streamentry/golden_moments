เกมตอบคำถามเป็นหนึ่งในกิจกรรมกลุ่มที่คนนิยมขอมากที่สุดในบ้านพักคนชราและศูนย์ดูแลกลางวัน และหลายครอบครัวก็เล่นกันที่โต๊ะในครัวด้วย หากจัดแบบเดิมคือมีคะแนนและให้คนคนเดียวตอบ อาจทำให้ผู้ที่อยู่กับภาวะสมองเสื่อมรู้สึกถูกจับตา แต่ถ้าจัดอย่างนุ่มนวล จะเป็นวิธีมีชีวิตชีวาในการฟังเรื่องเล่า ข้างล่างนี้มี 50 คำถามง่ายๆ พร้อมตัวเลือกและประเด็นให้คุยสำหรับแต่ละข้อ ตามด้วยวิธีจัดเกมให้เหมาะ

## จะจัดเกมตอบคำถามให้ได้ผลสำหรับผู้ที่อยู่กับภาวะสมองเสื่อมอย่างไร

ให้เน้นที่การรับรู้และจดจำสิ่งที่เกิดขึ้นนานแล้ว และต้อนรับทุกคำตอบ

1. **ถามถึงอดีตที่ไกลออกไป** [สมาคมอัลไซเมอร์](https://www.alz.org/alzheimers-dementia/what-is-alzheimers) ระบุว่าอาการเริ่มต้นที่พบบ่อยที่สุดของอัลไซเมอร์คือการจำข้อมูลที่เพิ่งเรียนรู้ได้ยาก เพลง คำพูดติดปาก และชีวิตประจำวันจากหลายทศวรรษก่อนมักเป็นพื้นที่ที่เข้าถึงได้ง่ายกว่า
2. **มีตัวเลือกให้เสมอ** การเลือกคำตอบที่ถูกจากสองหรือสามตัวเลือกง่ายกว่าการดึงคำตอบขึ้นมาจากที่ว่างเปล่ามาก
3. **อ่านคำถามดังๆ และโชว์ให้ใหญ่** กระดานไวท์บอร์ดหรือแท็บเล็ตที่ยกขึ้นมาช่วยคนที่ได้ยินไม่ค่อยชัด
4. **บอกเฉลยอย่างเต็มใจ** ถ้าไม่มีใครรู้ ก็บอกอย่างอบอุ่นแล้วเดินต่อ อย่าพูดว่า 'เอ้าหง่ายๆ แบบนี้ยังไม่รู้เหรอ'
5. **ไม่ให้คะแนน** ไม่ให้รายคนและไม่ให้รายโต๊ะ ถ้าคนอยากมีตัวเลข ก็เก็บยอดรวมเพียงหนึ่งยอดของทั้งกลุ่ม
6. **อย่าเรียกให้คนคนเดียวตอบ** ให้คำตอบมาจากใครก็ได้ ในแบบตัวต่อตัว ให้ตอบด้วยกันว่า 'ฉันคิดว่าเป็นเปียโนนะ คุณคิดว่าอะไร?'
7. **ใช้ประเด็นสนทนา** คำตอบเป็นจุดเริ่ม ไม่ใช่จุดจบ เรื่องเล่าต่างหากคือเป้าหมายที่แท้จริง
8. **ทำให้สั้นๆ** คำถามสิบข้อโดยมีเรื่องเล่าแทรกอยู่ระหว่างก็เพียงพอแล้ว

[สถาบันการสูงอายุแห่งชาติ](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease) กล่าวกฎหลักอย่างง่ายๆ ว่า ให้สังเกตความหงุดหงิดและแน่ใจว่าผู้นั้นรู้สึกว่าตัวเองทำได้สำเร็จ [มูลนิธิอัลไซเมอร์แห่งอเมริกา](https://alzfdn.org/therapeutic-activities-for-3-main-stages-of-alzheimers-disease/) จัดให้เกมตอบคำถามเป็นหนึ่งในกิจกรรมสำหรับระยะเริ่มต้น ในระยะกลาง ให้ใช้สองตัวเลือกและพึ่งประเด็นสนทนา ส่วนระยะหลัง ให้เปลี่ยนไปใช้คำถามแบบอันนี้หรืออันนั้นด้านล่าง

## ปริศนาเกี่ยวกับเพลงและความบันเทิง

คำตอบอยู่ใน **ตัวหนา** ปรับคำถามให้เข้ากับตัวบุคคล คนที่เติบโตกับเพลงโมทาวน์จะอยากได้นักร้องต่างจากคนที่เติบโตกับวงดนตรีใหญ่ๆ

| คำถาม | ตัวเลือก | ประเด็นสนทนา |
| --- | --- | --- |
| ใครถูกเรียกว่ากษัตริย์แห่งร็อกแอนด์โรล? | **เอลวิส เพรสลีย์**, แฟรงก์ ซินาตรา, บิง ครอสบี | เคยเห็นเอลวิสทางโทรทัศน์ไหม? |
| นักร้องคนไหนมีฉายาว่าตาสีฟ้า? | ดีน มาร์ติน, **แฟรงก์ ซินาตรา**, เพอร์รี โคโม | เพลงของซินาตราที่คุณชอบที่สุดคือเพลงอะไร? |
| บิง ครอสบีฝันถึงวัน...สีขาว | **คริสต์มาส**, งานแต่งงาน, บ้าน | ช่วยกันร้องหนึ่งบรรทัด |
| หลุยส์ อาร์มสตรองร้องเพลง "What a Wonderful..." | วัน, **โลก**, ชีวิต | อะไรทำให้โลกของคุณวิเศษ? |
| จูดี การ์แลนด์ร้องเพลง "Over the Rainbow" ในภาพยนตร์เรื่องไหน? | **The Wizard of Oz**, Gone with the Wind, Singin' in the Rain | คุณไปดูภาพยนตร์โปรดที่ไหน? |
| ใครแสดงเป็นลูซีใน "I Love Lucy"? | **ลูซิลล์ บอล**, ดอริส เดย์, เบตตี ไวต์ | ครอบครัวของคุณดูรายการอะไรด้วยกัน? |
| คาวบอยคนไหนขี่ม้าชื่อ Trigger? | **รอย โรเจอร์ส**, จีน ออทรี, จอห์น เวย์น | ตอนเด็กเคยเล่นเป็นคาวบอยไหม? |
| ใครเป็นพิธีกรรายการ "The Tonight Show" เป็นเวลา 30 ปี? | เอ็ด ซัลลิแวน, **จอห์นนี คาร์สัน**, บ็อบ โฮป | เคยนอนดึกเพื่อดูโทรทัศน์ไหม? |
| เครื่องดนตรีชนิดไหนมี 88 คีย์? | กีตาร์, **เปียโน**, ทรัมเป็ต | มีใครในครอบครัวคุณเล่นดนตรีไหม? |
| การเต้นรำแบบไหนนับหนึ่ง-สอง-สาม หนึ่ง-สอง-สาม? | **วอลต์ซ**, ทวิสต์, แทงโก้ | คุณไปเต้นรำที่ไหน? |

สำหรับเรื่องเพลงเพิ่มเติม ดู [กิจกรรมดนตรีสำหรับภาวะสมองเสื่อม](/activities/music/)

## ปริศนาเกี่ยวกับชีวิตประจำวัน

| คำถาม | ตัวเลือก | ประเด็นสนทนา |
| --- | --- | --- |
| ก่อนมีตู้เย็น หลายบ้านเก็บอาหารให้เย็นใน... | **ตู้น้ำแข็ง**, เตาอบ, ห้องใต้หลังคา | ใครเป็นคนส่งน้ำแข็ง? |
| ใครนำนมมาส่งถึงหน้าบ้านในขวดแก้ว? | คนส่งจดหมาย, **คนส่งนม**, คนส่งหนังสือพิมพ์ | ยังมีอะไรอีกที่ส่งมาถึงบ้าน? |
| คุณโทรโทรศัพท์แบบหมุนเลขอย่างไร? | กดปุ่ม, **หมุนวงล้อ**, พูดกับมัน | เล่าให้ฟังเกี่ยวกับโทรศัพท์ในบ้านของคุณ |
| บริษัทไหนผลิตรถยนต์รุ่น Model T? | **ฟอร์ด**, เชฟโรเลต, บูอิก | เล่าให้ฟังเกี่ยวกับรถที่คุณชอบ |
| จะพบคนทำเครื่องดื่มโซดาได้ที่ไหน? | **ร้านเครื่องดื่มโซดา**, ร้านเบเกอรี่, ธนาคาร | คุณสั่งอะไรที่เคาน์เตอร์? |
| ของเล่นอะไรเป็นสปริงโลหะที่เดินลงบันไดได้? | โย-โย, **สลิงกี้**, ห่วงฮูลา | ตอนเด็กคุณชอบของเล่นอะไร? |
| ไดรฟ์อินเป็นที่สำหรับดู... | **ภาพยนตร์จากในรถ**, เกมกีฬา, ขบวนพาเหรด | คุณไปกับใคร? |
| ใบหน้าของใครอยู่บนธนบัตรหนึ่งดอลลาร์? | ลิงคอล์น, **จอร์จ วอชิงตัน**, เจฟเฟอร์สัน | สมัยก่อนหนึ่งดอลลาร์ซื้ออะไรได้บ้าง? |
| ใบหน้าของใครอยู่บนเหรียญเพนนี? | **อับราฮัม ลิงคอล์น**, วอชิงตัน, แฟรงคลิน | สมัยก่อนคุณเก็บเหรียญเพนนีไว้ในไหไหม? |
| รถบัสโรงเรียนมักมีสีอะไร? | แดง, **เหลือง**, น้ำเงิน | คุณไปโรงเรียนอย่างไร? |

## วันสำคัญ ธรรมชาติ และสถานที่

| คำถาม | ตัวเลือก | ประเด็นสนทนา |
| --- | --- | --- |
| วันสำคัญวันไหนตรงกับวันพฤหัสบดีที่สี่ของเดือนพฤศจิกายน? | วันแรงงาน, **วันขอบคุณพระเจ้า**, วันรำลึกทหารผ่านศึก | บนโต๊ะของคุณมีอะไรอยู่เสมอ? |
| ฟักทองแกะสลักทำขึ้นสำหรับวันสำคัญวันไหน? | **วันฮาโลวีน**, วันอีสเตอร์, วันคริสต์มาส | เล่าให้ฟังเกี่ยวกับวันฮาโลวีนตอนคุณโตขึ้น |

| ฤดูไหนมาหลังฤดูหนาว? | ฤดูใบไม้ร่วง, **ฤดูใบไม้ผลิ**, ฤดูร้อน | ฤดูกาลที่คุณชอบที่สุดคือฤดูไหน? |

## คำพูดติดปากที่คุ้นเคย

การเติมคำพูดติดปากให้จบดึงเอาภาษาที่เรียนรู้มานาน และมักทำได้ง่าย เกม [เติมคำพูดให้จบ](/games/finish-the-saying/) ของเรามีอีกมากมาย เพียงแตะก็เห็นตอนจบได้

| คำพูด | ตัวเลือก | ประเด็นสนทนา |
| --- | --- | --- |
| แอปเปิลวันละผลช่วยให้... | **หมอห่างไกล**, ฝนห่างไกล, แมวห่างไกล | ใครเคยพูดอย่างนี้ให้คุณฟัง? |
| นกที่ตื่นเช้ากับได้... | รถบัส, **หนอน**, รถไฟ | คุณเป็นคนตื่นเช้าไหม? |
| อย่านับลูกไก่ก่อนที่มันจะ... | **ฟักออกมา**, นอน, ร้อง | ครอบครัวคุณเลี้ยงไก่ไหม? |
| เพนนีที่เก็บไว้คือเพนนีที่... | **ได้มา**, หายไป, ใช้ไป | ใครในครอบครัวคุณเป็นคนเก็บเงิน? |
| บ้านคือที่ที่... | สวนอยู่, **หัวใจอยู่**, ครัวอยู่ | อะไรทำให้สถานที่หนึ่งรู้สึกเหมือนบ้าน? |
| ช้าก็ยังดีกว่า... | เร็ว, **ไม่ทำเลย**, ขอโทษ | ใครในครอบครัวชอบมาสายเสมอ? |
| ก้อนเมฆทุกก้อนมี...สีเงิน | **ขอบ**, ช้อน, เหรียญ | เล่าให้ฟังเกี่ยวกับโชคดีครั้งหนึ่ง |
| การกระทำพูดได้ดังกว่า... | **คำพูด**, ดนตรี, ฟ้าผ่า | เล่าให้ฟังเกี่ยวกับคนที่พูดอย่างนั้น |

## คำถามแบบอันนี้หรืออันนั้นที่ไม่มีคำตอบผิด

คำถามเหล่านี้เหมาะกับทุกระยะ รวมถึงระยะหลัง เพราะไม่มีอะไรต้องตอบให้ถูก ถาม ฟัง และแบ่งปันคำตอบของคุณเองด้วย

- กาแฟหรือชา?
- ทะเลหรือภูเขา?
- สุนัขหรือแมว?
- ฤดูร้อนหรือฤดูหนาว?
- พายหรือเค้ก?
- เต้นรำหรือดูคนอื่นเต้น?
- พระอาทิตย์ขึ้นหรือตก?
- ระเบียงหน้าบ้านหรือสวนหลังบ้าน?
- วิทยุหรือแผ่นเสียง?
- แพนเค้กหรือไข่?
- กุหลาบหรือเดซี่?
- เดินทางด้วยรถไฟหรือรถยนต์?

สำหรับประเด็นสนทนาที่ใช้คู่กับรูปภาพ ลองใช้ [การ์ดสนทนา](/games/conversation-cards/) ที่พิมพ์ได้ของเรา

## จะจัดเกมตอบคำถามในบ้านพักคนชราหรือกลุ่มอย่างไร

1. **จัดที่นั่งให้ทุกคนเห็นและได้ยิน** ใส่เครื่องช่วยฟัง สวมแว่นตา ปิดโทรทัศน์
2. **แนะนำเป็นการสนทนา** 'ฉันมีคำถามเกี่ยวกับสมัยก่อนอยู่บ้าง และฉันเชื่อว่าคุณรู้มากกว่าฉันอีกนะ'
3. **อ่านคำถามแต่ละข้อสองรอบและโชว์ตัวเลือกให้ใหญ่**
4. **ต้อนรับคำตอบจากทุกมุมของห้อง** ทวนคำตอบที่ดีให้ทุกคนได้ยิน
5. **บอกเฉลยให้ทุกคนฟัง** แล้วถามประเด็นสนทนาให้ทั้งห้อง
6. **ไปตามกระแส** ถ้าคำถามหนึ่งข้อทำให้เกิดเรื่องเล่ายาวสิบนาที ก็ปล่อยให้เป็นไปตามนั้น
7. **จบด้วยเพลงหรือรอบคำถามแบบอันนี้หรืออันนั้น** เพื่อให้ทุกคนจบด้วยสิ่งที่ง่าย

สำหรับรูปแบบกลุ่มอื่นๆ รวมถึงบิงโกภาพและการร้องเพลงด้วยกัน ดู [กิจกรรมกลุ่มสำหรับบ้านพักคนชรา](/activities/care-home-groups/)

## เมื่อไหร่ควรเปลี่ยนแผน

ถ้าใครดูวิตกกังวล เงียบไป หรือพูดว่า 'ฉันไม่รู้' มากกว่าหนึ่งครั้ง ให้ทำให้ง่ายขึ้น คือเหลือสองตัวเลือก ตอบด้วยกัน หรือเปลี่ยนไปใช้คำถามแบบอันนี้หรืออันนั้น ถ้ากลุ่มอยากคุยเรื่องคำถามหนึ่งข้อจนตลอดบ่าย นั่นก็ถือว่าสำเร็จ เป้าหมายไม่เคยเป็นคำตอบที่ถูกต้อง แต่คือช่วงเวลาที่ได้อยู่กับคนอื่นอย่างดี
