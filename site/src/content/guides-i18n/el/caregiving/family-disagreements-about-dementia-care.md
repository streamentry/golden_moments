Όταν ένα μέλος της οικογένειας έχει άνοια, οι συγγενείς μπορεί να διαφωνούν για την ασφάλεια, τη φροντίδα ή το μέλλον. Ένα άτομο μπορεί να βλέπει τις καθημερινές δυσκολίες, ενώ ένα άλλο μπορεί να επισκέπτεται λιγότερο συχνά ή να θυμάται το άτομο όπως ήταν πριν. Τα χρήματα, η απόσταση, η δουλειά και οι οικογενειακοί ρόλοι μπορούν να προσθέσουν πίεση. Η σύγκρουση είναι επώδυνη, αλλά από μόνη της δεν δείχνει ότι κάποιος νοιάζεται λιγότερο.

Ο [οδηγός της Alzheimer's Association για οικογενειακές συγκρούσεις](https://www.alz.org/help-support/caregiving/resolving-family-conflicts) προτείνει να ακούτε χωρίς κατηγορίες, να συζητάτε συγκεκριμένες φροντιστικές εργασίες και να επανέρχεστε στη συζήτηση καθώς αλλάζουν οι ανάγκες. Η [Dementia Australia](https://www.dementia.org.au/news/how-do-i-navigate-changes-my-relationships) σημειώνει επίσης ότι οι οικογένειες μπορεί να διαφωνούν για αποφάσεις φροντίδας και ότι μπορεί να χρειάζονται εξωτερική υποστήριξη. Αυτός ο οδηγός προσφέρει έναν τρόπο συζήτησης· δεν επιλύει νομικά θέματα εξουσιοδότησης και δεν αποφασίζει ποια φροντίδα είναι σωστή για ένα συγκεκριμένο άτομο.

## Πώς μπορούμε να κρατήσουμε το άτομο στο κέντρο;

Ρωτήστε το άτομο που ζει με άνοια τι έχει σημασία για εκείνο και πώς θέλει να συμμετέχει. Η διάγνωση δεν αφαιρεί τη θέση του στις συζητήσεις για την καθημερινή του ζωή. Ρωτήστε ποιους θέλει να συμπεριλάβετε και ποιες πληροφορίες νιώθει άνετα να μοιραστείτε. Αν θέλει βοήθεια για να εκφράσει μια προτίμηση, δώστε του χρόνο και συζητήστε μία επιλογή κάθε φορά.

Ο [οδηγός για τα πρώτα βήματα μετά τη διάγνωση](/caregiving/after-dementia-diagnosis/) έχει ιδέες για το πώς να εμπλέξετε το άτομο στον μελλοντικό σχεδιασμό. Αν το άτομο έχει επιλέξει κάποιον που θα το βοηθά με τις αποφάσεις, συμπεριλάβετε αυτό το πρόσωπο στη συζήτηση, σεβόμενοι την ιδιωτικότητα και τις επιθυμίες του ατόμου. Αν τα μέλη της οικογένειας διαφωνούν για το ποιος έχει νομική εξουσία αποφάσεων, ρωτήστε έναν αρμόδιο επαγγελματία της περιοχής αντί να μαντεύετε.

## Πώς να ξεκινήσουμε μια οικογενειακή συζήτηση;

Διαλέξτε μια ήρεμη στιγμή πριν από κρίση, όταν είναι δυνατόν. Αποφασίστε ένα θέμα για τη συζήτηση, όπως ποιος μπορεί να προσφέρει μεταφορές ή πώς θα κλειστεί το επόμενο ραντεβού. Μια μεγάλη λίστα δύσκολων αποφάσεων μπορεί να δυσκολέψει όλους να ακούσουν.

Πριν από τη συζήτηση, γράψτε τι έχετε δει και τι υποθέτετε. Για παράδειγμα, η φράση «ο μπαμπάς έχασε δύο ραντεβού αυτόν τον μήνα» είναι συγκεκριμένη παρατήρηση. Η φράση «ο μπαμπάς δεν μπορεί πια να κάνει τίποτα» είναι γενικό συμπέρασμα που ίσως δεν αντικατοπτρίζει τις ικανότητες ή τις προτιμήσεις του.

Δώστε σε κάθε άτομο την ευκαιρία να εξηγήσει τι τον ανησυχεί. Ακούστε χωρίς να διακόπτετε, χωρίς κατηγορίες και χωρίς να συγκρίνετε πόσο συνεισφέρει ο καθένας. Κάποιος που ζει μακριά μπορεί να μην βλέπει τις καθημερινές ανάγκες· κάποιος που φροντίζει τα περισσότερα μπορεί να είναι εξαντλημένος. Και οι δύο εμπειρίες έχουν σημασία, ακόμη κι όταν οδηγούν σε διαφορετικές απόψεις.

## Τι πρέπει να συζητήσουμε στη σύσκεψη;

Κρατήστε τη συζήτηση πρακτική. Μια σύντομη ατζέντα μπορεί να βοηθήσει την οικογένεια να φύγει με ένα σαφές επόμενο βήμα:

| Θέμα | Ερώτηση για συζήτηση |
| --- | --- |
| Οι επιθυμίες του ατόμου | Τι θέλει το άτομο να συνεχίσει να κάνει; Ποιους θέλει να συμμετέχουν; |
| Τι συμβαίνει τώρα | Τι παρατήρησε κάποιος και πότε; Τι χρειάζεται τη γνώμη ιατρού; |
| Εργασίες και όρια | Τι βοήθεια χρειάζεται; Ποιος έχει τον χρόνο και την ικανότητα για κάθε εργασία; |
| Επόμενα βήματα | Ποιος θα κάνει τι, μέχρι πότε, και πότε θα ξανασυναντηθείτε; |

Αν ένα θέμα χρειάζεται ιατρική συμβουλή, γράψτε την ερώτηση και ρωτήστε την ομάδα φροντίδας. Ο [οδηγός για την επίσκεψη στον γιατρό](/caregiving/doctor-visit-with-dementia/) μπορεί να βοηθήσει στην προετοιμασία αυτής της συζήτησης. Αφήστε θέματα που αφορούν νομικά έγγραφα, επιδόματα ή συμβόλαια σε εξειδικευμένους επαγγελματίες που γνωρίζουν τους τοπικούς κανόνες.

## Πώς μπορούμε να μοιράσουμε τις φροντιστικές εργασίες δίκαια;

Το δίκαιο δεν σημαίνει πάντα ίσο. Η [Alzheimer's Association προτείνει να φτιάξετε λίστα εργασιών που να περιλαμβάνει τον χρόνο, τα χρήματα και την προσπάθεια που απαιτούνται](https://www.alz.org/help-support/caregiving/resolving-family-conflicts). Έπειτα ρωτήστε τι προτιμά ο καθένας και τι μπορεί πραγματικά να κάνει.

Κάποιοι μπορεί να βοηθούν με τακτικές επισκέψεις ή προσωπική φροντίδα. Άλλοι μπορεί να είναι καταλληλότεροι για τον προγραμματισμό ραντεβού, τις μεταφορές, την παράδοση γεύματος, τα χαρτιά ή έναν εβδομαδιαίο έλεγχο. Ένας συγγενής που ζει μακριά μπορεί παρ' όλα αυτά να συντονίζει τηλεφωνήματα, να αναζητά τοπικές υπηρεσίες ή να κανονίζει εφόδια, αν το άτομο συμφωνεί. Ο [οδηγός για τη φροντίδα από απόσταση](/caregiving/long-distance-caregiving-with-dementia/) δίνει ένα πληρέστερο σχέδιο για ρόλους, ενημερώσεις και επισκέψεις.

Καταγράψτε τις συμφωνημένες εργασίες σε ένα κοινό ημερολόγιο ή σε γραπτή λίστα. Συμπεριλάβετε ποιος είναι υπεύθυνος, πόσο συχνά και ποιον να καλέσετε αν αλλάξουν τα σχέδια. Ξαναδείτε τη λίστα αν αλλάξει η υγεία, το εργασιακό πρόγραμμα ή η δυνατότητα φροντίδας κάποιου. Ο [οδηγός για την αυτοφροντίδα του φροντιστή](/caregiving/caregiver-self-care/) καλύπτει τρόπους να ζητάτε από άλλους να μοιράζονται τη φροντίδα.

## Τι μπορούμε να κάνουμε αν εξακολουθούμε να διαφωνούμε;

Επιστρέψτε σε όσα είναι γνωστά, σε όσα θέλει το άτομο και στο ερώτημα που μένει ανοιχτό. Μπορεί να μην λύσετε τα πάντα σε μία σύσκεψη. Συμφωνήστε σε μία ενέργεια που είναι ασφαλής και αποδεκτή για τώρα, και ορίστε χρόνο για να ξανασυζητήσετε τη μεγαλύτερη απόφαση.

Αν οι συγγενείς διαφωνούν για μια μετακόμιση, κάντε πρώτα βήμα τη συλλογή πληροφοριών αντί για ψηφοφορία ναι ή όχι. Ρωτήστε τι υποστήριξη λείπει στο σπίτι, τι θα προτιμούσε το άτομο και ποιες επιλογές θέλει να μάθει η οικογένεια. Μια επίσκεψη σε μονάδα φροντίδας ή μια συζήτηση με πάροχο υποστήριξης στο σπίτι μπορεί να τροφοδοτήσει τη συζήτηση χωρίς να δεσμεύσει το άτομο σε μετακόμιση. Ο [οδηγός για τις μονάδες φροντίδας](/caregiving/choosing-residential-dementia-care/) έχει ερωτήσεις για τη σύγκριση των επιλογών.

Αν η ένταση συνεχίζεται, ζητήστε τη βοήθεια ενός έμπιστου τρίτου. Ανάλογα με το θέμα, μπορεί να είναι ο γιατρός του ατόμου, ένας κοινωνικός λειτουργός, σύμβουλος, μεσολαβητής ή θρησκευτικός λειτουργός. Μια ομάδα υποστήριξης μπορεί επίσης να δώσει στους συγγενείς έναν χώρο για να μιλήσουν με ανθρώπους που περνούν παρόμοιες αλλαγές. Η επαγγελματική συμβουλή είναι ιδιαίτερα σημαντική για ιατρικά, νομικά ή οικονομικά ζητήματα.

Αν η οικογενειακή σύγκρουση επηρεάζει την ασφάλεια ή τη φροντίδα του ατόμου, επικοινωνήστε με μια αξιόπιστη τοπική υπηρεσία για βοήθεια. Μην αφήνετε το άτομο να βρεθεί στη μέση μιας διαμάχης. Αν υπάρχει άμεσος κίνδυνος, καλέστε τις τοπικές υπηρεσίες έκτακτης ανάγκης.

Οι οικογένειες δεν θα συμφωνούν πάντα, και μία συζήτηση μπορεί να μην λύσει το θέμα. Συνεχίστε να ακούτε το άτομο, κάντε σαφείς δεσμεύσεις και ζητήστε βοήθεια προτού ένας συγγενής αναλάβει μόνος όλο το βάρος.
