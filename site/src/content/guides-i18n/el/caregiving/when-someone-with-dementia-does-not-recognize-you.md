Αν ένα άτομο με άνοια δεν σας αναγνωρίζει πια, η στιγμή μπορεί να είναι επώδυνη και μπερδεμένη. Ίσως αναρωτιέστε τι να πείτε ή αν πρέπει να εξηγήσετε ξανά τη σχέση σας. Κάθε κατάσταση είναι διαφορετική. Ξεκινήστε με ό,τι φαίνεται να βοηθά το άτομο να νιώσει ασφαλές και άνετο, και όχι με ένα τεστ για το τι θυμάται.

Ο [οδηγός της Alzheimer's Association για τη μνήμη και τη σύγχυση](https://www.alz.org/help-support/caregiving/stages-behaviors/memory-loss-confusion) περιλαμβάνει τη μη αναγνώριση της οικογένειας μεταξύ των αλλαγών που μπορεί να συμβούν. Η [Dementia Australia](https://www.dementia.org.au/living-dementia/mood-and-behaviour-changes/hallucinations-and-delusions) και η [Alzheimer's Society](https://www.alzheimers.org.uk/about-dementia/stages-and-symptoms/how-dementia-changes-perception) εξηγούν ότι ένα άτομο μπορεί να περάσει για άλλον κάποιον που γνωρίζει. Αυτή είναι γενική καθοδήγηση· δεν μπορεί να εξηγήσει γιατί συμβαίνει μια συγκεκριμένη αλλαγή.

## Τι μπορεί να συμβαίνει όταν το άτομο δεν με αναγνωρίζει;

Η άνοια μπορεί να επηρεάσει τη μνήμη και τον τρόπο που ένα άτομο ερμηνεύει όσα βλέπει. Κάποιος μπορεί να σας περάσει για άλλο συγγενή ή να μην είναι σίγουρος πώς συνδέεστε. Αυτό δεν σας λέει ακριβώς τι νιώθει για εσάς. Επικεντρωθείτε στην άνεση και στην αντίδρασή του εκείνη τη στιγμή.

Η αναγνώριση μπορεί επίσης να επηρεαστεί από αμυδρό φωτισμό, προβλήματα όρασης ή ακοής, ασθένεια, παρενέργειες φαρμάκων, ένα άγνωστο μέρος ή μια αλλαγή ρουτίνας. Αυτοί είναι πιθανοί παράγοντες, όχι τρόπος να διαγνώσετε την αιτία. Αν η αλλαγή είναι νέα ή συνεχίζει να αναστατώνει το άτομο, πείτε στον κλινικό γιατρό του τι συνέβη και ρωτήστε αν πρέπει να εξεταστεί.

Αν ένας χώρος είναι σκοτεινός ή πολυσύχναστος, δοκιμάστε μία αλλαγή: ανάψτε ένα φως, μειώστε τον θόρυβο του παρασκηνίου ή μετακινηθείτε σε κάτι οικείο. Ρωτήστε αν το άτομο θέλει τα γυαλιά ή τα βοηθήματα ακοής του, αν τα χρησιμοποιεί. Αυτά τα βήματα μπορεί να βοηθήσουν, αλλά δεν θα εξηγήσουν κάθε περίπτωση μη αναγνώρισης.

## Τι μπορώ να πω τη στιγμή εκείνη;

Πλησιάστε εκεί όπου σας βλέπει το άτομο και μιλήστε με μια ήρεμη, οικεία φωνή. Πείτε το όνομά σας και τη σχέση σας απλά, όπως θα κάνατε όταν το συναντάτε σε άλλη ημέρα: «Γεια σας, είμαι η Ελένη, η κόρη σας.» Μετά κάντε μια παύση και παρατηρήστε την αντίδρασή του.

- **Αν φαίνεται άνετο,** συνεχίστε μια συνηθισμένη κουβέντα. Μιλήστε για ό,τι συμβαίνει τώρα ή ρωτήστε αν θα ήθελε να καθίσετε μαζί.
- **Αν φαίνεται αβέβαιο,** προσφέρετε μια σύντομη καθησυχαστική φράση: «Είναι εντάξει, είμαι εδώ μαζί σας.» Δώστε του χρόνο να απαντήσει.
- **Αν φαίνεται φοβισμένο ή σας ζητά να φύγετε,** κάντε ένα βήμα πίσω και δώστε του χώρο. Μην επιβάλλετε αγκαλιά, μην επιμένετε ότι πρέπει να σας αναγνωρίσει και μην επαναλαμβάνετε πληροφορίες που τον αναστατώνουν.
- **Αν σας αποκαλεί με άλλο όνομα,** μπορείτε να συστηθείτε μία φορά, χωρίς να το μετατρέψετε σε διόρθωση. Αν παραμένει άνετο, περάστε σε ένα θέμα ή μια δραστηριότητα που του αρέσει.

Ο [οδηγός επικοινωνίας](/caregiving/communication-tips/) συνιστά σύντομη, ήρεμη γλώσσα και αποφυγή ερωτήσεων ή διαμαχών. Προσπαθήστε να μην ρωτάτε: «Θυμάστε ποιος είμαι;» Η ερώτηση μπορεί να νιώθεται σαν τεστ και μπορεί να μην βοηθήσει το άτομο να σας αναγνωρίσει.

## Μπορεί μια οικεία ένδειξη να βοηθήσει;

Μερικές φορές μια ένδειξη μπορεί να βοηθήσει το άτομο να σας τοποθετήσει, αλλά δεν θα λειτουργήσει για όλους. Δοκιμάστε μία απαλή ένδειξη κάθε φορά και σταματήστε αν προσθέτει πίεση.

- **Πείτε το όνομά σας φυσικά.** Μια οικεία φωνή ή μια σύντομη σύσταση μπορεί να αρκεί.
- **Χρησιμοποιήστε μια φωτογραφία ή ένα κοινό αντικείμενο.** Αν το άτομο απολαμβάνει τις φωτογραφίες, μπορείτε να κοιτάξετε μία μαζί χωρίς να του ζητάτε να ονομάσει κάποιον. Ο [οδηγός μας για την ανάμνηση](/activities/reminiscence/) έχει ιδέες για τη χρήση φωτογραφιών χωρίς ερωτήσεις.
- **Δοκιμάστε μια συνηθισμένη κοινή δραστηριότητα.** Ένα οικείο τραγούδι, ένα ρόφημα ή μια συνηθισμένη εργασία μπορεί να κάνει τη στιγμή ευκολότερη. Ακολουθήστε την αντίδραση του ατόμου· είναι εντάξει να αλλάξετε θέμα ή να τελειώσετε την επίσκεψη.
- **Μειώστε τη σύγχυση γύρω του.** Ελέγξτε ότι ο χώρος έχει αρκετό φως και ότι το άτομο έχει τα γυαλιά ή τα βοηθήματα ακοής του, αν τα χρησιμοποιεί. Ένας πιο ήσυχος χώρος μπορεί να βοηθήσει, αν μιλούν πολλοί.

Μην συνεχίζετε να προσθέτετε ενδείξεις αν το άτομο παραμένει αναστατωμένο. Μια μακρά εξήγηση ή μια σειρά φωτογραφιών μπορεί να το επιβαρύνει. Η ήρεμη παρουσία σας μπορεί να αρκεί· είναι εντάξει και να κάνετε ένα διάλειμμα και να δοκιμάσετε ξανά άλλη φορά.

## Πώς μπορώ να κάνω τις επισκέψεις πιο εύκολες;

Αν το άτομο ζει σε μονάδα φροντίδας ή έχει πολλούς βοηθούς, ρωτήστε τους ανθρώπους που γνωρίζουν τη ρουτίνα του πότε αισθάνεται πιο άνετα. Μπορείτε να επισκεφθείτε σε πιο ήσυχη ώρα, να πάτε με κάποιον που τον αναγνωρίζει ή να φέρετε ένα οικείο αντικείμενο. Αυτές είναι επιλογές για εξέταση, όχι πρόγραμμα που πρέπει να ακολουθήσει κάθε οικογένεια.

Πριν από μια επίσκεψη, αποφασίστε τι θα ήταν διαχειρίσιμο και για εσάς. Μπορείτε να σχεδιάσετε μία σύντομη δραστηριότητα, να φέρετε ένα άλμπουμ φωτογραφιών ή απλώς να καθίσετε μαζί. Αν το άτομο δεν φαίνεται να ξέρει ποιος είστε, μπορείτε ακόμα να ανταποκριθείτε στις ανάγκες του εκείνη τη στιγμή. Μην κάνετε την επίσκεψη να εξαρτάται από το αν θα πει το όνομά σας.

Είναι κατανοητό να νιώθετε λύπη, απόρριψη ή απογοήτευση. Μιλήστε με κάποιον που εμπιστεύεστε, με έναν σύμβουλο ή σε ομάδα υποστήριξης φροντιστών αν η εμπειρία βαραίνει. Ο [οδηγός αυτοφροντίδας του φροντιστή](/caregiving/caregiver-self-care/) περιλαμβάνει τρόπους να ζητήσετε στήριξη από άλλους.

## Πότε πρέπει να ζητήσω ιατρική βοήθεια;

Αν η αδυναμία αναγνώρισης είναι νέο μοτίβο, συμβαίνει συχνά ή προκαλεί δυσφορία, πείτε στον γιατρό του ατόμου. Σημειώστε πότε συμβαίνει και τι άλλο συνέβαινε, όπως μια αλλαγή στην υγεία, τον ύπνο, τον φωτισμό, την ακοή, τα φάρμακα ή το περιβάλλον. Μην σταματάτε ή αλλάζετε φάρμακα με βάση ένα γενικό άρθρο.

Η ξαφνική σύγχυση ή μια απότομη αλλαγή στη συμπεριφορά ή την υγεία χρειάζεται επείγουσα ιατρική προσοχή. Το [οδηγός του NHS για ξαφνική σύγχυση](https://www.nhs.uk/symptoms/confusion/) λέει ότι πρέπει να ζητήσετε αμέσως ιατρική βοήθεια. Χρησιμοποιήστε το τοπικό σύστημα έκτακτης ή επείγουσας φροντίδας εκεί όπου ζει το άτομο.

Το να μην σας αναγνωρίζουν μπορεί να είναι δύσκολο και για τους δύο. Κρατήστε τα λόγια σας απλά, προσφέρετε μια ένδειξη μόνο όταν βοηθά και αφήστε την άνεση του ατόμου να καθορίζει τι θα γίνει στη συνέχεια.
