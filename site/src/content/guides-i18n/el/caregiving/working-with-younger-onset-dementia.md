Μια διάγνωση άνοιας κατά τη διάρκεια της εργασιακής ζωής μπορεί να εγείρει ερωτήματα για το εισόδημα, το απόρρητο, την ταυτότητα και την ασφάλεια. Μερικοί θέλουν να κρατήσουν τη σημερινή τους δουλειά, άλλοι εξετάζουν αλλαγές και άλλοι επιλέγουν να φύγουν. Δεν υπάρχει ένας δρόμος που ταιριάζει σε όλους. Οι προτιμήσεις σας, τα καθήκοντά σας, η υγεία σας και η υποστήριξη που έχετε έχουν όλα σημασία.

Ο [οδηγός της Alzheimer's Association για την άνοια με έναρξη σε νεαρή ηλικία](https://www.alz.org/help-support/i-have-alz/younger-onset) συζητά την εργασία, τα οικογενειακά οικονομικά και τα επιδόματα εργοδότη. Η [Dementia Australia](https://www.dementia.org.au/living-dementia/what-next-after-your-diagnosis/planning-ahead/work-and-dementia) και η [Alzheimer's Society](https://www.alzheimers.org.uk/get-support/living-with-dementia/work-dementia) περιγράφουν επιλογές για παραμονή στη δουλειά, αλλαγή ρόλου ή αποχώρηση. Οι κανόνες απασχόλησης διαφέρουν ανά τόπο, γι' αυτό αυτός ο οδηγός προσφέρει ερωτήματα προς εξέταση, όχι νομική ή οικονομική συμβουλή.

## Σημαίνει η διάγνωση ότι πρέπει να σταματήσω να εργάζομαι;

Όχι. Η διάγνωση από μόνη της δεν αποφασίζει αν μπορείτε να συνεχίσετε να εργάζεστε. Η [Alzheimer's Society εξηγεί](https://www.alzheimers.org.uk/get-support/living-with-dementia/work-dementia) ότι η απόφαση εξαρτάται από τα συναισθήματά σας, τη δουλειά σας και την προσωπική σας κατάσταση. Μερικοί συνεχίζουν στον ίδιο ρόλο, κάποιοι αλλάζουν καθήκοντα ή ώρες και κάποιοι φεύγουν από τη δουλειά.

Σκεφτείτε τι λειτουργεί και τι έχει γίνει δυσκολότερο. Μπορείτε να σημειώσετε ποια καθήκοντα νιώθετε οικεία, πότε κουράζεστε ή αποσπάτε την προσοχή σας και αν υπήρξαν συγκεκριμένα λάθη ή ανησυχίες ασφάλειας. Συγκεκριμένα παραδείγματα μπορούν να βοηθήσουν εσάς και τον κλινικό γιατρό σας να συζητήσετε τη δουλειά χωρίς να μετατρέπετε μια δύσκολη μέρα σε συμπέρασμα για την ικανότητά σας.

Η ασφάλεια έχει επίσης σημασία. Αν η δουλειά σας περιλαμβάνει οδήγηση, χειρισμό μηχανημάτων, φροντίδα άλλων ανθρώπων ή άλλο καθήκον με ευαίσθητη ασφάλεια, ρωτήστε τον κλινικό γιατρό σας πώς να εκτιμηθεί ο κίνδυνος. Τοπικοί νόμοι, επαγγελματικοί κανόνες και συμβάσεις εργασίας μπορεί επίσης να ισχύουν. Αυτός ο οδηγός δεν μπορεί να σας πει αν ένας συγκεκριμένος ρόλος είναι ασφαλής ή τι πρέπει να κάνει ο εργοδότης σας.

## Πώς μιλάω με τον κλινικό γιατρό μου για τη δουλειά;

Περιγράψτε τα καθήκοντα της δουλειάς σας και τις αλλαγές που έχετε παρατηρήσει. Ρωτήστε αν μια υγειονομική ανησυχία μπορεί να επηρεάσει συγκεκριμένο καθήκον, ποια σημάδια σημαίνουν ότι πρέπει να ζητήσετε βοήθεια και αν άλλος επαγγελματίας μπορεί να αξιολογήσει ένα καθήκον της δουλειάς. Μπορεί να θέλετε να φέρετε ένα έμπιστο πρόσωπο, αλλά αποφασίστε μαζί πώς μπορεί να σας στηρίξει χωρίς να μιλά εκ μέρους σας.

Ο [οδηγός για την επίσκεψη στον γιατρό](/caregiving/doctor-visit-with-dementia/) έχει τρόπους να προετοιμάσετε ερωτήσεις και σημειώσεις. Μπορείτε να ζητήσετε από τον κλινικό γιατρό να εξηγήσει τι μπορεί να αξιολογήσει και τι χρειάζεται ξεχωριστή αξιολόγηση χώρου εργασίας ή επαγγελματικής υγείας. Ένας γενικός οδηγός για την άνοια δεν μπορεί να αντικαταστήσει μια εξατομικευμένη εκτίμηση υγείας και ασφάλειας.

## Ποιες αλλαγές στη δουλειά μπορεί να βοηθήσουν;

Αν θέλετε να συνεχίσετε να εργάζεστε, ρωτήστε ποιες αλλαγές είναι δυνατές στον ρόλο σας. Η Dementia Australia προτείνει επιλογές όπως η χρήση ρουτίνας, η εστίαση σε ένα καθήκον τη φορά, η λήψη σημειώσεων και η δημιουργία βήμα προς βήμα οδηγού για συνηθισμένες εργασίες. Ανάλογα με τη δουλειά σας, μπορείτε επίσης να ρωτήσετε για γραπτές οδηγίες, ένα ημερολόγιο, λιγότερες διακοπές ή προγραμματισμένα διαλείμματα.

Αντιμετωπίστε αυτές τις επιλογές ως ιδέες προς συζήτηση, όχι ως λίστα ελέγχου που κάθε εργοδότης μπορεί ή πρέπει να εφαρμόσει. Επιλέξτε μία αλλαγή που αντιμετωπίζει ένα καθήκον που βρίσκετε δύσκολο. Αν εσείς και ο εργοδότης σας τη δοκιμάσετε, συμφωνήστε πώς θα την αξιολογήσετε και αν βοηθά. Μια αλλαγή που λειτουργεί για έναν ρόλο μπορεί να μην ταιριάζει σε άλλον.

## Πρέπει να το πω στον εργοδότη μου;

Εσείς αποφασίζετε ποιες προσωπικές πληροφορίες θα μοιραστείτε, εκτός αν ισχύει τοπικός νόμος, σύμβαση ή απαίτηση ασφάλειας για τον ρόλο σας. Οι απαιτήσεις διαφέρουν ανά χώρα, πολιτεία και θέση εργασίας. Πριν αποφασίσετε, ελέγξτε τη σύμβασή σας, την πολιτική του χώρου εργασίας και τις τοπικές οδηγίες. Αν δεν είστε σίγουροι, μιλήστε με έναν έγκυρο σύμβουλο εργασίας, εκπρόσωπο συνδικάτου ή δικηγόρο που γνωρίζει τους κανόνες στην περιοχή σας.

Αν αποφασίσετε να το πείτε σε κάποιον, σκεφτείτε τι θέλετε να γνωρίζει και τι υποστήριξη ζητάτε. Μπορεί να προτιμάτε να μιλήσετε πρώτα με έναν έμπιστο προϊστάμενο ή με το τμήμα ανθρώπινου δυναμικού. Ρωτήστε πώς θα χειριστούν τις πληροφορίες σας και ποιος θα τις λάβει· μην υποθέτετε ότι κάθε χώρος εργασίας έχει την ίδια διαδικασία απορρήτου.

Ορισμένες δουλειές περιλαμβάνουν καθήκοντα ευαίσθητα στην ασφάλεια. Αν δεν είστε σίγουροι αν πρέπει να σταματήσετε ή να αλλάξετε ένα τέτοιο καθήκον, επικοινωνήστε άμεσα με τον κλινικό γιατρό σας και με έναν έγκυρο τοπικό σύμβουλο εργασίας. Μην βασίζεστε σε έναν γενικό οδηγό για να αποφασίσετε αν ένα συγκεκριμένο καθήκον είναι ασφαλές.

## Ποια επιδόματα και οικονομικά ζητήματα πρέπει να ελέγξω;

Πριν αλλάξετε ώρες ή φύγετε από τη δουλειά, ελέγξτε τα επιδόματα που προσφέρει ο εργοδότης σας. Ρωτήστε το τμήμα ανθρώπινου δυναμικού ή τον υπεύθυνο παροχών για άδειες, επιδόματα αναπηρίας ή εισοδήματος, κάλυψη υγείας και προθεσμίες. Ζητήστε τους τρέχοντες κανόνες γραπτώς και κρατήστε ένα αντίγραφο των πληροφοριών που λαμβάνετε.

Η επιλεξιμότητα, οι φόροι και ο χρονισμός εξαρτώνται από τον εργοδότη σας, την ασφαλιστική πολιτική και την τοποθεσία. Η [Alzheimer's Association συμβουλεύει να ελέγχετε τα επιδόματα εργοδότη και να κρατάτε γραπτή επιβεβαίωση](https://www.alz.org/help-support/i-have-alz/younger-onset). Για τη δική σας απόφαση, μιλήστε με έναν έγκυρο σύμβουλο παροχών ή οικονομικών που μπορεί να εξετάσει τα έγγραφα που σας αφορούν. Μην υπογράφετε ούτε τερματίζετε κάλυψη βασιζόμενοι μόνο σε ένα γενικό άρθρο.

Η οικογένειά σας μπορεί επίσης να επηρεαστεί από αλλαγή εισοδήματος ή προγράμματος. Αν θέλετε, μιλήστε με τους ανθρώπους που εμπιστεύεστε για το τι έχει μεγαλύτερη σημασία και ποιες επιλογές θέλετε να εξερευνήσετε. Ο [οδηγός για τα πρώτα βήματα μετά τη διάγνωση](/caregiving/after-dementia-diagnosis/) καλύπτει ευρύτερη υποστήριξη και ερωτήματα για τον σχεδιασμό του μέλλοντος.

## Τι γίνεται αν αποφασίσω να μειώσω τις ώρες ή να φύγω;

Η αποχώρηση από τη δουλειά μπορεί να είναι η σωστή επιλογή για κάποιους. Δεν σημαίνει ότι αποτύχατε. Μπορεί να σκεφτείτε το εισόδημα, την κάλυψη υγείας, την καθημερινή ρουτίνα και τους ανθρώπους που θα σας λείπει να βλέπετε. Ρωτήστε για τοπική υποστήριξη πριν κάνετε μια αλλαγή και δώστε στον εαυτό σας χρόνο να συγκρίνει τις επιλογές που έχουν σημασία για εσάς.

Η δουλειά είναι μόνο ένα μέρος της ζωής. Αν μειώσετε ώρες ή φύγετε, επιλέξτε άλλες δραστηριότητες ή σχέσεις που σας φαίνονται άξιες όταν είστε έτοιμοι. Τα μέλη της οικογένειας μπορούν να προσφέρουν βοήθεια, αλλά η απόφαση πρέπει να σας περιλαμβάνει. Ο [οδηγός αυτοφροντίδας του φροντιστή](/caregiving/caregiver-self-care/) έχει ιδέες για το πώς να ζητάτε από άλλους να μοιράζονται τη στήριξη, χωρίς να φορτώνεται όλη η ευθύνη σε έναν άνθρωπο.
