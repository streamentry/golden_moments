認知症になると、言葉を見つけること、長い文を理解すること、周りの音を遮ることが難しくなることがあります。それは、その方が人とつながりたい気持ちをなくしたという意味ではありません。会話の場の整え方、話し方、聞き方を少し変えるだけで、おふたりにとって会話が楽に、穏やかになります。

## 認知症の方と話すとき、いちばん大切なコツは何ですか？

注意を向けてもらい、シンプルに、そして辛抱強く。5つだけ覚えるなら、次のとおりです。

1. **部屋を静かにして、顔を見る。** テレビを消し、目の高さに座り、お名前を呼びます。
2. **一度にひとつのことを言う。** 短い文で、ひとつの内容、ひとつの質問を。
3. **二択にする。**「お茶とコーヒー、どちらにしましょうか？」は、「何がいいですか？」より答えやすいものです。
4. **待つ。** 自然に感じるより長く答えを待ち、できるだけ遮らないようにしましょう。
5. **言い争ったり、問いただしたりしない。** 事実が正しいかではなく、どう感じているかに応えましょう。

## 会話は、どう始めればいいですか？

ご本人があなたに集中できるように整えましょう。[米国家族介護者連盟のガイド](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)は、まず騒音を減らすよう勧めています。ラジオやテレビを消す、カーテンやドアを閉める、静かな場所に移る、などです。

- **正面から近づく。** 後ろや横から来ると、驚かせてしまうことがあります。
- **自分が誰かを伝える。**「お父さん、娘の沙織です」。これで、名前を思い出そうと探さずにすみます。
- **目の高さに合わせる。** ご本人が座っているなら、あなたも座るか膝をついて、目の高さをそろえましょう。
- **表情と声のトーンを確かめる。**[米国国立老化研究所（NIA）](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/communicating-someone-who-has-alzheimers)は、声のトーン、大きさ、表情、体の動きに気を配り、あたたかく、落ち着いた態度を心がけるよう勧めています。
- **眼鏡と補聴器をつけているか確かめる。** 十分に見えない、聞こえない状態で、会話についていくのは大変です。

## 話す内容は、どう言えばいいですか？

やさしい言葉、短い文、落ち着いた低めの声を使いましょう。

- **1つの文にひとつの内容。**「コートを着ましょう。そのあと外に出ましょう」。2つを一度に言わないようにします。
- **「あの人」ではなく名前を。**「洋子おばさんから電話があったよ」のほうが、「あの人から電話があったよ」よりわかりやすくなります。
- **大きくではなく、低く。** 米国家族介護者連盟は、声を張り上げるより、低い声を勧めています。
- **繰り返し、それから言い換える。** 伝わらなかったら、同じ言葉を一度繰り返します。それでだめなら、少し待って、別の言葉で言ってみましょう。
- **言うだけでなく、見せる。** カップを指さす、2枚のセーターを見せる、最初の手順をやってみせる。
- **本人に向かって話し、本人のことを話さない。** NIAは、その場にいないかのように本人のことを話すこと、そして「赤ちゃん言葉」を使うことに注意を促しています。

NIAは、よくある質問をよりシンプルにした形を勧めています。その趣旨に沿った例を挙げます。

| こう言う代わりに | こう言ってみる |
| --- | --- |
| 「夕食は何がいいですか？」 | 「魚と鶏肉、どちらがいいですか？」 |
| 「ご気分はいかがですか？」 | 「疲れていますか？」 |
| 「おなかはすいていますか？」 | 「夕食は5分でできますよ」 |
| 「そのやり方では違いますよ」 | 「こんなふうにやってみましょうか」 |
| 「あの湖への旅行、覚えていますか？」 | 「あの湖への旅行のことを思い出していました。どこが楽しかったか、聞かせてください」 |
| 「さっきも言いましたよ」 | 初めてのことのように、やさしく、もう一度答える。 |

## 上手に聞くには？

言葉だけでなく、意味と気持ちに耳を傾けましょう。

- **待つ。** 沈黙は、考える時間であることがよくあります。口をはさむ前に、ゆっくり10数えましょう。
- **言葉に詰まったときだけ、言葉を添える。** 米国家族介護者連盟は、困っているときに言葉を示すのはかまわないとしています。
- **聞いたことを確かめる。**[米国アルツハイマー病協会のコミュニケーションのガイド](https://www.alz.org/help-support/caregiving/daily-care/communications)は、言葉の奥にある意味を探し、それを言い直して、理解できているか確かめるよう勧めています。「車のことが心配なのですね？」
- **表情と体を見る。** NIAは、話すことが難しくなるにつれ、悲しみ、怒り、いら立ちが、言葉よりも表情にはっきり表れることがあると述べています。
- **気がかりを真剣に受け止める。** 心配の元が間違った事実であっても、その気持ちは本物です。

## 事実と違うことを言ったときは？

言い争わないでください。勝てる見込みは低く、ご本人が恥ずかしい思いをしたり、怖がったりしかねません。かわりに、気持ちに寄り添い、それからそっと話題を移しましょう。

米国家族介護者連盟は、気持ちの切り替えの前に、まずその感情を受け止めるよう勧めています。たとえば、お母さんが子どもを学校に迎えに行かなければと言い張る場合：

- 避けたい言い方：「お母さん、子どもたちはもう大人よ。40年も前のことでしょう」
- こう言ってみる：「お母さんは、いつも子どもたちのことを思いやっていたものね。お迎えのこと、聞かせて。まずおやつにしましょうか？」

米国アルツハイマー病協会も、同意できない発言について言い争わないよう勧めています。場面を選びましょう。害のない思い込みなら、そのままにしておいてかまいません。

## 認知症が進むと、コミュニケーションはどう変わりますか？

必要なことは時間とともに変わるので、対応も調整しましょう。米国アルツハイマー病協会は、大きく3つの段階を説明しています。

| 段階 | 助けになること |
| --- | --- |
| 初期 | 話せないと決めつけない。会話に加え、直接話しかけ、どんな支援がほしいか尋ね、役立つならユーモアも使う。 |
| 中期 | 静かな場所での一対一の会話。ゆっくり話し、目を合わせ、「はい・いいえ」で答えられる質問にし、一つずつ手順を伝え、批判や訂正をしない。 |
| 後期 | 正面から近づき、自分が誰かを伝える。指さしや身ぶりをうながす。ふれる、音、見るもの、においを使う。その場にいないかのように話さない。 |

人はそれぞれ違い、同じ方でも調子の良い日と難しい日があります。ラベルではなく、今のご本人のようすに応えましょう。

## 絵や活動で会話がしやすくなりますか？

はい。いっしょに見る絵は、プレッシャーを和らげ、ふたりで見て、指さすものになります。

- **絵のきっかけ。**[会話カード](/games/conversation-cards/)は、問いただすことのない、自由に答えられる質問のついた絵を用意しています。
- **家族の写真。**[写真合わせ](/games/photo-pairs/)は、ご自身で選んだ写真をやさしい神経衰弱のようなゲームにし、思い出話のきっかけになることがよくあります。
- **なじみのことわざ。**[ことわざの続き](/games/finish-the-saying/)は、よく知られたことわざのあとに、話のきっかけになる問いかけが続きます。
- **背景としての絵合わせ。**[絵合わせ](/games/picture-pairs/)は、おしゃべりをしながら、手を動かせます。

ほかにも、[いっしょにゲームを楽しむコツ](/caregiving/how-to-play-together/)と[回想のレクリエーション](/activities/reminiscence/)をご覧ください。訪問や通話については、[訪問](/activities/visiting/)と[電話・ビデオ通話](/activities/phone-and-video-calls/)のガイドをお読みください。

## 我慢できなくなったら？

誰にでも起こることです。NIAは、いら立ちを感じたら、気持ちを落ち着ける時間をとるよう勧めています。別の部屋に移り、ゆっくり数回呼吸して、落ち着いたら戻りましょう。会話はいつでもやり直せますし、あなたが落ち着いた気分でいれば、ご本人もそれに応えてくれるかもしれません。いら立ちが常になっているなら、それはあなたがだめだからではなく、もっと支えが必要だというサインです。[介護者のセルフケア](/caregiving/caregiver-self-care/)のガイドに、頼れる先があります。
