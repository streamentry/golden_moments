認知症があると、言葉を見つけたり、長い文の流れを追ったり、周りの雑音を気にせず集中したりすることが難しくなる場合があります。それは、相手の方が人とつながりたいという気持ちを失ったという意味ではありません。会話の場を整え、話し方や聴き方を少し工夫するだけで、お互いにとって話しやすく、落ち着いた時間になりやすくなります。

## 認知症のある方と話すとき、いちばん大切なポイントは何ですか。

注意を向けてもらい、かんたんに伝え、待ちましょう。覚えておくことが五つだけだとしたら、次のことです。

1. **部屋を静かにして、正面に座る。** テレビを消し、目の高さを合わせて、名前を呼びましょう。
2. **一度にひとつのことを話す。** 短い文で、ひとつの内容、ひとつの質問にしましょう。
3. **二つの選択肢を示す。** 「何が飲みたいですか？」よりも、「お茶とコーヒー、どちらがよいですか？」の方が答えやすいです。
4. **待つ。** 思っているより長く返事を待ち、途中で言葉をさえぎらないようにしましょう。
5. **言い争ったり、問い詰めたりしない。** 事実が正しいかどうかよりも、相手の方がどんな気持ちかに応えましょう。

## 会話はどのように始めればよいですか。

相手の方があなたに意識を向けやすいように、環境を整えましょう。[Family Caregiver Alliance のガイド](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)では、まず周りの音を減らすことが勧められています。ラジオやテレビを消したり、カーテンやドアを閉めたり、もっと静かな場所へ移動したりしてみましょう。

- **正面から近づく。** 後ろや横から声をかけると、驚かせてしまうことがあります。
- **自分が誰かを伝える。** 「お父さん、こんにちは。娘のさくらです」のように伝えると、相手の方が名前を思い出そうとする負担が少なくなります。
- **目の高さを合わせる。** 相手の方が座っているなら、あなたも座るか、ひざまずいて目線を合わせましょう。
- **表情と声の調子に気をつける。** [National Institute on Aging（NIA）](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/communicating-someone-who-has-alzheimers)は、声の調子や大きさ、表情、身ぶりに気を配り、あたたかく落ち着いた話し方を心がけるよう助言しています。
- **眼鏡や補聴器を確認する。** よく見えなかったり聞こえなかったりすると、会話についていくことが難しくなります。

## どのような言い方をすればよいですか。

かんたんな言葉、短い文、落ち着いた低めの声で話しましょう。

- **一文にひとつの内容を。** 「上着を着ましょう。それから外に出ましょう」と分けて伝えます。ひと息にまとめて言わないようにしましょう。
- **代名詞ではなく名前を使う。** 「彼女から電話がありました」よりも、「洋子さんから電話がありました」の方がわかりやすいです。
- **大きな声より、低めの声で。** Family Caregiver Alliance は、声を張り上げるよりも、低めの声で話すことを勧めています。
- **繰り返してから、言い換える。** 伝わらなかったときは、まず同じ言葉をもう一度繰り返しましょう。それでも難しければ、少し間を置いて別の言葉で伝えてみましょう。
- **言葉だけでなく、見せる。** カップを指さしたり、セーターを二枚見せたり、最初の手順を実際にやって見せたりしましょう。
- **その方に向かって話す。** NIA は、その方がいないかのようにほかの人と話したり、子ども扱いするような話し方をしたりしないよう注意しています。

NIA は、よくある質問をよりかんたんな言い方にする例を示しています。ここでは、その考え方に沿った例を紹介します。

| 言い方を変える前 | 言い方を変えた例 |
| --- | --- |
| 「夕食は何が食べたいですか？」 | 「お魚と鶏肉、どちらが食べたいですか？」 |
| 「気分はどうですか？」 | 「疲れていますか？」 |
| 「お腹は空いていますか？」 | 「あと五分で夕食の準備ができますよ。」 |
| 「そのやり方は違います。」 | 「こうやってみましょう。」 |
| 「湖への旅行を覚えていますか？」 | 「湖への旅行のことを思い出していました。どんなところが楽しかったですか？」 |
| 「もう言いましたよ。」 | 初めて聞かれたかのように、やさしくもう一度答える。 |

## うまく聴くにはどうすればよいですか。

言葉そのものだけでなく、その意味や気持ちに耳を傾けましょう。

- **待つ。** 沈黙は、考えている時間かもしれません。口を挟む前に、心の中でゆっくり十まで数えてみましょう。
- **言葉に詰まっているときだけ助ける。** Family Caregiver Alliance によると、相手の方が困っているときに言葉をそっと添えることは問題ありません。
- **受け取った内容を確かめる。** [Alzheimer's Association のコミュニケーションガイド](https://www.alz.org/help-support/caregiving/daily-care/communications)では、言葉の裏にある意味をくみ取り、自分の理解が合っているか確かめるために言い換えて返すことが勧められています。「車のことが心配なんですね？」のようにたずねてみましょう。
- **表情や身ぶりに目を向ける。** 言葉が出にくくなるにつれて、NIA が述べているように、悲しみ、怒り、いらだちなどの気持ちが言葉よりも表情に表れることがあります。
- **心配ごとを大切に受け止める。** 心配のもとになっている事実が間違っていても、その気持ちは本物です。

## 事実と違うことを言ったときはどうすればよいですか。

言い争わないようにしましょう。相手の方の考えを変えられることはほとんどなく、恥ずかしさや不安を感じさせてしまうことがあります。その代わりに、気持ちに寄り添い、やさしく話題を移しましょう。

Family Caregiver Alliance は、話を切り替える前にまず感情を受け止めることを勧めています。たとえば、お母様が「学校に子どもを迎えに行かなければ」と言った場合は、次のように声をかけてみましょう。

- 言い方を変える前：「お母さん、子どもたちはもう大人よ。四十年も前のことよ。」
- 言い方を変えた例：「お母さんはいつも子ども思いだったね。迎えに行っていたころのこと、聞かせて。先におやつにしようか。」

Alzheimer's Association も、自分とは違う考えを言われたときに言い争わないよう助言しています。大切なのは場面を見極めることです。間違った思い込みが害のないものであれば、そのままにしておきましょう。

## 認知症が進むと、コミュニケーションはどう変わりますか。

時間とともに必要な支えは変わるため、関わり方も調整していきましょう。Alzheimer's Association は、大きく三つの段階に分けて説明しています。

| 段階 | 役立つ工夫 |
| --- | --- |
| 初期 | コミュニケーションが取れないと思い込まない。会話に加え、直接話しかけ、どんな支えがほしいかたずねる。合う場合は、ユーモアも役立つことがある。 |
| 中期 | 静かな場所で一対一で話す。ゆっくり話し、目を合わせ、「はい」「いいえ」で答えられる質問をし、手順を一つずつ伝える。批判したり訂正したりしない。 |
| 後期 | 正面から近づき、自分が誰かを伝える。指さしや身ぶりを促す。触れること、音、見えるもの、においを活用する。その方がいないかのように話さない。 |

一人ひとり違いがあり、同じ方でも調子のよい日とそうでない日があります。決まった型にはめず、今の相手の方の様子に合わせて関わりましょう。

## 写真や活動は、会話の助けになりますか。

はい。写真などを一緒に見ることで、話すことへの負担が軽くなり、二人で同じものを見たり指さしたりしやすくなります。

- **写真を使った声かけ。** [Conversation Cards](/games/conversation-cards/) には、問い詰めない開かれた質問付きの写真があります。
- **家族の写真。** [Photo Pairs](/games/photo-pairs/) は、選んだ写真を使ったやさしい神経衰弱で、思い出話につながることがよくあります。
- **なじみのあることわざ。** [Finish the Saying](/games/finish-the-saying/) は、よく知られたアメリカのことわざを使い、そのあとで話すきっかけを提供します。
- **会話の土台になる合わせゲーム。** [Picture Pairs](/games/picture-pairs/) は、話しながら手を動かせる活動です。

詳しくは、[一緒にゲームを楽しむ方法](/caregiving/how-to-play-together/)や[回想の活動](/activities/reminiscence/)をご覧ください。面会や電話・ビデオ通話については、[面会](/activities/visiting/)や[電話・ビデオ通話](/activities/phone-and-video-calls/)のガイドも参考になります。

複数の言語を使ってきた方については、[言語をまたいだコミュニケーションのガイド](/caregiving/language-and-dementia-communication/)をご覧ください。

## いらだってしまったときはどうすればよいですか。

誰にでもあることです。NIA は、いらだちを感じたときは、落ち着くための時間を取るよう勧めています。別の部屋に移動し、ゆっくり深呼吸をして、落ち着いてから戻りましょう。会話はいつでもやり直せますし、あなたの落ち着いた様子に相手の方も応えてくれるかもしれません。いらだちが続くようになったときは、あなたがうまくできていないということではなく、もっと支えが必要だというサインです。[介護する方のセルフケア](/caregiving/caregiver-self-care/)のガイドに、頼れる場所をまとめています。
