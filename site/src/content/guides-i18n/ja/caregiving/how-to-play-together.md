認知症のある方との良いゲームは、勝負のようには見えません。二人が寄り添って座り、絵を指さし、ことわざに笑い、思いついたことをあれこれ話している。そんなふうに見えます。ゲームは、いっしょに過ごすためのきっかけにすぎません。

このガイドでは、準備の仕方、ゲームのペースの合わせ方、何かが「うまくいかない」ときにかける言葉、どんなゲームでもやさしくしたり少し難しくしたりする方法、会話につなげる方法、そしてやめどきの見極め方を紹介します。このサイトの[ゲーム](/games/)にも、お手持ちのトランプ、パズル、ボードゲームにも使えます。

## 認知症のある方とゲームをするいちばん良い方法は？

何かを達成することではなく、楽しむことに目を向けましょう。これが[レクリエーションについての米国アルツハイマー病協会のガイダンス](https://www.alz.org/help-support/caregiving/daily-care/activities)の中心となるアドバイスです。ご本人が今も持っている技能を生かし、始めるのを手伝い、難しいところはあなたが仕上げ、害のないことを批判したり正したりしないこと。

実際には、次のようなことです。

- **向かい合わずに、隣に座る。** 隣に並べば、二人とも画面やテーブルが見え、手助けも見張りではなくチームワークのように感じられます。
- **一度に勧めるゲームはひとつだけ。** 選択肢がずらりと並ぶと、始まる前からテストのように感じられることがあります。
- **ご本人に合わせる。** 自分の好きな順番で絵をタップしたい、一枚の絵について十分間話したい、二回やったらやめたい。それが今日のゲームです。
- **終わった回数ではなく、良いひとときを数える。** 笑顔、思い出話、落ち着いた三十分。それこそが目指す結果です。

## 始める前に、どんな準備をすれば良いですか？

数分の準備で、ゲームそのもののせいにされがちないら立ちのほとんどを防げます。

1. **調子のいちばん良い時間帯を選ぶ。** [レクリエーションの工夫についての米国国立老化研究所（NIA）のガイダンス](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)は、お出かけやレクリエーションは、ご本人の調子がいちばん良い時間帯に計画するよう勧めています。多くの方にとっては午前中の半ばです。夕方は難しくなることが多いので、[夕方に落ち着いて過ごすためのレクリエーション](/caregiving/late-day-restlessness/)もご覧ください。
2. **部屋を静かにする。** テレビやラジオを消し、できればドアを閉めましょう。[米国家族介護者連盟（Family Caregiver Alliance）](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)は、話しかける前に騒音や気が散るものを減らすよう勧めています。
3. **まず快適さを確かめる。** 手の届くところに飲み物、始める前にトイレ、座り心地の良い椅子、そして眼鏡と補聴器。
4. **部屋を明るくする。** 画面に照り返しのない、明るくむらのない光だと、絵が見やすくなります。
5. **座る前にゲームの準備をしておく。** ゲームを開き、設定を選び、音量を合わせるのはあなたが。それから画面をご本人のほうへ向けましょう。タブレットのコツは、[タブレットやスマートフォンの設定](/caregiving/tablets-and-screens/)をご覧ください。
6. **機器を立てておく。** タブレットを立てておけるスタンドやケースがあれば、誰も持たなくてすみ、指さしもしやすくなります。

## プレッシャーをかけずに誘うには？

気軽に、断りやすい形で誘いましょう。受け入れられやすい言い方の例です。

- 「庭の絵を見つけたんです。いっしょに見ませんか？」
- 「このパズル、手伝ってもらえますか？行き詰まってしまって。」
- 「今日はお花と鳥、どちらにしましょうか？」（自由に答える質問より、二択のほうが答えやすくなります）
- 「妹さんにカードをつくっているんです。ここは何色が良いでしょう？」

米国アルツハイマー病協会は、友人へのカードづくりのように、レクリエーションの目的を伝えることを勧めています。理由があると、意味が生まれるからです。手伝いをお願いするのも、ご本人が役に立っていると感じられるので、うまくいきます。

断られたら、受け入れましょう。時間をおいてもう一度誘うか、別のものを勧めます。[断られたときにどうするか](/caregiving/when-they-say-no/)のガイドで、さらに詳しく紹介しています。

## ゲームの長さはどのくらいで、どんなペースで進めれば良いですか？

ペースはご本人に任せ、短い時間を想定しておきましょう。いっしょに遊ぶゲームの理想的な長さについて、根拠に基づく答えはありません。落ち着いた二〜五分でも、立派なひとつのレクリエーションです。

- **自然に感じるより長く待つ。** NIAは、返事をするための時間を多めにとり、さえぎらないようにすることを勧めています。手伝う前に、心の中で十まで数えましょう。
- **一度にひとつの手順。** 「絵をタップしてください」のように、短い指示をひとつだけ伝えて待ちます。説明するよりやって見せましょう。タップする場所を指さします。
- **自由にひと休みする。** ご本人が絵について話し始めたら、ゲームは待たせておけます。急ぐ必要はありません。
- **見てもらうのも良い。** NIAは、見ているほうが好きな方もいると述べています。それもちゃんとした選択です。

## 間違いは正したほうが良いですか？

いいえ。善意からでも、何度もやさしく訂正されると、ご本人は自分ができていないのだと受け取ってしまいます。米国アルツハイマー病協会は、害のないことを批判したり正したりしないよう勧めています。ゲームの中では、ほとんどすべての間違いが害のないものです。

| 代わりに | 試してみたい言い方 |
| --- | --- |
| 「違いますよ、それは間違いです。」 | 「こうしてみましょうか。」（NIAが挙げている例） |
| 「それは同じ絵じゃないですよ。もう一度よく見て。」 | 何も言わずに次の番に進む、または「あら、どちらも赤ですね。」 |
| 「これが誰か覚えていますか？」 | 「この絵のこと、聞かせてください。」 |
| 「それはもうやりましたよ。」 | 「いいですね。もう一回やりましょう。」 |
| 「ほら、知っているでしょう。」 | 「答えを出してみましょうか？」 |

間違いにはっきりいら立っているようなら、そっと手伝いましょう。正しい絵を指さす、あなたが番をする、次の回はゲームをやさしくするなど。ことわざの続きにおもしろい答えが出てきたら、いっしょに笑いましょう。ご本人の答えのほうがすてきかもしれません。

## ゲームをやさしくしたり、難しくしたりするには？

段階の呼び名ではなく、その日のご本人に合わせてゲームを調整しましょう。同じ方でも、朝より夕方のほうがシンプルなものが合うことがあります。NIAの最初のヒントは、ご本人ができることにレクリエーションを合わせ、うまくいったと感じられるようにすることです。

| ゲーム | やさしくするには | 少し難しくするには |
| --- | --- | --- |
| [絵合わせ](/games/picture-pairs/) | カード4枚から始め、絵は見えたままに | カードを増やす。抵抗がなければ絵を伏せる |
| [同じ絵さがし](/games/find-the-same/) | 選択肢2つ | 選択肢を最大4つまで |
| [いっしょに仕分け](/games/sort-together/) | 絵はあなたが持ち、ご本人がかごを指さす | 絵もかごもご本人がタップする |
| [絵パズル](/games/picture-puzzle/) | 4ピースで。先に絵全体について話す | 9ピース |
| [ことわざの続き](/games/finish-the-saying/) | 答えを表示してから、いっしょに言う | タップする前に、ご本人に続きを言ってもらう |
| [大きな文字の言葉さがし](/games/word-search/) | 印刷して、言葉をひとつだけいっしょにさがし、最初の文字を指さす | 次にさがす言葉をご本人に選んでもらう |
| [ぬりえ](/games/coloring/) | あなたが二色を選び、ご本人がどちらかを選ぶ | 色はすべてご本人が選ぶ |
| [会話カード](/games/conversation-cards/) | いっしょに絵を眺めるだけ | カードにある答えが自由な問いかけを使う |
| [写真合わせ](/games/photo-pairs/) | 大好きな家族の写真を数枚だけ | 写真を増やす |
| [絵ビンゴ](/games/picture-bingo/) | 参加する人それぞれに手伝う人がつく | 自分のカードに自分で印をつける |
| [ゆったり呼吸](/games/calm-breathing/) | いっしょに座って眺めるだけ | いっしょにゆっくり呼吸する |

難しすぎるサイン：考えているというより不安そうな長い間、何度も「できない」と言う、機器を押しやる、間違いに動揺する。やさしすぎるかもしれないサイン：退屈そうにする、子どもっぽいと言う。そんなときは、その気持ちを尊重し、言葉さがし、実際の写真を使ったパズル、ご本人がしていた仕事にまつわる絵についておしゃべりするなど、大人らしく感じられるものに切り替えましょう。

## ゲームを会話につなげるには？

一枚一枚の絵を話すきっかけにして、ご本人が何を言っても、それを良い答えとして受け止めましょう。多くのご家族にとって、これがいっしょに遊ぶいちばん楽しい部分です。

- **答えが自由で、間違いのない質問をする。** 「何か気づいたことはありますか？」「どれが好きですか？」「こんな台所のこと、聞かせてください。」
- **先にあなたが話す。** 「祖母がこんな犬を飼っていたんです。」あなたの話があると、ご本人も話しやすくなります。
- **脱線についていく。** 車の絵からドライブ旅行の思い出話が始まったら、その思い出話こそがレクリエーションです。ゲームは止めたままにしておきましょう。
- **事実を確かめない。** 回想では、細かいことの正確さより、楽しい会話のほうが大切です。前回と話が変わっていたら、新しいバージョンを楽しみましょう。
- **組み込まれている問いかけを使う。** [ことわざの続き](/games/finish-the-saying/)では、ことわざのあとにおしゃべりの問いかけが続きます。[会話カード](/games/conversation-cards/)は、まさにそのためにつくられています。[写真合わせ](/games/photo-pairs/)はご自分の家族の写真を使うので、いちばん豊かな思い出話が生まれることがよくあります。

ほかのアイデアは、[回想を使ったレクリエーション](/activities/reminiscence/)と[会話のコツ](/caregiving/communication-tips/)のガイドにあります。

## やめどきは？

疲れや動揺のサインが見え始めたら、できればその少し前にやめましょう。米国アルツハイマー病協会は、集中が途切れたり、いら立ちが募ったりしたら、やめるか別のことに変えるよう勧めています。

次のようなサインに気を配りましょう。

- あくびをする、姿勢が崩れる、視線が画面から離れていく
- そわそわする、立ち上がる、もう行きたいと言う
- ため息をつく、返事が短くなる、「私はこういうのは苦手で」と言う
- でたらめにタップする、機器を押しやる
- 涙ぐむ、いらいらする、急に気分が変わる

上手な終わり方：

- **かんたんなことで終える。** 最後にご本人がそろえられるペアをひとつ、または最後に眺める一枚の絵で。
- **あなたの都合にする。** 「お茶が飲みたくなりました。ここまでにしましょうか？」と言えば、ご本人がうまくできなかったという印象を与えずにすみます。
- **体を動かすことや、ほっとすることに移る。** 短い散歩、おやつ、洗濯物たたみ、音楽など。
- **あたたかいひと言を。** 「いっしょにできて楽しかったです。」「正解できた」ことをほめるのではなく、いっしょに過ごした時間を喜びましょう。

早めに終えること、予定を変えること、ゲームはやめていっしょに座っているだけにすること。どれも良い終わり方です。

## グループやビデオ通話でも遊べますか？

はい。少しだけ準備を足せば遊べます。グループでは人数を少なめにし、手助けが必要な方の隣には手伝う人が座り、みんなで同じものに注目できるゲームを選びましょう。[絵ビンゴ](/games/picture-bingo/)には、グループ向けの印刷できるカードと画面上の読み上げ役があります。詳しくは[介護施設でのグループレクリエーション](/activities/care-home-groups/)をご覧ください。

ビデオ通話では、通話相手が絵を説明し、部屋にいる人が指さしたりタップしたりできます。通話は短く、なじみのある形にしましょう。[電話やビデオ通話](/activities/phone-and-video-calls/)のガイドに、ほかのコツもあります。

## どうしてもゲームがうまくいかないときは？

何をしてもうまくいかない日もあります。それはあなたのせいでも、ご本人のせいでもありません。ゲームを片づけて、別の時間帯に、別のゲームで、あるいはゲームなしで過ごしてみましょう。良いレクリエーションの多くは、画面とはまったく関係がありません。音楽、タオルたたみ、アルバムをめくること、短い散歩など。ほかのアイデアは[レクリエーションのアイデア](/activities/ideas/)をご覧ください。
