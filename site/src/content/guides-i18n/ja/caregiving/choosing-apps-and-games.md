アプリストアには、シニア向け、記憶向け、認知症向けとうたうゲームがあふれています。よく考えて作られたものもあれば、医学的に聞こえるうたい文句や、遊びをテストに変えてしまうタイマー、広告やデータ収集を加えたものもあります。このページでは、どんなアプリでもご自身で見きわめるための方法を紹介します。他社の製品のランキングやレビューはしません。

## 認知症向けアプリを選ぶ前に、何を決めておくとよいですか？

アプリに何をしてほしいかを決めましょう。「お母さんにゲームを」と言っても、意味はまったく違いえます。ひとつの目的に最適なものが、別の目的にはあまり向かないことがよくあります。

| 目的 | イメージ | 見るポイント |
| --- | --- | --- |
| やさしい刺激 | 絵合わせ、仕分け、かんたんなパズル、言葉のゲーム | 難しさを調整できる、絵が見えたまま、時間のプレッシャーがない |
| 思い出話 | 昔の写真、なじみのことわざ、若いころの音楽 | ご自身の写真が使える、答えを決めない問いかけ、クイズがない |
| 落ち着き | ゆっくりした映像、静かな音、呼吸、自然 | 始めるのもやめるのも簡単、点滅がない、突然のことが起きない |
| つながり | 対面やビデオ通話でいっしょに遊ぶ・話す | 2人向けに作られている、会話のきっかけがある |

認知症のある方への構造化された「認知刺激」の研究は、そのほとんどが、訓練を受けたスタッフが進行し、話し合い、言葉のゲーム、パズル、音楽、創作活動を行うグループセッションです。[コクランのレビュー](https://www.cochrane.org/evidence/CD005562_can-cognitive-stimulation-benefit-people-dementia)は、平均すると小さな効果があり、研究によってばらつきがあることを見いだしました。そのような社会的で変化に富んだプログラムは、ひとりで使うアプリと同じものではありません。アプリは、数あるいっしょに楽しむ活動のひとつとして考えましょう。

## アプリがご本人に合っているか、どうすればわかりますか？

診断名や段階ではなく、ご本人の反応を見ましょう。「同じ段階」の2人でも、視力、聴力、手の動き、言葉、画面への慣れは大きく違うことがあります。[米国アルツハイマー病協会](https://www.alz.org/help-support/caregiving/daily-care/activities)は、過去の興味と現在できることを頭に置き、達成よりも楽しさに焦点を当てるよう勧めています。

合っているサイン：

- あまり誘わなくても、自分から始める、または加わる。
- 笑顔が出る、感想を話す、思い出を語る。
- 間違いを気にしていないようすである。
- やめる時間になったら、気持ちよくやめられる。

合っていないサイン：

- 「できない」「ばかばかしい」と繰り返す。
- どこをタップすればよいか、わからない。
- いら立ち、恥ずかしさ、端末を押しのける。
- あなたがほとんど全部やらないと、成り立たない。

つらそうなようすは、がまんして続けるものではなく、合図です。[断られたときの対応](/caregiving/when-they-say-no/)もご覧ください。アプリ以外の、段階別のアイデアは、[初期](/activities/early-stage/)と[後期](/activities/late-stage/)の活動をご覧ください。

## どんな設計を探し、何を避けたらよいですか？

落ち着いた、シンプルで、大人向けの設計を探し、プレッシャーを加えるものは避けましょう。

| 探したいもの | 注意したいもの |
| --- | --- |
| 大きな絵と文字、高いコントラスト | 小さなアイコン、ごちゃごちゃした画面 |
| 1画面にひとつの明確な操作 | たくさんのボタン、メニュー、何段階もある手順 |
| タイマーがない、またはオフにできる | カウントダウン、スピードボーナス、「記録を更新しよう」 |
| 点数がない、またはやさしいフィードバック | ポイント、ライフ、連続記録、ランキング、「脳年齢」 |
| 間違いを静かに扱う | ブザー、赤いバツ印、「不正解」のメッセージ |
| 大人向けの、実際の絵や写真 | 漫画のような、子どもっぽいテーマ |
| オフラインで動く、始めるのにアカウントが不要 | 登録、ログイン、先にコンテンツのダウンロードが必要 |
| 一時停止や終了が簡単 | 「続けますか？」や、アプリの評価をうながすポップアップ |
| 広告がなく、買い切りか定額かが明確 | 広告、ガチャのような課金要素、頻繁な購入の誘導 |
| もうひとりも加わりやすい | ひとり用のみ、競争的な設計 |

広告や購入の誘導は、うっかりタップしてしまいやすいものです。

## アプリのプライバシーは、どう確かめますか？

アプリが何を集め、誰と共有し、削除できるかを確かめましょう。インストールする前に：

1. **ストアのプライバシーの概要を読む。** Google Playの[データ セーフティ セクション](https://support.google.com/googleplay/answer/11416267?hl=en&co=GENIE.Platform%3DAndroid)や、App Storeの[プライバシー情報のセクション](https://support.apple.com/en-us/102399)には、アプリが収集・共有する可能性のあるデータの種類が載っています。どちらの会社も、この情報は開発者自身が提供するものだとしています。つまり出発点であって、監査ではありません。
2. **アカウントが必要かどうか確かめる。** 絵を見せるだけ、かんたんなゲームだけのアプリなら、あなたの名前、メールアドレス、誕生日を知る理由がないかもしれません。
3. **権限を確認する。** 絵合わせのゲームに、本当に位置情報、連絡先、マイク、写真ライブラリ全体が必要でしょうか。不要なものはオフにしましょう。
4. **広告と分析ツールを探す。** 広告や追跡のツールは、アプリの使われ方についてのデータを、ほかの会社に送ることがあります。
5. **写真がどこへ行くか調べる。** ご家族の写真を追加する場合、端末の中にとどまるのか、サーバーにアップロードされるのか。削除できるのか。
6. **削除方法を確かめる。** プライバシーポリシーやデータの概要で、データとアカウントの削除方法を探しましょう。データを削除できないとするアプリには、特に写真や健康に関する情報があれば、なおさら注意が必要です。
7. **プライバシーポリシーを読み、** 何を、なぜ、どのくらいの期間集め、誰と共有するのかを、わかりやすく確かめましょう。

### 認知症向けアプリの情報は、HIPAAで保護されますか？

通常は保護されません。意外に思う方は多いでしょう。米国保健福祉省は、HIPAAが、医療保険、ほとんどの医療提供者、医療情報交換機関、およびその業務委託先に適用されると[説明しています](https://www.hhs.gov/hipaa/for-professionals/privacy/guidance/cell-phone-hipaa/index.html)。ほとんどの場合、個人的な利用のためにアプリに入力したデータは、対象機関やその業務委託先がアプリを提供したのでない限り、保護されません。アプリストアの「認知症アプリ」は、健康について語っていても、HIPAAの対象外であることがよくあります。（HIPAAは米国の法律です。日本でのアプリの扱いについては、アプリのプライバシーポリシーを確かめましょう。）

### HIPAAの対象外のアプリで、健康データは何に守られますか？

米国連邦取引委員会の「医療情報漏えい通知規則」が、その多くを対象としています。2024年、FTCは、この規則がHIPAAの対象外のヘルスアプリや類似の技術に適用されることを明確にする[変更を確定しました](https://www.ftc.gov/news-events/news/press-releases/2024/04/ftc-finalizes-changes-health-breach-notification-rule)。「漏えい」には、ハッキングだけでなく、無断の開示も含まれ、企業は影響を受ける人とFTCに通知しなければなりません。これは何か起きたあとのセーフティネットであって、アプリが必要なものだけを集めるという約束ではありません。

## 研究や効果についてのうたい文句は、どう読めばいいですか？

効果についての主張はゆっくり読み、特に大きな約束ほど懐疑的になりましょう。考えたい問い：

- **具体的に何を調べたのか。** ひとつの訓練プログラムの研究は、アプリのすべてのゲームが同じように効くことを示すものではありません。
- **誰を調べたのか。** 健康な高齢者での結果は、認知症のある方には当てはまらないかもしれません。
- **何を測ったのか。** ゲームそのものが上手になることと、日常生活、会話、気分、自立の変化は別のものです。
- **研究はどのくらい確かか。** ランダム化比較試験（RCT）は、アプリを使うグループと使わないグループを比べます。良い設計ですが、小規模または短期間のRCTがひとつあっても証拠にはなりません。独立した研究者による、一致する複数の研究を探しましょう。
- **病気そのものを変えると主張していないか。** 検査での小さな改善を示した研究は、アプリが認知症の進行をゆるやかにする、予防する、治療する証拠にはなりません。

米国国立老化研究所の[認知機能の健康と高齢者](https://www.nia.nih.gov/health/brain-health/cognitive-health-and-older-adults)のページは、米国国立衛生研究所（NIH）が資金を出した、構造化された認知訓練の大規模試験を紹介したうえで、特定のコンピューターゲームやオンラインゲームが記憶や思考力を高められるといううたい文句に注意するよう呼びかけています。市販の脳トレアプリが、その試験で検証された訓練と同じ影響をもつという証拠は、まだ十分ではないとしています。詳しくは、[脳トレゲームと科学的根拠](/brain-health/brain-games/)と、[認知症の予防について研究が示していること](/brain-health/can-dementia-be-prevented/)のガイドをご覧ください。

### 誤解を招く宣伝の、公になった例は？

2016年1月、FTCは、「脳トレーニング」プログラム Lumosity の運営会社との和解を[発表しました](https://www.ftc.gov/news-events/news/press-releases/2016/01/lumosity-pay-2-million-settle-ftc-deceptive-advertising-charges-its-brain-training-program)。FTCは、同社が十分な証拠なしに、そのゲームが加齢による認知機能の低下を遅らせ、軽度認知障害、認知症、アルツハイマー病から守れると主張したと訴えました。同社は200万ドルの支払いに同意し、今後このような主張をするには、信頼できる十分な科学的証拠が必要です。この事例は、宣伝の文句は証拠ではないことを思い出させてくれます。

### 注意が必要な言葉は？

アプリや広告が次のように言っているときは、注意しましょう。

- 認知症やアルツハイマー病を「予防する」「回復させる」「止める」「治す」。
- 研究の名前、対象者、測定内容を示さずに、「臨床的に証明された」と言う。
- 診断を思わせる、「脳年齢」や記憶のスコアを出す。
- 脳を「鍛える」「高める」「トレーニングする」と言う。
- 体験談を証拠として使う。

うたい文句に迷ったら、かかりつけ医に尋ねましょう。

## Golden Moments は、どこに位置づけられますか？

Golden Moments が提供するのは、記憶のテストでも、セラピーでも、医療的な助言でもなく、いっしょに楽しむシンプルな活動です。[絵合わせ](/games/picture-pairs/)、[会話カード](/games/conversation-cards/)、[写真合わせ](/games/photo-pairs/)、[絵ビンゴ](/games/picture-bingo/)、[ゆったり呼吸](/games/calm-breathing/)などのゲームは、楽しさと会話のために作られています。認知症の診断、治療、予防、測定はせず、記憶や思考についての効果もうたっていません。

また、無料のアプリ[iPhone・iPad・Android向け Golden Moments](/app/)も提供しています。大きなタイルのやさしい絵合わせ、ご自身で選んだ家族の写真を使うゲーム、オフラインで使える絵のパックがあり、アカウント、広告、タイマー、点数はありません。同じチェックリストが当てはまります。App Storeのプライバシー表示は「データは収集されません」となっており、[アプリのプライバシーポリシー](/app-privacy/)には、写真のコピーがどこに保管されるかが説明されています。

私たちは、信頼してもらうより、見きわめてもらいたいと考えています。このページのチェックリストを使い、[プライバシーのページ](/privacy/)と[医療に関する免責事項](/medical-disclaimer/)を読み、私たちのものを含め、介護している方に合わないものは使うのをやめてください。

## 新しいアプリは、どのように試すのがよいですか？

2週間ほどいっしょに試して、どうなるかを見守りましょう。

1. **先に設定をしておく。**[タブレットとスマートフォンの設定ガイド](/caregiving/tablets-and-screens/)を使い、いちばんやさしい設定から始めましょう。
2. **短い時間で行い、** 笑顔、会話、落ち着きに気づき、良い場面で終えましょう。
3. **いら立ちのもとになるなら、やめる。** どんなに評価が高くても同じです。
