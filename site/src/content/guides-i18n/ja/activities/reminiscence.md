回想とは、シンプルに言えば、いっしょに昔を楽しむことです。認知症のある方の多くは、今朝のできごとより、何十年も前の思い出のほうがはっきりしています。写真、なじみのあるもの、音楽、思い出話は、そうした記憶の扉を開き、いっしょに味わえるあたたかい話題を与えてくれます。ルールはひとつだけ。これは会話であって、決してクイズではありません。

## 回想とは何で、質問で試すこととはどう違うのですか？

回想とは、ご本人のペースで、写真、もの、音楽、映像を通して思い出を分かち合うことです。[英国の国民保健サービス（NHS）](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)は、本やタブレットにまとめた写真、もの、映像、音楽の助けを借りて、昔の経験や思い出話を分かち合うことだと説明しています。質問で試すのは、これとは違います。正しい答えを出すようご本人に求めることになり、楽しさの代わりに恥ずかしさをもたらしてしまうことがあります。

[米国国立老化研究所（NIA）](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/dos-and-donts-communicating-person-who-has)は、何かや誰かを覚えているかどうかを尋ねることを、避けたいことに挙げています。[米国家族介護者連盟（Family Caregiver Alliance）](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)は、短期記憶に頼る質問は避け、代わりにもっと昔のことを話題にするよう勧めています。

| 代わりに | 試してみたい言い方 |
| --- | --- |
| 「これ、覚えていますか？」 | 「楽しそうな日ですね。聞かせてください。」 |
| 「これは誰ですか？」 | 「海に行ったときの春子おばさんですね。すてきな帽子。」 |
| 「これは何年のことですか？」 | 「昔の家みたいですね。あそこでの暮らしはどんなでしたか？」 |
| 「違いますよ、それは健二さんじゃなくて正男さん。」 | 「楽しそうな方ですね。」 |
| 「その話、もう聞きましたよ。」 | 「そのお話、好きです。」 |

## 質問で試さずに、写真について話すには？

まず見えたものを言葉にし、ご本人が何か付け加えたければ、そのための間をあけておきましょう。

1. **隣に並んで座る。** アルバムを二人の間に持ち、テーブル越しに試すのではなく、いっしょに眺めましょう。
2. **写真を少し選ぶ。** 箱いっぱいの写真より、良い写真五枚のほうが向いています。大きく、はっきりした写真がいちばんです。
3. **人の名前はあなたが言う。** 「お父さんと結婚式の日のあなたですね」と言えば、プレッシャーがなくなります。
4. **細かいところに感想を言う。** 服、車、食べ物、天気、表情など。「すてきな車ですね。ぴかぴかです。」
5. **求めるのではなく、誘う。** 「〜のこと、聞かせてください」「何か気づいたことはありますか？」黙っていても大丈夫です。
6. **ご本人に合わせる。** まったく別の話を始めても、それに合わせましょう。
7. **楽しいうちにやめる。** 疲れが出る前にアルバムを閉じましょう。

すぐに使える絵の問いかけなら、[会話カード](/games/conversation-cards/)をお試しください。ご家族の写真をやさしい絵合わせゲームにするなら、[写真合わせ](/games/photo-pairs/)をどうぞ。選んだ写真はブラウザの中にとどまります。

## 思い出の箱はどうつくれば良いですか？

思い出の箱とは、ご本人の人生にまつわるものを入れて、手に取ったり話したりするための入れ物です。

1. **開けやすい丈夫な箱を選ぶ。** 靴箱、帽子の箱、小さな木箱など。
2. **テーマを決めるか、いろいろ混ぜる。** 仕事、趣味、ある場所、ある年代、または少しずついろいろと。
3. **安全なものを集める。** 始めるなら五〜十個で十分です。
4. **大切なものはコピーを使う。** 代わりのきかない写真や書類はコピーし、原本は安全な場所にしまっておきましょう。
5. **一度にひとつずつ取り出す。** ひとつ手渡し、それについて何か言って、話がどこへ向かうか見てみましょう。

入れるもののアイデア：

- **仕事：** 名札、小さな道具、制服のワッペン、帳簿、看護師のバッジ、食堂のメニュー。
- **家：** ご本人の手書きのレシピカード、ふきん、お気に入りのスカーフやネクタイ。
- **趣味：** 針を外した釣りのルアー、野球のボール、毛糸玉、花の種の袋。
- **場所：** 絵はがき、地図、旅行のおみやげ、ふるさとの新聞の切り抜き。
- **家族：** 写真のコピー、子どもの描いた絵、結婚式の招待状。

とがったもの、飲み込んでしまいそうな小さなもの、そして喜ばれると分かっている場合を除き、つらい記憶を呼び起こしそうなものは入れないでおきましょう。

## 人生の物語の本はどうつくれば良いですか？

人生の物語の本とは、ご本人の人生についての写真と短い説明をまとめた、シンプルなアルバムです。いっしょに眺めて楽しむものであり、訪ねてくる人や介護スタッフがその方の全体像を知る助けにもなります。

1. **形を決める。** クリアポケットのついたバインダー、印刷したフォトブック、タブレットのスライドショーなど。
2. **いくつかの章を考える。** 子どものころ、学校、仕事、家族、住んだ場所、信仰、趣味、好きな食べ物と音楽。
3. **各ページに写真を一、二枚。** 大きな文字の短い説明を添えます。「花子、22歳、銀行に勤め始めたころ。」
4. **好きなことや日課も入れる。** 「コーヒーにはミルクを入れる。昔の歌謡曲が好き。テレビの大きな音は苦手。」これは、ご本人をケアするすべての人の助けになります。
5. **ご本人にも関わってもらう。** 写真を選ぶ、思い出話をする、できあがっていくのを眺めるなど、ご本人が望む範囲で。
6. **どんどん付け加える。** 完成していなくても役に立ちます。

## ほかの回想のアイデア

- **若いころの音楽を流し、** その音楽がどこへ連れて行ってくれるかを話しましょう。[音楽を使ったレクリエーション](/activities/music/)もご覧ください。
- **ホームビデオや、好きだった年代のテレビ番組を観る。**
- **子どものころの料理をつくり、** 香りに会話を導いてもらいましょう。
- **ふるさとの地図を眺め、** なじみのある通りを指でたどりましょう。
- **昔のカタログや雑誌を手に取り、** 値段、ファッション、車について話しましょう。
- **ご本人の許可を得て、思い出話をスマートフォンで録音し、** 家族のために残しましょう。
- **電話のときに分かち合う。** ビデオ通話中に写真を一枚かざしてみましょう。[電話やビデオ通話](/activities/phone-and-video-calls/)もご覧ください。
- **訪ねるときに写真やものを持っていく。** 面会の話題が自然に生まれます。[面会](/activities/visiting/)もご覧ください。

## 思い出がつらいものだったら？

悲しみ、後悔、恐れを呼び起こす思い出もあります。ご本人が動揺したら、いったんやめて寄り添い、そっと話題やレクリエーションを変えましょう。何があったかについて言い争うのはやめましょう。米国家族介護者連盟は、ご本人が間違っていると説得しようとしないよう勧め、ご本人が表している気持ちに応えることを勧めています。その気持ちは本物だからです。亡くなった方のことを生きているかのように話すときは、その気持ちに応えましょう。「会いたいですね。どんな方だったか聞かせてください。」

## 研究では何が分かっていますか？

22の試験、1,972人を対象にした[回想法についてのコクランのレビュー](https://www.cochrane.org/evidence/CD001120_reminiscence-therapy-dementia)では、効果は一貫せず、小さく、行われる場や形式によってさまざまだとされました。認知症のある方への害を示す根拠は見つかりませんでした。私たちが回想をおすすめするのは、治療としてではなく、あたたかく意味のある時間をいっしょに過ごせることがあるからです。気軽な会話について詳しくは、[会話のコツ](/caregiving/communication-tips/)をご覧ください。
