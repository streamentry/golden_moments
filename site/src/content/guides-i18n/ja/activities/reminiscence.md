回想法とは、過去を一緒に楽しむことです。多くの認知症の方にとって、今朝起きたことより何十年も前の思い出の方が鮮明に残っています。写真、なじみの物、音楽、物語は、それらの思い出を開き、温かく分かち合えるものを与えてくれます。ただ一つのルールがあります。それは会話であり、決してクイズではないということです。

## 回想法とは何か、クイズとどう違うのか？

回想法とは、写真や物、音楽、映像を通して、その人のペースで思い出を分かち合うことです。[NHS](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)は、写真、物、映像、音楽を手がかりに、過去の経験や物語を分かち合うことだと説明しています。本やタブレットでもできます。クイズとは違います。クイズは正解を引き出そうとするもので、楽しみではなく恥ずかしさを招くことがあります。

[National Institute on Aging](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/dos-and-donts-communicating-person-who-has)は、何かや誰かを覚えているかを尋ねることを避けるべきことの一つに挙げています。[Family Caregiver Alliance](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)は、短期記憶に頼る質問を避け、より遠い過去について話すことを勧めています。

| こう言う代わりに | こう試してみましょう |
| --- | --- |
| 「これ、覚えている？」 | 「楽しそうな日だね。教えて。」 |
| 「これは誰？」 | 「ビーチにいるローズおばさんだよ。あの帽子を見て。」 |
| 「何年の写真？」 | 「昔の家みたいだね。そこに住んでいた頃はどんな感じだった？」 |
| 「違うよ、ビルじゃなくてフランクだよ。」 | 「とても楽しそうな人だね。」 |
| 「それ、もう話したよ。」 | 「その話、大好き。」 |

## クイズにならずに写真について話すには？

まず目に見えるものについて話し、相手が望めば何かを加えられる余地を残します。

1. **横に並んで座ります。** アルバムを二人の間に置き、向かい合って試すのではなく、一緒に見ます。
2. **写真を数枚選びます。** 箱いっぱいより、良い写真が五枚ある方が良いです。大きくて鮮明なプリントが最適です。
3. **人物の名前を自分で言います。** 「結婚式の日のあなたとお父さんだよ」と言うと、プレッシャーがなくなります。
4. **細部にコメントします。** 服、車、食べ物、天気、顔。「すごい車だね。ピカピカだ。」
5. **誘い、要求しません。** 「教えて…」や「何に気づく？」。沈黙も構いません。
6. **相手のペースに合わせます。** 全く別の話題になっても、それに従います。
7. **楽しいうちに終えます。** 疲れる前にアルバムを閉じます。

用意された絵のヒントが欲しいなら、[会話カード](/games/conversation-cards/)を試してみてください。家族の写真をやさしい合わせ遊びにしたいなら、[写真ペア](/games/photo-pairs/)を試してみてください。選んだ写真はブラウザ内にとどまります。

## メモリーボックスはどう作りますか？

メモリーボックスとは、その人の生活にまつわる物を入れた容器で、手に取って話すためのものです。

1. **丈夫な箱を選びます** 開けやすいもの、靴箱、帽子箱、小さな木箱など。
2. **テーマを一つ選ぶか、混ぜます。** 仕事、趣味、場所、十年代、または少し全部。
3. **安全な物を集めます。** まず五〜十個で十分です。
4. **大切なもののコピーを使います。** かけがえのない写真や書類はコピーし、原本は安全に保管します。
5. **一度に一つずつ出します。** 一つ手渡し、それについて一言言い、話がどこへ行くか見ます。

入れるアイデア：

- **仕事：** 名札、小さな工具、制服のワッペン、台帳、看護師のピン、食堂の料理本。
- **家庭：** 手書きのレシピカード、ティータオル、お気に入りのスカーフやネクタイ。
- **趣味：** 針のない釣りルアー、野球ボール、毛糸玉、種の袋。
- **場所：** ポストカード、地図、観光のおみやげ、故郷の新聞の切り抜き。
- **家族：** 写真のコピー、子どもの絵、結婚式の招待状。

鋭利な物、飲み込める小さな物、そして苦しい思い出を呼び起こす可能性があるものは、歓迎されることが分かっている場合以外は避けます。

## ライフストーリーブックはどう作りますか？

ライフストーリーブックとは、その人の人生についての写真と短いキャプションをまとめた簡単なアルバムです。一緒に見るものであり、訪問者や介護スタッフが診断名だけでなくその人全体を知る助けにもなります。

1. **形式を選びます。** シートプロテクター付きバインダー、印刷したフォトブック、タブレットのスライドショー。
2. **いくつかの章を計画します。** 幼少期、学校、仕事、家族、住んだ場所、信仰、趣味、好きな食べ物や音楽。
3. **ページごとに写真を一〜二枚加え**、大きな文字で短いキャプションを付けます：「メアリー、22歳、銀行で働き始める。」
4. **好みや日常を含めます。** 「コーヒーはミルク入り。日曜の賛美歌が好き。大きな音のテレビは苦手。」これは介護する誰にでも役立ちます。
5. **本人をできるだけ関わります** 写真を選ぶ、話を聞かせる、または完成を見守るだけでも。
6. **加え続けます。** 使えるようになるのに、完成している必要はありません。

## もっと回想法のアイデア

- **若い頃の音楽をかけ**、どこへ連れて行ってくれるか話します。[音楽の活動](/activities/music/)をご覧ください。
- **ホームムービーやお気に入りの年代のテレビ番組を見ます。**
- **子どもの頃の料理を作り**、匂いから会話を広げます。
- **故郷の地図を見て**、なじみの通りをたどります。
- **古いカタログや雑誌を手に取り**、値段、ファッション、車について話します。
- **本人の許可を得て**、家族のために電話で話を録音します。
- **通話中に共有します。** ビデオ通話で写真を一枚掲げます。[電話とビデオ通話](/activities/phone-and-video-calls/)をご覧ください。
- **訪問時に写真や物を持って行きます。** 訪問に簡単な焦点が生まれます。[訪問](/activities/visiting/)をご覧ください。

## 思い出がつらいものだったら？

思い出の中には、悲しみ、後悔、恐れを伴うものもあります。その人が動揺したら、いったん止め、慰め、そっと話題や活動を変えてください。何が起きたかを論じないでください。Family Caregiver Allianceは、相手が間違っていると納得させようとしないよう勧め、その人が表す感情に応えることを提案しています。それらの感情は本物です。亡くなった人をまだ生きているように話す場合は、感情に応えてください：「寂しいのね。その人について教えて。」

## 研究は何を示していますか？

[Cochraneの回想法レビュー](https://www.cochrane.org/evidence/CD001120_reminiscence-therapy-dementia)は、22の試験と1,972人を対象に、効果は一貫せず、小さく、場面や形式によって異なることを示しました。認知症の方に害があるという証拠は見つかりませんでした。私たちは、温かく意味のある時間を一緒に過ごせるからこそ回想法を勧めます。治療としてではありません。やさしい会話について詳しくは、[コミュニケーションのヒント](/caregiving/communication-tips/)をご覧ください。
