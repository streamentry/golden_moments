五感を使ったレクリエーションは、触覚、嗅覚、味覚、聴覚、視覚という五つの感覚を使います。記憶も、手順も、正解も必要ないので、どの段階でも楽しめます。特に大切になるのは後の段階です。[米国アルツハイマー病協会](https://www.alz.org/help-support/caregiving/stages-behaviors/late-stage)は、後期には世界を主に五感を通して感じるようになり、触れること、音、見るもの、味、香りを通していたわりを伝えられると述べています。いくつか安全を確かめておけば、誰にとってもくつろげるレクリエーションになります。

## 認知症の方の五感を使ったレクリエーションとは？

五感を使ったレクリエーションとは、布に触れる、ハーブの香りをかぐ、雨の音を聴くなど、一度にひとつの感覚を中心にしたシンプルな体験です。[英国の国民保健サービス（NHS）](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)は、後の段階のレクリエーションは五感に焦点を当てる必要があることが多いとし、音楽、触ったり手に取ったりできるもの、ハンドマッサージを挙げています。[米国アルツハイマー病財団](https://alzfdn.org/therapeutic-activities-for-3-main-stages-of-alzheimers-disease/)は、後期の方は安心のために何かを抱きしめていたいという強い気持ちを持つことがあると述べています。

## 感覚ごとのアイデア

### 触覚

- **ハンドマッサージ。** 少しのローションを手のひらで温め、手首から指先へとゆっくりなでます。[米国国立老化研究所（NIA）](https://www.nia.nih.gov/health/alzheimers-caregiving/care-last-stages-alzheimers-disease)は、安らぎのために無香料のローションでマッサージすることを挙げています。
- **布のかご。** ベルベット、コーデュロイ、フリース、サテン、ウールの大きな布を入れておき、なでたり、たたんだり、話題にしたりしましょう。
- **温かいおしぼり。** 寒い日に、温かく湿らせた布で手を包みます。まずあなた自身の手首で温度を確かめましょう。
- **アクティビティエプロンやひざ掛け。** 大きなボタン、ファスナー、リボン、手ざわりの違う布をしっかり縫いつけたもの。
- **たたむ、しわを伸ばす。** 清潔なおしぼりやナプキンを入れたかごを用意し、たたんで、重ねて、またたたみ直します。
- **手に持てるやわらかいもの。** フリースのひざ掛け、クッション、本物らしいぬいぐるみの動物などを、おもちゃとしてではなく、そっと渡しましょう。

### 嗅覚

- **新鮮なハーブ。** ミント、ローズマリー、バジル、ラベンダー、しそなどの葉を指でこすってから手渡しましょう。
- **台所の香り。** そばでいれるコーヒー、焼けるトースト、シナモン、むいているみかんやオレンジなど。
- **花。** 庭やお店で買った生花を少し飾りましょう。
- **なじみのある製品。** 肌に合うなら、ご本人がずっと使ってきた石けんやローション。

### 味覚

- **好きな味。** すりおろしりんご、プリン、アイスクリームなど、大好きなものを小さなスプーンに一杯、安全に食べられる形状で。
- **お菓子づくりを手伝ってもらう。** いっしょに作りながら、果物やクリームを少し味見します。
- **季節の味。** 夏のすいか、秋の温かいほうじ茶など。安全な温度で出しましょう。

### 聴覚

- **好きな音楽。** なじみのある歌を、やさしい音量で。[音楽を使ったレクリエーション](/activities/music/)をご覧ください。
- **自然の音。** 雨、波、鳥のさえずりなど。NIAは、音楽、ホワイトノイズ、自然の音で落ち着く方もいるようだと述べています。
- **あなたの声。** 読み聞かせ、ハミング、お話をすること。
- **かんたんな楽器。** 小さな太鼓、マラカス、鈴などで、音楽に合わせて鳴らしましょう。

### 視覚

- **窓の外を眺める。** 窓の外の鳥のえさ台、下校する子どもたち、降る雪など。
- **水槽やゆっくりした映像。** 大きな音のない、おだやかな動き。
- **大きな写真。** はっきりした写真を一枚ずつ、目の高さで。
- **色と模様。** 鮮やかな端切れ、花、色とりどりのナプキンを分ける、あるいはこのサイトの[ぬりえ](/games/coloring/)からかんたんなページを選んで。
- **屋外で。** NHSは、香りのよい植物、さまざまな手ざわり、水の流れなどがある「五感の庭」を勧めています。[屋外と庭仕事のレクリエーション](/activities/outdoor-and-gardening/)をご覧ください。

## 五感の箱の作り方

1. **ご本人の人生に関わるテーマを選ぶ。** 海辺、庭、台所、作業場、裁縫など。
2. **大きくて安全なものを五つか六つ選ぶ。** 大きな貝殻、木のスプーン、やわらかいスカーフ、口をしっかり縫い閉じた乾燥ラベンダーの香り袋、なめらかな木のブロックなど。
3. **ひとつひとつ確かめる。** 小さな部品、とがった角、ほつれた糸、割れるものがないか。
4. **一度にひとつずつ出す。** 手渡して、それについて話し、ご本人に自由に触れてもらいましょう。
5. **使い終わったら箱をしまう。** 特別なものであり続けるように。次に使う前にも、もう一度確かめましょう。

## まず安全を

五感を使ったレクリエーションはおだやかなものですが、気をつけたい危険がいくつかあります。認知症のある方の中には、食べ物ではないものを食べ物と間違える方がいます。また、時間とともに飲み込むことが難しくなることがあります。NIAは、後期に飲み込みの問題が起きると、窒息の危険が高まると注意しています。

| 危険 | すること |
| --- | --- |
| 窒息・誤えん | 飲み込めない大きさのものだけを使う。ボタン、ビーズ、硬貨、ビー玉、小さなおもちゃを箱にばらばらに入れない。食べ物は、介護・医療チームが安全だとする形状のものだけを勧める。 |
| 食べ物に見えるもの | NIAは、食べ物のように見えたりにおったりすることがあるローション、石けん、シャンプー、香水を鍵のかかる場所にしまい、作り物の果物は片づけるよう勧めている。五感用の製品は使い終わったらしまう。 |
| アレルギー | 始める前に、ナッツ、ラテックス、ウール、植物、香料へのアレルギーがないか確かめる。 |
| 強い香り | 強い香水や精油は避ける。ぜんそくなど呼吸の問題がある場合は特に。ほのかで自然な香りのほうが安全。 |
| 肌 | マッサージの前に、痛み、傷、もろくなった肌がないか確かめる。やさしい力で行い、顔をしかめたらやめる。 |
| 温度 | 温かい布や飲み物は、まずあなた自身の手首で確かめる。 |
| とがったもの・有害なもの | とがった道具、ガラス、有害な工作用品は使わない。 |

## アロマセラピーは役に立ちますか？

目に見えるかたちで役立つことは、おそらくありません。[認知症に対するアロマセラピーについてのコクランのレビュー](https://www.cochrane.org/evidence/CD003150_aromatherapy-dementia)は、すべて介護施設で行われた13件の研究、708人を調べ、効果についての説得力のある根拠は見つかりませんでした。研究は小規模で、結果は食い違い、副作用もきちんと報告されていませんでした。庭のラベンダーのように、ご本人がほのかでなじみのある香りを楽しむなら、それはいっしょに楽しむ十分な理由になります。ただし、治療ではありません。

## 五感を使ったレクリエーションの勧め方

- **静かなときを選び、** テレビを消しましょう。
- **正面から近づき、** 名前を呼び、触れる前に尋ねるか伝えましょう。「ローションがあるの。手をマッサージしましょうか？」
- **一度にひとつずつ勧める。** 圧倒されないように。
- **反応を見る。** 表情がやわらぐ、手の力が抜ける、笑顔になるのは良いサインです。身を引く、顔をしかめる、落ち着かないのは、やめるべきサインです。
- **短めに。** 落ち着いた五分間で、十分なひとときになります。

最後に、[ゆったり呼吸](/games/calm-breathing/)のように、いっしょにゆっくり呼吸する時間をとると、やさしい締めくくりになります。ベッドのそばでできるアイデアは[後期の認知症の方とのレクリエーション](/activities/late-stage/)を、夕方の落ち着かなさについては[夕方の落ち着かなさ（夕暮れ症候群）](/caregiving/late-day-restlessness/)をご覧ください。
