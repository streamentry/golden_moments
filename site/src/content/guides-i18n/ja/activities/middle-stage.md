認知症の中期は、いちばん長く続くことが多い時期で、レクリエーションにしっかりとした手助けが必要になり始める時期でもあります。言葉が出にくくなり、手順が混乱し、何かを始めること自体が難しく感じられるようになります。それでも、役に立ちたい、参加したいという気持ちは、たいてい残っています。少し準備をすれば、中期の方も驚くほど多くのことを楽しめます。特に、なじみのある家事、音楽、絵や写真を、あなたと並んでいっしょにすることです。

## 中期の認知症には、どんなレクリエーションが合いますか？

短く、なじみがあり、手を使い、ひとつずつの手順に分けたレクリエーションがいちばん合います。[米国アルツハイマー病協会](https://www.alz.org/help-support/caregiving/stages-behaviors/middle-stage)は、新しくすることを考え出す必要はないと述べています。いっしょに夕食を作る、庭仕事をする、音楽を聴く、散歩に出かけるなど、ふだんの暮らしの一部がレクリエーションになります。

[米国アルツハイマー病財団](https://alzfdn.org/therapeutic-activities-for-3-main-stages-of-alzheimers-disease/)は、この時期の方は、目的を持っていたい、何かの世話をしたいという強い気持ちを持つことが多く、レクリエーションを始めたり続けたりするのに手助けが必要だと述べています。中期のアイデアとして、洗濯物をたたむ、食器を洗う、靴下を仕分ける、軽い運動、なじみの音楽に合わせて踊る、付き添っての散歩、みんなで歌う、かんたんな絵を描く、アルバムを眺めるなどを挙げています。

## うまくいくように準備するには？

レクリエーションの多くは、準備の段階でうまくいくかどうかが決まります。[米国アルツハイマー病協会](https://www.alz.org/help-support/caregiving/daily-care/activities)と[米国家族介護者連盟（Family Caregiver Alliance）](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)の助言をもとにした、次の心がけがいちばん大きな違いを生みます。

1. **場所を整える。** テレビを消し、ドアを閉め、そのレクリエーションに必要なものだけを出しましょう。
2. **あなたが始める。** たたんだり混ぜたりし始めてから、「これ、手伝ってもらえる？」と誘いましょう。
3. **やって見せて、待つ。** 手順をひとつやって見せます。お皿を置く場所を示すなど、指さしや手を添えて伝えましょう。
4. **手順は一度にひとつ。** 「これをたたんで、色ごとに重ねて」より、「半分にたたんでね」のほうがかんたんです。
5. **答えの決まっていない質問ではなく、二択に。** 「どれをやりたい？」より、「青いタオルと白いタオル、どっちにする？」のほうが答えやすいものです。
6. **難しいところはあなたが。** あなたが量り、ご本人が混ぜる。あなたが針に糸を通し、ご本人が毛糸を巻く。
7. **理由を添える。** 「このナプキンは日曜日の夕食用なの」と言えば、その仕事が本物に感じられます。
8. **見ているほうが良ければ、それで。** [米国国立老化研究所（NIA）](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)は、ただ見ているだけでも楽しめることがあると述べています。

## 中期のレクリエーションのアイデア

### 役に立つ家事

- **タオルやおしぼりをたたむ。** 小さく平らなものがいちばんかんたんです。温かいおしぼりを入れたかごがあれば、たたんで、しわを伸ばして、またたたみ直せます。
- **靴下を組み合わせる。** まずは見た目がまったく違う数組から。色だけで分けるのでもかまいません。
- **割れない食器を洗う、ふく。** 温かい石けん水は手に心地よいものです。座ってふけば、足への負担も軽くなります。
- **食卓を整える。** 一度に一種類ずつ手渡し、ひと席分はお手本としてあなたが並べておきましょう。
- **夕食の支度を手伝ってもらう。** じゃがいもを洗う、レタスをちぎる、ボウルの中を混ぜるなど。包丁と火はあなたが扱います。
- **掃く、ほこりを払う、ふく。** テーブル用のふきん、玄関先用の軽いほうきなど。

さらに多くのアイデアは[家事を使ったレクリエーション](/activities/household-tasks/)をご覧ください。

### 音楽と体を動かすこと

- **昔なじみの歌を歌う。** あなたが歌い始めましょう。何十年も親しんできた歌なら、いっしょに歌い出す方が多くいます。[音楽を使ったレクリエーション](/activities/music/)もご覧ください。
- **自由に踊る。** 体を揺らす、手をたたくなど、心地よいように動きましょう。座ったままでもかまいません。
- **風船を投げ合う。** ゆっくり動くので、椅子に座ったままでも受け止めやすいです。
- **付き添って散歩する。** なじみのある短い道をいっしょに一周しましょう。そのほうが安心なら、腕を組んで。

### 写真とお話

- **アルバムを眺める。** 質問するのではなく、見えたものについて話しましょう。「すてきな車ね。この車のこと、聞かせて」。[回想を使ったレクリエーション](/activities/reminiscence/)もご覧ください。
- **会話カードを使う。** [会話カード](/games/conversation-cards/)は、絵と、試すことのない答えの自由な問いかけを組み合わせたカードです。
- **いっしょに昔の映画を観る。** なじみのある作品を選び、そばにいて、ときどき止めて休憩しましょう。

### プレッシャーのない、かんたんなゲーム

- **絵が見えたままの絵合わせ。** [絵合わせ](/games/picture-pairs/)は絵を見えたままにできるので、覚えるのではなく、見て気づくゲームになります。
- **同じ絵さがし。** [同じ絵さがし](/games/find-the-same/)は一枚の絵と、二〜四つの選択肢だけを表示します。
- **いっしょに仕分け。** [いっしょに仕分け](/games/sort-together/)は、画面の上で洗濯物を仕分けるようなゲームです。絵をタップして、次にそのかごをタップします。
- **絵ビンゴ。** [絵ビンゴ](/games/picture-bingo/)は家族の集まりやグループによく合います。

ゲームでいら立ちが見え始めたら、やめて別のことをしましょう。[認知症のある方といっしょにゲームを楽しむコツ](/caregiving/how-to-play-together/)もご覧ください。

## 落ち着かなさをレクリエーションに変える

落ち着かない様子やくり返しの行動には、理由があることがよくあります。米国家族介護者連盟は、押し入れの中身を何度も出してしまう方は、忙しくしていたい、何かの役に立ちたいという気持ちを満たそうとしているのかもしれないと指摘しています。米国アルツハイマー病協会は、そうしたエネルギーを止めるのではなく、それに合うレクリエーションへと向けることを勧めています。

| 見られる様子 | 勧めてみること |
| --- | --- |
| テーブルをこする、つまむ | 湿らせたふきんを渡して、テーブルをふいてほしいと頼む |
| 足が落ち着かない、指でトントンたたく | 拍子のはっきりした音楽に合わせて、足や手でリズムをとる |
| 引き出しや押し入れの中身を出す | たたんだり仕分けたりする服やおしぼりを入れたかご |
| 同じ質問をくり返す | 安心できる言葉をかけてから、歌や家事をいっしょにする |
| 歩き回る | いっしょに散歩する、または物を運ぶ仕事を頼む |
| 夕方になると落ち着かない | 明るい場所で、落ち着いたなじみのある作業を。[夕方の落ち着かなさ（夕暮れ症候群）](/caregiving/late-day-restlessness/)もご覧ください |

## やめどき、変えどき

そわそわする、顔をしかめる、物を押しのける、「できない」と言うなど、疲れ、いら立ち、恥ずかしさ、退屈のサインが見えたらやめましょう。米国アルツハイマー病協会は、別の時間帯にもう一度試すか、レクリエーションをもっとかんたんにすることを勧めています。無理強いはしないでください。断るのは、不安や、その作業が難しすぎることが理由かもしれません。[「いや」と言われたとき](/caregiving/when-they-say-no/)もご覧ください。

早めに終えてもかまいません。お茶を飲みながら、ただいっしょに座っているのも良いことです。できることがさらに変わってきたら、[後期の認知症の方とのレクリエーション](/activities/late-stage/)のアイデアのほうが合うかもしれません。[レクリエーションのアイデア101](/activities/ideas/)にも、試せることがたくさんあります。
