自分や大切な人の記憶に変化が出てきたと気づくのは、不安なことです。このページは、いつ受診の予約をとるか、どう準備するかを考える助けになります。ただし、誰かが認知症かどうかを判断することはできません。**認知症を診断できるのは、資格のある医療者だけです。**また、物忘れの原因になる状態の多くは、認知症ではありません。ネット上のクイズや自己チェックには頼らないでください。

## 認知症の初期サインは？

[米国アルツハイマー病協会](https://www.alz.org/alzheimers-dementia/10_signs)は、10の初期サインを挙げており、それぞれに、年齢にともなう一般的な変化を比較として添えています。ここでは私たちの言葉で紹介します。

| 確認したほうがよいサイン | 年齢とともにあり得る変化 |
| --- | --- |
| 日常生活に支障が出る物忘れ。たとえば、最近の出来事を忘れる、同じことを何度も尋ねる | ときどき名前や約束を忘れるが、あとで思い出す |
| 計画を立てたり問題を解決したりするのが難しい。たとえば、慣れたレシピに沿って作る、請求書の管理をする | 家計の支払いで、たまにミスをする |
| 家庭や職場、外出先で、慣れた作業を終えるのが難しい | 電子レンジの設定や、テレビの録画で、たまに助けが必要になる |
| 日付や季節、今いる場所が分からなくなる | 曜日を間違えても、あとで気づく |
| 距離感をつかむ、文字を読む、色を見分けるのが新たに難しくなる | 白内障による見え方の変化 |
| 言葉に新たな問題がある。たとえば、会話の途中で止まる、物の名前を間違える | ときどき、ぴったりの言葉が出てこない |
| 物を普段と違う場所に置き、たどって探せない | ときどき物を置き忘れても、たどって見つけられる |
| お金や身だしなみなどで、判断力が落ちる | たまに、よくない判断をする |
| 趣味や仕事、人づきあいから離れていく | ときどき、親族の集まりや人の集まりに行く気がしない |
| 気分や性格が変わる。たとえば、混乱する、疑い深くなる、怖がる、不安になる | 自分なりのやり方があり、決まった流れが崩れるといら立つ |

サインがひとつあるだけでは、認知症とは限りません。大切なのは、**その人のふだんの状態からの変化**、とくに日常生活を難しくする変化です。

## 年齢による変化と認知症は、どう違いますか？

[米国国立老化研究所（NIA）](https://www.nia.nih.gov/health/memory-loss-and-forgetfulness/memory-problems-forgetfulness-and-aging)は、多くの高齢者が、物事を思い出すのに時間がかかったり、ときどき物の置き場所や請求書の支払いを忘れたりすることに気づくと述べています。これらは、たいてい軽い物忘れのサインです。**認知症は、年を取れば誰でもなるものではありません。**深刻な記憶の問題は、運転、電話の使用、家への帰り道など、ふだんの活動を難しくします。

NIAは、次のような様子があれば、医師に相談することを勧めています。

- 同じ質問を何度もくり返す
- よく知っていた場所で迷う
- レシピや道順に従うのが難しい
- 時間、人、場所についての混乱が増える
- 自分の世話をしなくなる。たとえば、食事が偏る、入浴しない、危険な行動をとる

**軽度認知障害（MCI）**のある方もいます。これは、同じ年齢の人より記憶や思考の問題が多いものの、日々の生活はなんとか送れている状態を指します。NIAは、MCIはアルツハイマー病の初期サインである可能性があるが、MCIのある人が全員アルツハイマー病になるわけではないと述べています。

## 物忘れの原因として、ほかに何がありますか？

認知症以外にも、記憶に影響するものは多く、治療で良くなるものもあります。NIAは、次のものを挙げています。

- **甲状腺、腎臓、肝臓の病気**
- **薬の副作用**
- **うつや不安**
- **ビタミンB12の不足**、または健康的な食事が足りていないこと
- **睡眠の問題**
- **アルコールや薬物の乱用**
- 脳の**感染症、血栓、腫瘍**
- **頭のけが**。たとえば脳しんとう
- **大きなストレスや悲しみ**。たとえば、退職や配偶者との死別

聴力や視力の問題が、混乱と間違えられることもあります。[聴力のガイド](/brain-health/hearing/)もご覧ください。これが、医学的な確認が大切な理由です。[米国アルツハイマー病協会](https://www.alz.org/alzheimers-dementia/diagnosis/visiting-your-doctor)によると、医師は甲状腺の問題、ビタミン不足、感染症を調べるために、血液検査を指示することがよくあります。よい[睡眠](/brain-health/sleep/)や、うつの治療についても、医師に相談する価値があります。

## 急な混乱は、緊急事態です

**数時間から数日のうちに急に起きた混乱は、すぐに医療機関を受診する必要があります。**せん妄の可能性があります。[米国退役軍人省（VA）はせん妄について](https://www.va.gov/geriatrics/pages/delirium_when_should_i_worry_about_delirium.asp)、医療上の緊急事態と説明し、本人のかかりつけの医療者にすぐ連絡するか、911に電話するよう勧めています（米国の場合。日本では、状況に応じて、かかりつけ医や救急相談、119番に連絡してください）。次のような様子が見られます。

- 考えがはっきりしているときと、そうでないときの波がある
- 注意を向けるのが難しい
- 考えがまとまらない
- 異常に眠そうにしている、または異常に落ち着きがなく、興奮している

これは、すでに認知症のある方を含め、誰にでも起こり得ます。[英国国民保健サービス（NHS）](https://www.nhs.uk/symptoms/confusion/)によると、よくある原因には、感染症（尿路感染症は高齢者や認知症のある方に多く見られます）、脳卒中、糖尿病のある方の低血糖、頭のけが、一部の薬があります。助けが来るまでの間は、本人のそばにいて、短くやさしい言葉で安心させましょう。たくさん質問するのは避け、飲んでいる薬を控えておいてください。

## 受診の準備は、どうしたらいいですか？

よい診察は、よいメモから始まります。[米国アルツハイマー病協会](https://www.alz.org/alzheimers-dementia/diagnosis/visiting-your-doctor)は、次のものを持っていくことを勧めています。

1. **変化の一覧**。記憶、気分、行動の変化を、具体的な例と、おおよそいつ始まったかとともに
2. **過去と現在の健康上の問題**。物忘れの家族歴があれば、それも
3. **処方薬と市販薬のすべて**
4. **ビタミン剤やサプリメント**
5. **質問したいこと**。たとえば、どんな検査をするのか、どのくらいかかるのか、結果はいつ分かるのか

本人をよく知る家族や友人に付き添ってもらうのもよい方法です。[NIAによると](https://www.nia.nih.gov/health/alzheimers-symptoms-and-diagnosis/how-alzheimers-disease-diagnosed)、医師は、本人と家族の両方に、健康状態、薬、日常の活動、行動の変化について尋ねることがあります。医師は次のようなこともします。

- 記憶、問題解決、注意、計算、言語の検査をする
- ほかの原因を調べるため、血液検査、尿検査などを指示する
- うつなど、ほかの心の健康の問題がないか確認する
- CTやMRIなどの脳の画像検査を指示する
- 老年科医、神経内科医、老年精神科医、神経心理士などの専門家を紹介する

NIAによると、米国では、認知機能の評価は、メディケアの年1回の健康診断（Annual Wellness Visit）の必須項目で、心配ごとを相談する自然な機会になり得ます。日本でも、かかりつけ医や、地域の相談窓口（地域包括支援センター）、認知症疾患医療センター、もの忘れ外来などで相談できます。医師が使う短い検査でさえ、それだけでは認知症を診断するのに十分ではありません。それらは、より詳しい評価への第一歩であり、診断には1回以上の受診が必要なこともあります。NIAは、記憶の問題がある方は6〜12か月ごとに受診することを勧めています。

## やさしく切り出すには

ほかの人のことが心配なときは、落ち着いた、人目のない時間を選びましょう。気づいた具体的なことを、非難ではなく、健康を気づかう気持ちとして伝えます。「健康診断を受けてみない？」と持ちかけるほうが、不安を与えにくいこともあります。決めごとには本人も加わってもらい、ひとりの大人として話しかけてください。[コミュニケーションのコツ](/caregiving/communication-tips/)もお役に立つかもしれません。

## 医師に相談を

記憶、思考、気分、ふだんの能力に、新しい変化が続いてみられるときは、かかりつけ医（内科など）に予約をとりましょう。急な混乱があるときは、すぐにかかりつけの医療者に連絡するか、119番（米国では911）に電話してください。早めに受診すれば、治療できる原因が見つかるかもしれません。認知症であれば、準備や支援を探す時間が長くとれます。この過程では、ご自身もいたわってください。[介護する方のセルフケアのガイド](/caregiving/caregiver-self-care/)もご覧ください。

このページは一般的な情報であり、医療上の助言ではありません。[医療に関する免責事項](/medical-disclaimer/)もご覧ください。
