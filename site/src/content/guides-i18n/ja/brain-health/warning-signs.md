記憶の変化に気づくと、自分自身のことでも、愛する人のことでも、不安になることがあります。このページは、いつ医師の診察を受けるか、そしてそれにどう備えるかを決める助けになります。誰が認知症かどうかを教えることはできません。**認知症を診断できるのは資格のある医療者だけ**で、記憶の問題を引き起こす病気の多くは認知症ではありません。ネットのクイズや自己診断に頼らないでください。

## 認知症の初期サインにはどのようなものがありますか?

[アルツハイマー協会](https://www.alz.org/alzheimers-dementia/10_signs)は10の初期サインを挙げています。それぞれを、年齢相応のよくある変化と比較しています。私たちの言葉でまとめると:

| 確認する価値のあるサイン | 年齢を重ねるとよりよくあること |
| --- | --- |
| 最近の出来事を忘れたり、同じことを何度も聞いたりするなど、日常生活を妨げる記憶の衰え | 名前や予定を忘れても、あとで思い出すことがある |
| なじみのあるレシピを追ったり、請求書を管理したりするなど、計画や問題解決が難しい | 家計の請求書で時々間違える |
| 家庭、職場、外出先でなじみのある作業を最後まで終えられない | 電子レンジの設定やテレビ番組の録画で時々助けが必要になる |
| 日付、季節、今いる場所がわからなくなる | 曜日を間違えても、あとでわかる |
| 距離感、読み書き、色の区別が新たに難しくなる | 白内障による視力の変化 |
| 会話の途中で止まったり、物を別の名前で呼んだりするなど、言葉の新しい問題 | 時々、適切な言葉が見つからない |
| 物を普段と違う場所に置き、あとから見つけられない | 時々物を置き忘れても、足取りをたどって見つける |
| お金や身だしなみなど、判断が悪くなる | 時々、あまりよくない判断をする |
| 趣味、仕事、社交活動から引きこもる | 時々、家族や社交の場に行きたくないと思う |
| 混乱したり、疑い深くなったり、恐れたり、不安になったりするなど、気分や性格の変化 | 決まったやり方があり、日常が乱されるとイライラする |

サインが一つだけでは、認知症を意味しません。大切なのは、**その人にとって普通だったことからの変化**、特に日常生活を難しくする変化です。

## 普通の加齢は認知症とどう違いますか?

[米国立老化研究所 (NIA)](https://www.nia.nih.gov/health/memory-loss-and-forgetfulness/memory-problems-forgetfulness-and-aging)によると、多くの高齢者は、思い出すのに時間がかかったり、時々物を置き忘れたり、請求書を忘れたりすることに気づきます。これらは通常、軽い物忘れのサインです。**認知症は加齢の正常な一部ではありません。**運転や電話の使用、家への帰り道といった日常生活が難しくなるほどの深刻な記憶の問題です。

NIAは、次のような場合に医師と相談することを勧めています:

- 同じ質問を何度も繰り返す
- 以前はよく知っていた場所で迷う
- レシピや道順を追うのが難しい
- 時間、人、場所についてますます混乱する
- 食事が不十分になる、入浴しない、安全でない行動をとるなど、自分自身のケアをやめる

**軽度認知障害 (MCI)** の人もいます。これは、同世代のほかの人よりも記憶や思考の問題が多いものの、日常生活は自分で管理できている状態です。NIAによると、MCIはアルツハイマー病の初期サインである可能性がありますが、MCIの人が皆アルツハイマー病を発症するわけではありません。

## 記憶の問題を引き起こすほかの原因には何がありますか?

認知症以外にも記憶に影響するものは多く、治療で改善するものもあります。NIAが挙げるのは:

- **甲状腺、腎臓、肝臓の問題**
- **薬の副作用**
- **うつと不安**
- **ビタミンB12不足**、または健康的な食事が足りないこと
- **睡眠の問題**
- **アルコールや薬物の過剰使用**
- 脳内の**感染症、血栓、腫瘍**
- **頭部のけが**、たとえば脳震盪
- **大きなストレスや悲しみ**、たとえば退職や配偶者の喪失

聴覚や視覚の問題が混乱と間違われることもあります。私たちの[聴覚ガイド](/brain-health/hearing/)をご覧ください。だからこそ、医療的な確認が大切です。[アルツハイマー協会](https://www.alz.org/alzheimers-dementia/diagnosis/visiting-your-doctor)によると、医師は甲状腺の問題、ビタミン不足、感染症を確認するために血液検査を依頼することがよくあります。よい[睡眠](/brain-health/sleep/)と、うつの治療も相談する価値があります。

## 突然の混乱は緊急事態です

**数時間から数日で急に起こる混乱には、早急な医療が必要です。** 譫妄の可能性があります。米退役軍人省 (VA) は[譫妄](https://www.va.gov/geriatrics/pages/delirium_when_should_i_worry_about_delirium.asp)を医療上の緊急事態と説明し、その方の医療提供者にすぐ連絡するか、911に電話することを勧めています。サインには次のものがあります:

- 思考がはっきりするかどうかの波
- 注意を払うのが難しい
- 思考がまとまらない
- いつもより眠そう、またはいつもより落ち着きがなく興奮している

これは、すでに認知症とともに暮らしている人を含め、誰にでも起こりえます。[NHS](https://www.nhs.uk/symptoms/confusion/)によると、よくある原因には感染症 (高齢者や認知症のある人では尿路感染症がよく見られます)、脳卒中、糖尿病の人の低血糖、頭部のけが、一部の薬があります。助けを待つ間は、その人のそばにいて、短く簡単な言葉で安心させてください。多くの質問はせず、服用している薬をメモしてください。

## 受診にはどう備えればよいですか?

よい診察は、よいメモから始まります。[アルツハイマー協会](https://www.alz.org/alzheimers-dementia/diagnosis/visiting-your-doctor)は、次を持参することを勧めています:

1. 記憶、気分、行動の**変化のリスト**。具体的な例と、だいたいいつ始まったか
2. 家族に記憶の問題がある場合も含めた、**過去と現在の健康上の問題**
3. **処方薬と市販薬すべて**
4. **ビタミンやサプリメント**
5. どんな検査が行われるか、どのくらいかかるか、結果はいつ出るかなど、**質問**

その人をよく知る家族や友人を連れてくるのも役立ちます。[NIAは説明しています](https://www.nia.nih.gov/health/alzheimers-symptoms-and-diagnosis/how-alzheimers-disease-diagnosed)が、医師はその人本人と家族の両方に、健康、薬、日常の活動、行動の変化について尋ねることがあります。医師は次のようなことも行う場合があります:

- 記憶、問題解決、注意、計算、言語の検査を行う
- ほかの原因を探すため、血液、尿、その他の検査を依頼する
- うつやその他の精神健康状態を確認する
- CTやMRIなど、脳の画像検査を依頼する
- 老年医学専門医、神経科医、老年精神科医、神経心理学者などの専門医を紹介する

NIAは、認知機能評価がメディケアの年次健康診断の必須部分であり、懸念を伝える自然な機会になることを指摘しています。医師が使う簡易検査だけでは、認知症を診断するには十分ではありません。これらはより詳しい評価への第一歩であり、診断には複数回の受診が必要になることもあります。NIAは、記憶の問題がある人は6〜12か月ごとに医師を再受診することを勧めています。

## 優しく話題を切り出す

ほかの人のことで心配な場合は、落ち着いた、プライベートな瞬間を選んでください。批判ではなく、その人の健康への心配として、気づいた具体的なことを話してください。一般的な健康診断を提案すると、それほど不安に感じないかもしれません。その人を決定に含め、大人として話しかけてください。私たちの[コミュニケーションのヒント](/caregiving/communication-tips/)が役立つかもしれません。

## 医師に相談しましょう

記憶、思考、気分、日常の能力に、新しく繰り返し起こる変化に気づいたら、かかりつけ医に予約を入れてください。突然の混乱には、すぐに911に電話するか、その方の医療提供者に連絡してください。早めに確認することで、治療できる原因を見つけられ、認知症だった場合でも、計画を立て支援を見つける時間が増えます。この間も自分自身を大切にしてください。私たちの[介護者セルフケアガイド](/caregiving/caregiver-self-care/)をご覧ください。
