“我想回家。”对许多家人来说，这是最难听到的话之一，尤其是当您照顾的人正坐在自己的客厅里时。这种情况很常见，痴呆的任何阶段都可能出现，而且有平静、实用的应对方法。本页说明这些话通常意味着什么，可以怎么说，哪些活动能在当下起到帮助，以及如何保持安全。

## 为什么患有痴呆的人一再说要回家？

通常，“家”更像是一种感受，而不是一个地方。英国阿尔茨海默病协会（Alzheimer's Society）将它描述为一种舒适和安全感，或过去的一个家，而不是房子本身。痴呆会让熟悉的房间看起来很陌生，人也可能觉得自己回到了生命中更早的阶段，那时的家是童年的房子，或是抚养孩子的地方。

这些话也可能说明当下有其他问题：他们可能饿了、渴了、需要上厕所、疼痛、太热或太冷、疲倦、孤单、害怕，或被噪音弄得不知所措。[美国国家老龄研究所](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/coping-agitation-aggression-and-sundowning)列出，疼痛、噪音、孤单、作息改变和药物都可能导致激动不安。

## 当他们说要回家时，我应该怎么说？

回应的是感受，而不是字面的话。[家庭照护者联盟](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建议不要试图说服对方他们错了：他们的感受是真实的，因此应先以安慰和安抚回应，再温和地转移注意力。

以下说法通常有帮助：

- **说出感受。** “听起来你很想家。”
- **给予安抚。** “你在这里很安全，我会陪着你。”[阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/stages-behaviors/anxiety-agitation)建议使用简单的话语：“你在这里很安全。”
- **邀请回忆。** “跟我讲讲你的家吧。你们的厨房是什么样子的？”询问遥远的过去，通常比询问今天的事情更让人自在。
- **一起做点什么。** “我们先喝杯茶吧。”或“你能帮我叠这些毛巾吗？”

如果对方喜欢身体接触，温和的语气和轻轻握住对方的手臂，可能比言语更有力量。

## 应该避免什么？

- **争辩或解释。** “你现在住在这里”或“这里已经是你住了 40 年的家了”，会要求对方接受一件痴呆让他们很难接受的事，并让他们觉得自己被说错了。
- **追问。** “你不记得了吗？”或“地址是什么？”会增加压力。
- **生气地挡住门。** 如果对方想要出去，请保持冷静，陪他们一起走。一段短暂的散步通常能平息这种冲动。
- **催促。** 在转换话题前，请给对方时间谈谈家的事情。

## 当下可以帮助的活动

在您回应了这种感受之后，一个平静、熟悉的活动可以转移注意力，同时又不会否定对方的感受。

1. **一起看家人和家里的照片。** 翻看相册，多作评论（例如“看那个花园”），而不是提问。在手机或平板电脑上，[照片配对](/games/photo-pairs/)可以把您自己的家庭照片变成一个温和的配对游戏，照片始终保存在您的设备上。
2. **谈论家。** [谈话卡](/games/conversation-cards/)提供关于房子、厨房、邻居和节日的开放式提示，没有标准答案。
3. **播放他们喜爱的音乐。** 美国国家老龄研究所将舒缓的音乐列为平息激动的方法之一。请参阅我们的[音乐活动](/activities/music/)。
4. **吃点东西或喝点什么。** 饥饿和口渴可能看起来像焦躁不安。一杯茶或他们喜欢的小点心，也是一种“在家”的小仪式。
5. **散步或坐在户外。** 活动和日光都有帮助，尤其是在一天的早些时候。
6. **交给他们一项熟悉的工作。** 叠衣服、整理餐具或浇花，可以让人重新找回管理家务的感觉。
7. **让一切慢下来。** 关掉电视，减少噪音和强光，并尝试一起进行一次[平静呼吸](/games/calm-breathing/)。

如果某个办法没有效果，过一段时间再尝试另一种。静静地待在一起，也是很好的结果。

## 检查可以解决的原因

| 检查项目 | 可以尝试的做法 |
| --- | --- |
| 饥饿或口渴 | 提供一杯饮料和一点小点心 |
| 需要上厕所 | 平静、不大惊小怪地提议去一下卫生间 |
| 疼痛或不适 | 留意皱眉、揉按身体某个部位或便秘等迹象，并告诉他们的医生 |
| 太热或太冷 | 增减衣物，或调节房间温度 |
| 噪音或人多 | 换到比较安静的房间，关掉电视 |
| 疲倦或过度刺激 | 休息，调暗房间灯光，播放轻柔的音乐 |
| 傍晚时分 | 请参阅下面的日落综合征部分 |

阿尔茨海默病协会建议，简单记录下这种询问出现的时间，例如饭前、访客离开后，或黄昏时。找到规律有助于提前做好安排。

## 可以说善意的谎言吗？

这是一个真正有争议的问题，充满善意的家人会有不同的选择。阿尔茨海默病协会表示，没有唯一正确的答案：谎言可能让一些人变得更加多疑，因此应当判断什么符合对方的最佳利益，并保持一致。在 Penn Memory Center，其联合主任的观点是，应以真相为默认选择，只有当对方无法理解某个特定的真相时，才可以接受温和的谎言，而且永远不要嘲笑对方的现实感受。

许多照顾者发现，一种折中的方式有效：先给予诚实的安慰和转移注意力（例如“我们今晚就待在这里，我就在你身边”），而不与对方争论“家”究竟在哪里。

## 如果每天下午或傍晚都这样，怎么办？

在傍晚开始或加重的烦躁不安，通常被称为日落综合征。[美国国家老龄研究所](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/coping-agitation-aggression-and-sundowning)建议保持稳定的作息，每天接触阳光并保持活动，减少傍晚的小睡，并在傍晚之后避免摄入咖啡因和酒精。在天黑之前开灯也会有帮助。我们关于[傍晚平静活动](/caregiving/late-day-restlessness/)的指南有更多内容。

## 如果对方想离开，如何保证其安全？

要求回家可能会导致游走。[阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/stages-behaviors/wandering)估计，患有痴呆的人中，每十人里约有六人至少会游走一次。

**提前做好准备：**

- 佩戴写有对方姓名和您电话号码的身份或医疗手环，并在其衣物上做标记。[美国国家老龄研究所](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/coping-alzheimers-behaviors-wandering-and)提到了 MedicAlert 以及阿尔茨海默病协会的 Safe and Found 项目，这些服务可能需要付费。
- 安装门铃或警报器，并在高处或低处安装门锁。切勿把对方独自锁在房间里。
- 准备一张近期的特写照片，以及一份他们可能去的地方的清单，例如以前的住所或工作地点。
- 告诉可信赖的邻居，并把您的电话号码留给他们。

**如果对方走失：** 请尽快联系当地警方或急救服务，同时在附近的安全地点查找。不要等待一个固定的时间才报告。2021 年，[美国司法部一篇关于失踪人员调查的期刊文章](https://www.justice.gov/usdoj-media/usao/media/1134031/dl?inline=)指出，执法机构不应规定固定的等待期；该文章还将类似痴呆的症状列为高风险因素。各地的报告程序有所不同。请告诉救援人员对方患有痴呆，提供最后已知的位置和一张近期照片，并听从他们的指示。如果有其他人可以帮忙，请让他留在电话旁。不要独自前往不安全的地方查找。

## 什么时候应该打电话给医生？

如果询问或意识混乱是突然出现的，或在数小时或数天内明显加重，请尽快联系他们的医生。[美国国家老龄研究所](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/alzheimers-caregiving-managing-personality-and)指出，突然或迅速变化的行为，尤其是在感染或更换药物之后，应立即进行检查。突然的意识混乱可能是谵妄，[NHS](https://www.nhs.uk/symptoms/confusion/)表示它需要紧急帮助；尿路感染是老年人中常见的原因。

在下一次就诊时，也可以提及一个稳定出现的规律，因为疼痛、情绪低落、睡眠问题或药物副作用都可能起到一定作用。
