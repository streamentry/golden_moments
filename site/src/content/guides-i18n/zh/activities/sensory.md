感官活动运用五种感官：触觉、嗅觉、味觉、听觉和视觉。它们不需要记忆，没有步骤，也没有标准答案，因此适用于任何阶段。它们在后期尤其重要。[阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/stages-behaviors/late-stage)指出，在后期阶段，人主要通过感官来体验世界，而您可以通过触摸、声音、视觉、味道和气味来表达关怀。做好几项安全检查，能让这些活动对每个人都更放松。

## 什么是失智症的感官活动？

感官活动，是围绕一种感官而设计的简单体验，例如摸摸布料、闻闻香草，或听听雨声。[英国国民保健服务（NHS）](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)指出，后期的活动往往需要以感官为重心，并提到音乐、可以触摸和拿在手上的物品，以及手部按摩。[美国阿尔茨海默病基金会](https://alzfdn.org/therapeutic-activities-for-3-main-stages-of-alzheimers-disease/)指出，后期的人可能非常需要抱住某样东西来获得安慰。

## 按感官分类的感官点子

### 触觉

- **手部按摩。** 在手心里加热一点乳液，然后从手腕慢慢按摩到指尖。[美国国家老龄研究所](https://www.nia.nih.gov/health/alzheimers-caregiving/care-last-stages-alzheimers-disease)提到，用无香味的乳液进行按摩，可以带来舒适感。
- **布料篮子。** 一篮大块的天鹅绒、灯芯绒、摇粒绒、缎子和羊毛布料，供对方抚摸、折叠，并谈论它们。
- **温热的毛巾。** 在寒冷的日子里，用温热、湿润的毛巾给双手保暖。先用您自己的手腕测试温度。
- **活动围裙或膝盖毯。** 牢牢缝上大纽扣、拉链、丝带和有纹理的布块。
- **折叠与抚平。** 一篮干净的小方巾或餐巾，供对方折叠、堆叠，再折一次。
- **有柔软的东西可以抱。** 一条摇粒绒毯子、一个靠垫，或一只逼真的柔软动物玩偶，简单地提供，而不是当作玩具。

### 嗅觉

- **新鲜香草。** 用手指轻轻揉搓薄荷、迷迭香、罗勒或薰衣草的叶子，然后让对方闻一闻。
- **厨房的气味。** 附近正在煮咖啡、烤面包、烤肉桂，或剥橙子。
- **鲜花。** 从花园或超市带一些新鲜的花进屋。
- **熟悉的产品。** 对方一直在用的肥皂或乳液，如果他的皮肤能够接受。

### 味觉

- **喜爱的味道。** 一小勺他喜爱的东西，例如苹果酱、布丁或冰淇淋，并且是以安全、他能够吞咽的质地提供。
- **一起烘焙时尝一尝。** 在烘焙时尝尝水果，或一点点糖霜。
- **应季的美食。** 夏天的西瓜，秋天的热苹果酒，在安全的温度下提供。

### 听觉

- **喜爱的音乐。** 以温和的音量播放熟悉的歌曲。参见[音乐活动](/activities/music/)。
- **大自然的声音。** 雨声、海浪或鸟鸣。美国国家老龄研究所指出，音乐、白噪音和自然声音，似乎能让一些人放松。
- **您的声音。** 朗读、哼歌，或讲一个故事。
- **简单的乐器。** 一个手鼓、摇铃或铃铛，用来伴随音乐。

### 视觉

- **看窗外。** 窗外挂着鸟食台，放学回家的孩子，或正在飘落的雪。
- **鱼缸或缓慢的影像。** 轻柔的动态，没有大声响。
- **大幅照片。** 一次只看一张清楚的照片，并与对方的视线同高。
- **颜色与图案。** 把鲜艳的布料碎片、花或彩色餐巾分类，或使用我们[填色](/games/coloring/)中的一张简单涂色页。
- **户外。** NHS 建议设置感官花园，种有香味植物，有各种质感，并设有水景。请参阅[户外与园艺活动](/activities/outdoor-and-gardening/)。

## 怎样制作感官盒？

1. **选一个与对方生活有关的主题，** 例如海边、花园、厨房、工作坊或缝纫。
2. **挑选五到六件大型、安全的物品，** 例如一个大贝壳、一把木勺、一条柔软的围巾、一小袋密封的干薰衣草，或一块光滑的木块。
3. **逐一检查每件物品，** 看看有没有小零件、锋利的边缘、松脱的线头，或易碎的部分。
4. **一次只拿出一件物品。** 交给对方，描述它，并让他自己去探索。
5. **活动结束后收起来。** 这样盒子里的东西会保持特别，下次使用前也会再次检查。

## 安全第一

感官活动很温和，但有几项风险需要注意。有些与失智症共同生活的人，可能会把非食物当成食物；而且随着时间推移，吞咽可能变得更困难。美国国家老龄研究所提醒，后期的吞咽问题会增加噎食的风险。

| 风险 | 应该怎么做 |
| --- | --- |
| 噎食 | 只使用大到无法吞下的物品。盒子里不要放散落的纽扣、珠子、硬币、弹珠或小玩具。食物只提供照护团队认为安全的质地。 |
| 看起来像食物的东西 | 美国国家老龄研究所建议锁好乳液、肥皂、洗发水和香水，因为它们可能看起来或闻起来像食物；也要移走假水果。用完感官用品后，要收好。 |
| 过敏 | 开始前，检查是否对坚果、乳胶、羊毛、植物或香料过敏。 |
| 浓烈的气味 | 避免浓烈的香水和精油，尤其是有哮喘或其他呼吸问题的人。温和、天然的气味比较安全。 |
| 皮肤 | 按摩前，检查皮肤是否有溃疡、破损或脆弱的地方。用轻柔的力道，如果对方皱眉，就停下来。 |
| 温度 | 先用您自己的手腕测试温热的毛巾和饮料的温度。 |
| 锋利或有毒的物品 | 不要使用锋利的工具、玻璃或有毒的手工用品。 |

## 芳香疗法有帮助吗？

大概没有可以测量到的效果。[Cochrane 对芳香疗法治疗失智症的系统综述](https://www.cochrane.org/evidence/CD003150_aromatherapy-dementia)审阅了13项研究，共708人，全部在养老机构中，发现没有令人信服的疗效证据。这些研究规模小，结果相互矛盾，副作用也报告不足。如果对方喜欢温和、熟悉的气味，例如花园里的薰衣草，那是分享它的好理由。但它不是一种治疗。

## 怎样提供感官活动？

- **选择一个安静的时刻，** 并关掉电视。
- **从正面靠近，** 叫出对方的名字，触碰前先询问或告知：“我这里有一些乳液，要不要给你的手按摩一下？”
- **一次只提供一样东西，** 以免让对方不知所措。
- **观察反应。** 脸部放松、双手松弛或微笑，都是好的迹象。如果对方缩手、皱眉或坐立不安，就表示该停下来了。
- **保持简短。** 五分钟的平静时光，就是很好的一次活动。

一起做一个缓慢的呼吸停顿，例如[平静呼吸](/games/calm-breathing/)，可以是一种温和的结束方式。如需更多床边的点子，请参阅[后期活动](/activities/late-stage/)；如果傍晚时分出现不安，请参阅[傍晚的坐立不安](/caregiving/late-day-restlessness/)。
