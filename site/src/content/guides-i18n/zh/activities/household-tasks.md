许多与失智症共同生活的人，都曾花几十年管理家务、养育家人或维持工作秩序。请他们帮忙做真实的家务，能比其他许多活动更清楚地传达一句话：“你仍然是这个家的一员。”本页介绍哪些任务通常效果好、怎样安排、如何随着情况变化而调整，以及如何让厨房和洗衣房保持安全。

## 为什么日常家务适合当作活动？

家务之所以有效，是因为它们熟悉，而且有明确的目的。美国国家老龄研究所列出了洗碗、摆餐桌、扫地、除尘、整理邮件、折叠衣物和分拣回收物等[人们可能喜欢的日常活动](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)。阿尔茨海默病协会指出，摆餐桌之类的任务，能让人[感到自己是家中受重视的一员](https://www.alz.org/help-support/caregiving/daily-care/activities)。

家务本身也带有开始的理由。“能帮我折这些毛巾吗？”比“你想不想做个活动？”更容易让人答应。

## 哪些家务适合尝试？

从对方过去做过的事情开始，再配合他今天能做到的程度。

### 洗衣和床单

- **折毛巾和小方巾。** 把一篮小而平的物品交给对方。毛巾比较宽容，折法没有对错。
- **配对袜子。** 把一堆混在一起的袜子放在桌上。如果很难找到配对，就只用两三种颜色差异很大的袜子。
- **抚平和叠放。** 餐巾、枕套或擦碗巾，可以抚平后叠放。当折叠的步骤变得太多时，这项工作就特别有用。

### 餐桌与厨房

- **摆餐桌。** 先摆好一个位置作为示范，让对方照着做。如果这样仍然太多，就一次只交一样东西：“这是每个盘子旁边的叉子。”
- **分拣餐具。** 把干净的叉子、汤匙和黄油刀放进一个盆里，再分进有隔格的托盘。尖锐的刀具不要放进去。
- **擦干碗碟。** 塑料或不易碎的餐具配上一块柔软的毛巾，这是一项安全的工作。
- **擦桌子或台面。** 用湿布擦干净的桌面。如果有人已经用手在桌上来回摩擦，阿尔茨海默病协会建议递给对方一块布，把不安的动作变成有用的动作。

### 家中的其他事

- **除尘。** 柔软的掸子，以及几个结实的表面，例如咖啡桌或书架。
- **整理邮件。** 把垃圾邮件和商品目录交给对方，分成几堆：保留、回收、以后再看。真正的账单和支票则放在别处。
- **分拣回收物。** 把干净的罐子、瓶子和纸张分进不同的回收箱。
- **扫地。** 如果平衡感稳定，可以在门廊或厨房地板上用一把小扫帚扫。
- **浇水。** 一个小而轻的洒水壶，加上几盆伸手就能够到的植物。

### 有监督的简单烹饪

烹饪可能唤起强烈而愉快的感受。美国国家老龄研究所建议，让对方取材料、量取、混合和倒入，或者只是告诉别人如何做一道喜欢的菜。适合的工作包括：

- 洗蔬菜或水果
- 搅拌面糊或凉拌菜
- 撕生菜
- 用钝刀给吐司抹黄油
- 把饼干面团放到烤盘上
- 在披萨上铺配料

如果量取变得困难，阿尔茨海默病协会建议由您先量好，再交给对方做另一个步骤，例如搅拌。

## 怎样安排一项家务，让它顺利进行？

1. **选对时间。** 选一天中对方通常比较休息、平静的时段。对许多人来说，这是早上。
2. **清理空间。** 一项任务，一个台面，桌上不要放其他东西。
3. **邀请，而不是指派。** “我需要一只手帮忙处理这些”比“该折衣服了”更有效。
4. **先示范第一个。** 慢慢折好第一条毛巾，再把下一条交给对方。示范比讲解更清楚。
5. **一次只给一个步骤。** 同时给太多指示可能让人不知所措。等一个步骤完成后，再说下一个。
6. **并肩工作。** 两人做同一件事，感觉是陪伴，而不是监督。
7. **谈任务，不谈结果。** “这些真柔软”或“跟我讲讲你以前是怎样整理被单柜的”，能引出对话，又不会考验任何人。

## 随着能力变化如何调整家务？

能力会随时间变化，甚至每天都不同。阿尔茨海默病协会建议，随着病情发展，逐步转向更简单、更重复的任务。

| 如果这件事变得困难 | 可以改为 |
| --- | --- |
| 折大床单 | 折小毛巾，或抚平餐巾 |
| 摆一整张餐桌 | 在每个座位放一块餐巾 |
| 把邮件分类 | 把信封叠成一摞 |
| 照着食谱做 | 搅拌，或在您做饭时看着并尝味道 |
| 扫整个地板 | 擦一张小桌子 |
| 根本无法做任务 | 在您做的时候陪着您，让您有人作伴 |

看也算数。美国国家老龄研究所指出，有些人只是喜欢看，这也是很好的参与方式。

## 怎样让家务保持安全？

安全最重要，尤其是在厨房。美国国家老龄研究所的[失智症照护者居家安全提示](https://www.nia.nih.gov/health/safety/alzheimers-caregiving-home-safety-tips)包括：

- 把清洁用品锁起来或移走，包括看起来像糖果的洗衣凝珠。
- 把刀具、剪刀和电动工具收在上锁的地方。
- 在炉灶上装上安全旋钮和自动断电开关。
- 在烤箱、烤面包机和熨斗附近放上写着“停止”或“很烫”的标识，并确保它们不会引燃物品。
- 把热水器设为120°F，以降低烫伤风险。
- 移走假水果，以及形状像食物的磁铁，它们可能看起来能吃。

还有几个实用的习惯也有帮助：

- 只要炉灶、烤箱或尖锐的工具在使用，就要留在房间里。
- 沥干碗碟和摆餐桌时，使用不易碎的餐具。
- 扫地或拖地时，保持地面干燥和无障碍。
- 如果对方以前用过工具，阿尔茨海默病协会建议从工作间中移走危险物品，这样像打磨一块木头这样的安全任务，仍然可以享受。

## 如果他们做得“不对”怎么办？

随它去。把毛巾折成三折而不是对折，它仍然是一条折好的毛巾。阿尔茨海默病协会说得很直接：重要的是共度时光，以及对方感到自己有用，而不是毛巾是否折得标准。如果某件事确实必须重做，就等到以后，并在对方看不到的时候做。

当场纠正，可能会把一件愉快的工作变成对方失去的能力的提醒。说一句“谢谢，你帮了我大忙”，几乎总是最好的回应。

## 什么时候应该停下来？

当您看到挫折、疲倦或兴趣减退的迹象时，就停下或换个活动。提早结束是很好的结果，而不是失败。您可以：

- 换成较简单的步骤
- 转向比较放松的事情，例如音乐或一杯咖啡
- 稍后或改天再试
- 干脆一起坐一会儿

如果对方说不，就不要勉强。请参阅[当他们说不时该怎么做](/caregiving/when-they-say-no/)，了解温和的应对方式。

## 安静时刻的轻松点子

如果无法进行体力上的家务，仍然可以坐着进行分类和配对。[一起分类](/games/sort-together/)让您可以把图片点进厨房或花园的篮子里，而[图片配对](/games/picture-pairs/)则是一个温和的配对游戏，图片大，没有计时器。[对话卡片](/games/conversation-cards/)提供关于家与家人的开放式话题，在家务完成后喝一杯咖啡时聊聊，很合适。
