中期通常是失智症最长的阶段，也是活动开始需要真正支持的时候。说话变得吃力，步骤容易乱，开始任何事情都可能觉得困难。但想要帮忙、想要参与的心愿通常还在。只要稍加准备，处于中期的人仍然能享受不少乐趣，尤其是熟悉的家务、音乐，以及和您并肩一起做的看图活动。

## 哪些活动适合中期失智症？

短暂、熟悉、需要动手、并拆成单独步骤的活动效果最好。[阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/stages-behaviors/middle-stage)指出，您不需要想出新花样：活动可以融入日常生活，例如一起做晚饭、园艺、听音乐或散步。

[美国阿尔茨海默病基金会](https://alzfdn.org/therapeutic-activities-for-3-main-stages-of-alzheimers-disease/)提到，这个阶段的人通常很需要觉得自己有用，或照顾某样东西，并且需要别人帮忙开始或继续一项活动。它列出的中期活动包括折叠衣物、洗碗、分类袜子、简单的运动、随着熟悉的音乐跳舞、短距离散步、一起唱歌、简单的绘画，以及翻看相册。

## 怎样设置活动才会成功？

大多数活动成败都取决于事前的准备。以下做法来自[阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/daily-care/activities)和[家庭照护者联盟](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)，最能带来改变：

1. **清出空间。** 关掉电视，关上房门，只摆出活动需要的东西。
2. **自己先开始。** 您先开始折叠或搅拌，再邀请对方加入：“能帮我一下吗？”
3. **示范，然后等待。** 示范一个步骤。用手指或手势引导，例如示意盘子应该放在哪里。
4. **每次只给一个步骤。** “对折一下”比“把这些折好，再按颜色叠起来”容易得多。
5. **给两个选择，而不是开放式问题。** “蓝色的毛巾还是白色的？”比“你想做什么？”更容易回答。
6. **难的部分由您来做。** 您量取材料，对方搅拌；您穿针，对方缠绕毛线。
7. **说明它的用处。** “这些餐巾是周日晚餐要用的”，会让这件事感觉真实。
8. **如果对方更喜欢，就让他看着。** [美国国家老龄研究所](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)指出，只是看着也可以很愉快。

## 中期阶段的活动点子

### 有用的家务

- **折叠毛巾和小方巾。** 小而平的物品最容易。一篮温热的小方巾，可以折好、抚平，再折一次。
- **配对袜子。** 先从几双颜色差别很大的袜子开始。只按颜色分类也很好。
- **洗或擦不易碎的餐具。** 温热的肥皂水让手感舒服。坐着擦干，对腿脚也更轻松。
- **摆放餐桌。** 一次只交给对方一种物品，并自己先摆好一个位置作为示范。
- **帮忙做晚饭。** 洗土豆、撕生菜，或搅拌一个碗里的食材。刀具和火由您来处理。
- **扫地、掸灰或擦拭。** 用抹布擦餐桌，用轻便的扫帚扫门廊。

更多家务点子，请见[家务活动](/activities/household-tasks/)。

### 音乐与律动

- **唱老歌。** 先由您自己开始唱，许多人会在唱了几十年的歌上加入。参见[音乐活动](/activities/music/)。
- **自由跳舞。** 摇摆、拍手或随自己的感觉动一动。坐着跳也很好。
- **传气球。** 气球移动得慢，坐在椅子上也容易接住。
- **一起散步。** 走一段短而熟悉的路线，如果需要，可以挽着手臂。

### 图片与故事

- **翻看相册。** 多评论您看到的，而不是提问：“看那辆车，跟我说说它。”参见[回忆活动](/activities/reminiscence/)。
- **使用对话卡片。** [对话卡片](/games/conversation-cards/)把一张图片和一个开放、无考问的话题配在一起。
- **一起看老电影。** 挑一部熟悉的，待在旁边，并在中间让对方休息。

### 简单、无压力的游戏

- **图片配对，图片保持可见。** [图片配对](/games/picture-pairs/)让图片一直显示，重点是注意到，而不是记住。
- **找找相同的。** [找找相同的](/games/find-the-same/)只显示一张图片和两到四个选项。
- **一起分类。** [一起分类](/games/sort-together/)就像在屏幕上分洗好的衣物：点一张图片，再点它该去的篮子。
- **图片宾果。** [图片宾果](/games/picture-bingo/)很适合家庭聚会和团体。

如果某个游戏开始让人沮丧，就停下来，改做别的事。请见[怎样一起玩](/caregiving/how-to-play-together/)。

## 把坐立不安变成一项活动

坐立不安或重复的行为通常有原因。[家庭照护者联盟](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)指出，一个人不停地清空橱柜，可能是想满足“我需要忙碌、有用”的需要。[阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/daily-care/activities)建议，把这份精力引导到一个相配的活动上，而不是直接制止。

| 您看到的情况 | 可以提供的活动 |
| --- | --- |
| 摩擦或抠桌面 | 一块湿抹布，请对方擦一擦桌子 |
| 脚不停动或手指敲打 | 节奏清楚的音乐，可以跟着拍手或敲打 |
| 翻抽屉或橱柜 | 一篮要折叠和分类的衣物或小方巾 |
| 一再问同一个问题 | 先给予安心，再一起唱歌或做一件家务 |
| 来回踱步 | 一起散步，或一件需要搬东西的工作 |
| 傍晚时分的不安 | 光线好的时候，做一件平静、熟悉的事；请见[傍晚的坐立不安](/caregiving/late-day-restlessness/) |

## 什么时候停下，或改变做法

当您看到疲倦、沮丧、尴尬或厌烦的迹象时，就该停下，例如坐立不安、皱眉、把东西推开，或说“我做不来”。[阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/daily-care/activities)建议，换一天中的另一个时段再试，或把活动变得更简单。不要勉强。拒绝可能来自害怕，也可能是任务太难了；请见[对方说不时](/caregiving/when-they-say-no/)。

提早结束没有关系。只是和对方一起坐着喝杯茶，也很好。随着能力进一步变化，[后期的活动](/activities/late-stage/)中的点子可能更合适，而[101个活动](/activities/ideas/)里还有更多可以尝试。
