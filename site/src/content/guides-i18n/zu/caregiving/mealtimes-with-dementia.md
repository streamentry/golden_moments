Ukudla kungaba nzima ukukulandela uma igumbi linomsindo, itafula ligcwele noma kukhona izinketho eziningi ngesikhathi esisodwa. Izinguquko ezimbalwa ezincane esimweni nasesivinini sokudla zingenza kube lula komuntu onesifo se-dementia ukuba yingxenye. Qala ngezinkambiso nezintandokazi zomuntu, futhi ugcine lokho okusebenza kahle.

Umhlahlandlela we-[Alzheimer's Association wokudla nokudla](https://www.alz.org/help-support/caregiving/daily-care/food-eating) kanye [neseluleko se-Dementia Australia ngesikhathi sokudla](https://www.dementia.org.au/living-dementia/home-life/eating-and-dementia) zombili zincoma indawo ethule, ukudla okujwayelekile nesikhathi esanele. Lo mhlahlandlela uhlanganisa isimo sesikhathi sokudla nokusekela kwansuku zonke. Akuwona uhlelo lokudla noma ukuhlolwa kokumunca.

## Singenza kanjani ukudla kube yisikhathi sokuhlanganyela ngaphandle kocindezelo?

Uma umuntu ethanda ukuba nabantu, hlala udle naye. Gcina ingxoxo ilula futhi mvumele agxile ekudleni uma efuna. Gwema ukumlungisa ngendlela asebenzisa ngayo insimbi noma ukumbuza imibuzo eyenza ukudla kube yisivivinyo. Uma itafula liba nomsindo noma linabantu abaningi, nciphisa inani labantu noma ahambele endaweni ethule.

Uma ukupheka sekuthathe amandla, ukudla okulungiselelwe okujwayelekile noma usizo kwingxenye yomsebenzi kungenza ukudla kube lula ukukuphatha. I-Dementia Australia iphakamisa ukudla okulethwa ekhaya noma okulungiselelwe njengezinketho uma kudingeka. Buza ukuthi yiziphi izinto umuntu azithandayo nohlobo losizo azoluvuma; ukulula akumele kuthathe indawo yokukhetha.

## Ngingenza kanjani itafula libe lula ukulilandela?

Yenza ukudla kubonakale kulula ngaphambi kokushintsha okuphakelwayo.

- **Nciphisa umsindo.** Vala umabonakude futhi wehlise eminye imisindo ephikisanayo. Hlala umuntu kude nendlela yabantu ekhishini uma lokho kumsiza agxile.
- **Susa izinto ezengeziwe.** Beka phansi kuphela izinsimbi nezinongo umuntu ayozisebenzisa. Hambisa amaphukuphuku, izimbali noma ezinye izinto ezingaphazamisa noma zingaphindwa njengokudla.
- **Sebenzisa ukuqhathanisa okucacile.** Ipuleti elilula elihlukile kumbala wetafula lingenza ukudla kube lula ukukubona. Gwema amaphethini anolaka emapuleteni nasezindwangu zetafula.
- **Hlola ukukhanya nokushisa.** Qinisekisa ukuthi umuntu uyayibona ipuleti, bese uhlola ukudla neziphuzo ngaphambi kokukuphakela ukuze kungashisi kakhulu.
- **Gcina uhlelo olujwayelekile.** Uma indawo, isikhathi noma uhlelo lwetafula kumjabulisa, zama ukukugcina kunjalo. Shintsha okubangela inkinga kuphela.

## Yini okufanele ngiyiphakele?

Qala ngokudla umuntu akwaziyo futhi akujabulelayo. Nikeza inkambo eyodwa ngesikhathi noma ukukhetha phakathi kwezinto ezimbili ezijwayelekile, kunokuba upuleti ligcwele izinto eziningi ezihlukene. Izingxenye ezincane zingaphinde zilungiswe uma umuntu efuna okwengeziwe.

Izintandokazi zingashintsha. Uma kwenqatshwa ukudla okuthandwa, gwema ukuxabana noma ukuphikisa. Nikeza enye inketho ejwayelekile, vumela umuntu aphumule, noma zama futhi kamuva. Ukudla akudingi ukulandela uhlelo oluqinile uma umuntu ekhathele noma ekhathazekile; gcina izikhathi zokudla ezivamile lapho zisebenza, bese ulungisa uhlelo ngokudingeka komuntu.

Uma ukupheka sekuba nzima, ilungu lomndeni lingasiza ngokulungiselela kuyilapho umuntu ehlanganyela emsebenzini ophephile amthandayo. Umhlahlandlela wethu [wemisebenzi yasekhaya](/activities/household-tasks/) unezindlela zokulungisa imisebenzi yasekhishini ngaphandle kokuyenza ukuhlolwa.

## Ngingasekela kanjani ukuzimela komuntu?

Vumela umuntu adle ngendlela ekhululekile futhi ephephile kuye. Angathanda isitsha, isipuni, ukudla okudliwa ngezandla noma ingxenye encane. Ungasheshi ukulungisa ukuchitheka noma ukuthatha umsebenzi umuntu asakwazi ukuwenza. Nikeza usizo uma lufunwa noma ludingeka, futhi unikeze isikhathi esanele sokudla.

Ukudla ndawonye kungenza ukudla kube yisikhathi sokuhlangana, uma umuntu ethanda ukuba nabantu. Hlala eduze, gcina ingxoxo ilula bese uvumela umuntu agxile ekudleni uma edinga lokho. Gwema imibuzo ehlola inkumbulo noma amazwana ngokuthi udle kangakanani. Uma umuntu emisa, linda ubuze ukuthi usekulungele yini okwengeziwe.

## Yini uma izikhathi zokudla zikhathaza?

Yima ubheke isizathu esisebenzayo. Igumbi lingase libe nomsindo; ukudla kungase kungajwayelekile; umuntu angase adinge ukusebenzisa indlu yangasese, aphumule noma ashintshe isimo. Zama ukulungisa okukodwa ngesikhathi, njengokususa itafula, ukunikeza amanzi noma ukuya endaweni ethule. Uma umuntu ekhathazekile, misa uzame futhi kamuva kunokumphoqa ukuba aqede.

Uma umuntu ehlala ekhaphela izidlo, ebonakala engakhululekile, enobunzima ekusebenziseni umlomo noma izandla, noma enoshintsho olusha ekudleni noma esisindweni, bhala lokho okubonayo bese ukhuluma nodokotela noma nesazi sokudla. Ubunzima obusha bokugwinya nokumunca, ukukhwehlela njalo lapho udla noma uphuza, noma ukuminyana kudinga iseluleko sochwepheshe. Isazi sezinkulumo nokumunca singahlola ukumunca futhi sinikeze amasu aphephile. Ungashintshi ukuqina kokudla, ungaqinisi iziphuzo noma usebenzise amasu okondla ngokusekelwe esiqondisweni esijwayelekile.

Ukudla okungaphelele kwesitsha esisodwa akuchazi ukuthi umuntu uyekeni. Bheka iphethini kuzo zonke izidlo: ukudla okuthile, isikhathi, izinga lomsindo noma indawo yokuhlala kungenza umsebenzi ube nzima. Uma into ethandwayo isiba nzima ngokuzumayo, hlola ukuphatheka noma ukungakhululeki emlonyeni, bese ubuza isazi sezempilo esikhundleni sokucabanga ukuthi umuntu uyanenga kanje.

Ngemibuzo yezempilo noma ukudla okukhethekile, buza isazi sezempilo somuntu. Ungaqali ukudla okuvimbelayo noma ushintshe imithi ukuze ushintshe isifiso sokudla ngaphandle kweseluleko. Umhlahlandlela we-[wokudla kwengqondo yezempilo](/brain-health/diet/) uxoxa ngocwaningo mayelana nokudla nengozi yedementia; uyahlukana nalo mhlahlandlela wokudla wansuku zonke.

## Ingabe ukudla kufanele kudliwe etafuleni njalo?

Cha. Uma ukuhlala etafuleni kukhathaza noma kudida, enye indawo enokukhululeka ingase isebenze kangcono, uma umuntu ekwazi ukudla ngokuphephile. Ukudla okuncane, isidlo esilula noma ukuphumula kungaba kukuhle kunokuzama ukuqeda isidlo esigcwele ngesikhathi esimisiwe.

Uma ukudla sekube nzima izinsuku ezimbalwa, noma uma ukhathazekile ngokudla, uketshezi noma ukumunca, xhumana nesazi sezempilo. Funa usizo lwezimo eziphuthumayo uma kukhona ingozi yokuminyana esheshayo.
