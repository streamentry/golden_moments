Ukunakekela umlomo kungokomuntu siqu. Umuntu ohlala ne-dementia angakhohlwa umkhuba ojwayelekile, athole ibhulashi lamazinyo lisesizayo ukulisebenzisa noma azizwe engakhululekile uma omunye umuntu enikeza usizo. Gcina umkhuba uthule futhi uhloniphe. Umuntu kufanele enze okukhulu angakwenza futhi akufisa ukukwenza.

Umhlahlandlela we-[Alzheimer's Association wokunakekela amazinyo](https://www.alz.org/help-support/caregiving/daily-care/dental-care) kanye [neseluleko se-Dementia Australia ngokunakekela amazinyo](https://www.dementia.org.au/living-dementia/staying-healthy/dental-care) baphakamisa ukusebenzisa umkhuba ojwayelekile, imiyalo emifushane nosizo lodokotela wamazinyo lapho kuvela izinkinga. Leli khasi linolwazi jikelele, hhayi iseluleko samazinyo noma uhlelo lokunakekela umuntu oyedwa.

## Ngingagcina kanjani ukunakekela komlomo okujwayelekile?

Sebenzisa isikhathi nendawo ejwayelekile kumuntu uma lokho usasebenza. Beka ibhulashi, ugesi wamazinyo nethawula lapho umuntu alindele khona. Chaza ukuthi yini oyenzayo ngaphambi kokuqala, bese unikeza isignali eyodwa elula ngesikhathi. “Thatha ibhulashi” kulula ukuyilandela kunokuba kube yimiyalo emide.

Nikeza umuntu isikhathi sokwenza isinyathelo ngasinye. Uma engahlanza ngokwakhe, mvumele. Uma isikhumbuzo sanele, linda ngaphambi kokunikeza usizo oluningi. Abanye abantu bathola kulula ukuhlala esinkwenjini noma basebenzise ibhulashi elinesibambo abangalibamba kahle. Buza udokotela wamazinyo ngezinketho uma ibhulashi ejwayelekile limbi ukulisebenzisa.

Ungayenzi ukuhlanza kube isivivinyo noma ukuncintisana. Uma umuntu ethi cha, ehlehla noma ethukuthele, misa. Zama futhi kamuva, shintsha isimo noma ucele iseluleko kodokotela wamazinyo. Ungaphoqi ibhulashi emlonyeni womuntu noma ubambe umuntu ukuze uqedele umsebenzi.

Uma umkhuba owawusebenza usuba nzima, qaphela ukuthi yiyiphi ingxenye enzima. Umuntu angase angazi ukuthi yenzenjani ngebhulashi, angathandi ugesi omusha, akhathele noma abe nokuzizwa kabi emlonyeni. Lezi yizinto ezingenzeka, hhayi ukuxilongwa. Inothi elifushane ngesikhathi ukuzwakala kwalokhu lingasiza udokotela wamazinyo axoxe ngezinyathelo ezilandelayo. Shintsha ingxenye eyodwa yomkhuba ngesikhathi ukuze kucace ukuthi umuntu uthanda yini.

## Ngingasiza kanjani ngivikela ubumfihlo?

Buza ngaphambi kokusiza, ngisho noma umuntu esesake wasizwa ngaphambili. Tshela ukuthi uzokwenzani bese ulinda impendulo yakhe. Uma evuma, vala umnyango, sebenzisa ithawula ukuvikela izingubo bese uvula kuphela ingxenye edingekayo. Vumelana ukuthi ngubani umsizi omzwela ngaye.

Uma umuntu edinga usizo lwesandla, chaza isinyathelo ngasinye ngaphambi kokusenza bese umisa uma ebonisa ukukhathazeka. Udokotela wamazinyo angakhombisa umkhuba ophephile wezidingo zomuntu. Ungazenzi ngokwakho ukusiza ngomzimba noma usebenzise indlela ongakaboniswa yisazi esiqeqeshiwe.

## Yini okufanele ngiyazi ngamazinyo amanga?

Gcina amazinyo amanga endaweni ejwayelekile ayiwo womuntu, ayaziwe kahle. Buza udokotela wamazinyo ukuthi kufanele ahlanzwe futhi agcinwe kanjani, nokuthi ukulingana kwawo kufanele kuhlolwe yini uma umuntu ekhathazeka. Uma amazinyo amanga asetshenziswa endaweni yokunakekela, makhombe isitsha sokugcina ukuze abasebenzi bakwazi ukuwuhlonza.

Ungaphoqi amazinyo amanga emlonyeni womuntu uma eyamukela noma uma ebonakala ebuhlungwini. Amazinyo amanga akhululekile noma ahlukile angenza ukudla kube nzima; buza udokotela wamazinyo ukuthi kufanele yenziwe yini. [Umhlahlandlela wethu wokudla](/caregiving/mealtimes-with-dementia/) uchaza ukulungiswa kokudla okuthulile nalapho izinkinga zokudla zidinga iseluleko sochwepheshe.

## Singalilungiselela kanjani ukuvakasha kodokotela wamazinyo?

Bhukha isikhathi lapho umuntu ejwayelekile ukuba sekhefu. Uma umuntu evuma, tshela ihhovisi lamazinyo ngaphambilini ukuthi kungase kudingeke isikhathi eside, incazelo ethulile noma usizo lomuntu amethembayo. Letha uhlu lwemithi olusha nesiqephu esifushane ngalokho okuye kwaba nzima, njengokuhlanza, ukudla noma ukugqoka amazinyo amanga.

Cela ithimba lamazinyo lichaze okuzokwenzeka sinyathelo ngesinyathelo. Umngane ajwayelene naye angasiza umuntu azizwe ehlala phansi, kodwa umuntu kufanele ahlale engxoxweni nasezinqumweni. Uma ukuya ehhovisi elijwayelekile kunzima, buza udokotela wamazinyo ngezikhathi zokuvakashela ezitholakalayo endaweni yakho.

## Abasizi abanye bangagcina kanjani uhlelo lufana?

Uma kukhona ilungu lomndeni, umsebenzi wekhaya noma isisebenzi sendlu yokunakekela sisiza, vumelana nomuntu ngohlelo ajwayelene nalo. Sebenzisa indawo efanayo ejwayelekile nesignali emfushane uma kungenzeka. Buza ukuthi uthanda yini ukuthi umuntu othile asize njalo.

Uma umuntu evumile, yabelana kuphela ngemininingwane ezosiza umsizi olandelayo: isikhathi esithandwayo, ayikwazi ukwenza ngokwakhe, isinyathelo esinzima nalapho efuna khona ukuthi usizo lumise. Gcina noma yiluphi uhlu olubhaliwe luyimfihlo futhi ulandele inqubo ejwayelekile yendawo yokunakekela. Uhlelo olubhaliwe kuyisiqondiso, hhayi imvume yokuqhubeka uma umuntu esho cha. Izinto zingashintsha, ngakho buza futhi uzivumelanise. Uma izindlela eziningi sezibe nzima, chaza engikubonile ithimba lamazinyo bese ucela iseluleko somuntu lowo.

## Yiziphi izimpawu okufanele ngizishe udokotela wamazinyo?

Ubuhlungu emlonyeni abuvamisile ukuchazeka kalula. Ukudonsa ubuso, ukwenqaba ukuhlanza, ushintsho ekudleni noma ukuphazamiseka kokulala kungaba yizinkomba, kodwa azifakazeli inkinga yamazinyo. Tshela udokotela ngalokho okubonile nangesikhathi esaqala ngaso. Udokotela angahlola ubuhlungu, inkinga yezinsini, ukubola kwamazinyo noma amazinyo amanga angasafaneleki kahle.

Uma umuntu eba nenkinga entsha yokugwinya noma yokumunca, xhumana nesazi sakhe sezempilo noma udokotela wamazinyo. Ungashintshi ukuqina kokudla, ungasebenzisi imithi yomlomo noma usebenzise amasu okumunca ngokusekelwe esihlokweni esivamile. Funa usizo oluphuthumayo uma kukhona ubuhlungu obukhulu, ukuvuvuka, ukopha noma enye inkinga ephuthumayo yezempilo.

Injongo ukuba nohlelo umuntu angalamukela, nosizo oluncane kakhulu. Isikhumbuzo esijwayelekile, isimo esiphumelelayo noma umzamo wakamuva kungase kwanele. Uma inkinga iqhubeka, buza udokotela wamazinyo ukuthi yiluphi usizo olufanele umuntu.
