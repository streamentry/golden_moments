Bingo ist für viele ältere Erwachsene ein vertrautes, geselliges Spiel, aber die Zahlen können für einen Menschen, der mit Demenz lebt, schwer zu verfolgen sein. Beim Bilder-Bingo bleibt der ruhige Ablauf erhalten, und die Zahlen werden durch große, klare Bilder ersetzt. Es funktioniert zu Hause, in einer Tagesbetreuung oder in einer Pflegeeinrichtung. Dieser Leitfaden erklärt, wie Sie spielen, wie Sie das Spiel anpassen und wie der Spaß im Mittelpunkt bleibt.

## So funktioniert Bilder-Bingo

Jede Person hat eine Karte mit einem Raster aus Bildern, zum Beispiel einer Teekanne, einer Katze, einer Rose, einem Segelboot oder einem Fahrrad. Ein Ansager zeigt oder nennt ein Bild nach dem anderen. Die Teilnehmenden markieren das passende Bild auf ihrer Karte. Wer eine ganze Reihe markiert hat, oder die Kombination, auf die sich die Gruppe geeinigt hat, kann „Bingo“ rufen, aber viele Gruppen lassen den Gedanken an einen Gewinner ganz weg.

Sie können die Karten zum Ausdrucken aus unseren [kostenlosen Aktivitäten zum Ausdrucken](/activities/printable/) verwenden oder das [Bilder-Bingo-Spiel](/games/picture-bingo/), das einen digitalen Ansager für Gruppen enthält. Beides funktioniert gut auf einem Tablet, das Sie für die ganze Gruppe hochhalten.

## Eine Runde vorbereiten

- **Wählen Sie eine kleine Gruppe.** Vier bis acht Personen sind eine gute Größe. Größere Gruppen sind schwerer zu begleiten und können sich gehetzt anfühlen.
- **Machen Sie die Bilder groß.** Nutzen Sie klare Linien und nur einen vertrauten Gegenstand pro Feld. Vermeiden Sie überladene Karten.
- **Sorgen Sie für gute Sitzplätze.** Setzen Sie jede Person so, dass sie den Ansager und ihre eigene Karte sehen kann, und in die Nähe einer helfenden Person, falls sie Unterstützung braucht.
- **Nutzen Sie einfache Spielsteine.** Große Spielsteine, Münzen oder ein Tippen mit dem Finger funktionieren besser als Bleistifte. Halten Sie ein paar Ersatzstücke bereit.
- **Planen Sie eine kurze Runde.** Dreißig Minuten sind oft genug. Hören Sie früher auf, wenn die Energie nachlässt.

Das [National Institute on Aging](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease) empfiehlt, Aktivitäten an das anzupassen, was eine Person noch gut kann. Vereinfachen Sie also die Karten und Regeln, wenn das hilft.

## So sagen Sie die Bilder an

1. **Halten Sie das Bild hoch** oder zeigen Sie darauf auf dem Bildschirm, bevor Sie sprechen.
2. **Nennen Sie es deutlich,** in einfachen Worten: „Teekanne.“ Wiederholen Sie es einmal, langsam.
3. **Warten Sie.** Geben Sie den Menschen Zeit zum Schauen und Markieren. Sagen Sie das nächste Bild erst an, wenn die meisten Gelegenheit hatten.
4. **Beschreiben Sie das Bild, wenn es hilft.** „Die rote Blume“ oder „die, die wir beim Picknick hatten“ kann ein Gespräch anregen.
5. **Halten Sie das Tempo ruhig.** Ein ruhiger Ansager ist wichtiger als ein schneller.

## Das Gewinnen freiwillig machen

Wettbewerb kann schwierig sein. Eine Person, die zurückliegt, kann sich geprüft fühlen, und eine Person, die wegen des Gewinnens angespannt ist, kann unruhig werden. Hier sind einige Alternativen:

- **Alle wählen ein Bild.** Jede Person nennt ein Bild, das ihr gefällt, und die Gruppe freut sich daran.
- **Teilen Sie eine volle Karte.** Bitten Sie die Teilnehmenden, etwas über ein Bild auf ihrer Karte zu sagen.
- **Spielen Sie, bis alle Bilder dran waren.** Sagen Sie jedes Bild auf einer Karte an und beginnen Sie dann eine neue, ohne dass es um einen ersten Gewinner geht.
- **Halten Sie den Preis klein oder lassen Sie ihn weg.** Ein Keks oder ein Lied passt besser als eine Trophäe.

## Anpassen für Menschen in einem späteren Stadium

Für Menschen, denen das Finden eines Bildes schwerfällt, nutzen Sie eine Karte mit nur vier oder sechs Feldern oder geben Sie jeder Person immer nur eine Karte. Lassen Sie eine helfende Person die Karte halten, während die Person darauf zeigt, oder verschieben Sie den Spielstein mit ihrer Erlaubnis vorsichtig für sie. Manche Menschen finden es leichter, einfach dem Ansager zuzuhören und den Klang der Wörter zu genießen.

Achten Sie auf Anzeichen von Unbehagen, zum Beispiel Wegdrehen oder Stirnrunzeln, und hören Sie auf, wenn sie auftreten. Weitere Ideen für ruhige Aktivitäten im Sitzen finden Sie unter [Aktivitäten für ein späteres Stadium](/activities/late-stage/).

## Bingo in Pflegeeinrichtungen und Tagesbetreuung

Gruppenaktivitäten gelingen am besten, wenn sie auf die Menschen im Raum abgestimmt sind. Unser [Leitfaden für Gruppenaktivitäten in Pflegeeinrichtungen und Tagesbetreuung](/activities/care-home-groups/) erklärt, wie Sie eine Runde planen, Sitzplätze ordnen und damit umgehen, wenn jemand gehen möchte. Bilder-Bingo passt auch gut zu einem gemeinsamen Lied oder einer Geschichte und zu [Sätze vervollständigen](/activities/finish-the-saying/) als ruhigerem Spiel später in der Runde.

## Was Bingo kann und was nicht

Bilder-Bingo ist gesellig und macht Freude. Es kann Menschen zusammenbringen, einen Anlass bieten, Bilder anzuschauen und zuzuhören, und der Gruppe ein warmes Gefühl geben. Es behandelt Demenz nicht und verlangsamt ihren Verlauf nicht. Beurteilen Sie den Erfolg daran, wie die Menschen während der Runde aussehen und sich fühlen, nicht daran, wer gewinnt.
