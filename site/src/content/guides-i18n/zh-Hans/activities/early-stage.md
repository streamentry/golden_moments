在认知症早期，很多人的生活仍和以前差不多。他们可能还在工作、做志愿者、和朋友见面，一天中的大部分安排也由自己做主。活动通常不需要替换，只需要做一些调整，让它们继续带来乐趣。您的角色更像是一位伙伴，而不是照护者：给予支持，和对方一起做计划，只在对方需要时才插手。

## 认知症早期适合做哪些活动？

早期最好的活动，通常就是对方本来就喜爱的那些，只是变得稍微容易一些。[美国阿尔茨海默病基金会](https://alzfdn.org/therapeutic-activities-for-3-main-stages-of-alzheimers-disease/)列出的点子包括：牌类和棋类游戏、找词游戏、散步、跳舞、园艺、插花、讲故事、画画、音乐、写日记、写信、做剪贴簿、做饭和节日传统。

改变的往往是环境，而不是活动本身。[美国阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/daily-care/activities)指出，处于早期的人可能会开始从原本喜欢的事情中退缩，并举例说，一个在大型聚会上感到应付不过来的人，在小范围的聚会中可能会自在得多。坦诚地聊聊哪些事情变难了，然后一起调整。

## 先问一问，并约定怎样帮忙

[美国阿尔茨海默病协会的早期照护指导](https://www.alz.org/help-support/caregiving/stages-behaviors/early-stage)建议了几个习惯，同样适用于活动：

- **直接问。**“怎样能让读书会对您来说更轻松一些？”比自己猜测能得到更好的答案。
- **相信对方能做到。**只要没有安全风险，就让对方试一试，给予鼓励，而不是接手代劳。
- **约定一个信号。**选一句话或一个点头，表示“可以帮我一下”，比如打牌时一时想不起某个名字的时候。
- **经常确认。**问问对方，帮忙的程度是刚刚好、太多还是太少。

## 适合早期的活动点子

### 保持原有的角色和爱好

- **保持一项固定的安排。**每周一次的志愿服务、合唱团或社团活动，能让一周有个节奏。如果它开始带来压力，换一个时间更短或更安静的角色可能更合适。
- **一起计划饭菜。**如果去超市买菜变得令人烦躁，美国阿尔茨海默病协会建议改为请对方帮忙计划一周的菜单，并写下购物清单。
- **做饭和烘焙。**一起照着喜欢的菜谱来做。开始之前，把食材按顺序摆好，让每一步都看得见。
- **打理花园。**一起规划一块花床、挑选种子或植物，然后一起动手。把这一周要做的园艺活写成一张清单，会有帮助。
- **继续做手工。**木工、缝纫、编织或拼装模型都可以继续，只要换成更简单的样式，并保证光线充足。

### 为了开心而玩的游戏

- **打牌和下棋。**熟悉的游戏最容易。分组来玩，这样没有人会被单独置于压力之下；计分可以随意一些，或者干脆不计分。
- **试试大字找词。**我们的[大字找词](/games/word-search/)（目前只有英文版）可以在屏幕上玩，也可以打印出来，享受一段安静的时光。
- **玩拼图。**选择让人觉得放松、而不是有挑战的块数。[图片拼图](/games/picture-puzzle/)是一个简短的屏幕版本，我们的[适合认知症长者的拼图](/activities/puzzles/)指南介绍了怎样挑选拼图。
- **为了乐趣参加问答。**有些人很喜欢团队问答之夜。如果它开始让人觉得像考试，就换别的活动，或者试试我们的[轻松问答题](/activities/trivia/)，题目带有选项，也不计分。

在这里，游戏是为了快乐。目前没有任何游戏被证明能治疗或延缓认知症；更多内容请阅读[益智游戏：研究怎么说](/brain-health/brain-games/)。

### 书写、回顾和记录

- **写日记。**美国阿尔茨海默病协会建议，写日记是在确诊后梳理情绪的一种方式。每天写几行就足够了。
- **主导制作人生故事册。**早期是让对方亲自挑选照片、写下或口述照片背后故事的好时机。请参阅[怀旧活动](/activities/reminiscence/)。
- **写信。**给孙辈、老朋友或以前的同事写一封信，对双方来说都可能很有意义。
- **借着照片聊天。**[照片配对](/games/photo-pairs/)把家庭照片变成一个温和的配对游戏，[聊天卡片](/games/conversation-cards/)则提供了轻松开启话题的起点。

### 出门走走，活动身体

[美国国家老龄化研究所](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)建议，只要你们双方都觉得自在，就继续熟悉的外出活动。把外出安排在对方一天中状态最好的时段，也别让时间拖得太长。

- **短途的文化出游。**去博物馆、看一场午后的演出或画展，最好选人少的时候。
- **游泳。**美国国家老龄化研究所建议选一天中人少的时段去泳池。
- **健步走小组和舞蹈课。**[NHS（英国国家医疗服务体系）](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)提到了跳舞、太极、瑜伽、游泳和健步走小组，以及在有条件的地方参加对认知症友好的活动。
- **合唱小组和记忆咖啡馆。**轻松的聚会，认知症人士和他们的伙伴可以在这里认识处境相同的人。

## 让活动保持愉快的小调整

| 如果这件事变难了 | 试试这样做 |
| --- | --- |
| 人多或嘈杂的地方 | 在人少的时候去，选人少的小组，坐在房间的边上 |
| 记住新认识的人的名字 | 每次都介绍对方的名字；请小组成员戴上名牌 |
| 按多个步骤的计划来做 | 把步骤写下来，或者先把所有东西按顺序摆好 |
| 容易累 | 外出时间短一些，回来后休息一下，当天不再安排别的事 |
| 在游戏中记住进度 | 分组来玩，简化规则，或者不计分 |
| 想不起要说的词 | 给对方时间；只有在约定的信号表示需要时，才提示一个词 |

## 什么时候该放慢脚步

当一项活动带来的压力多于乐趣时，就停下或换一种方式。反复受挫、回避某个爱好，或者说出“我真的做不到了”，都值得温和地聊一聊，而不是继续督促。答案往往是同一件事的简化版。当对方在开始活动和跟上步骤方面需要更多帮助时，[认知症中期的活动](/activities/middle-stage/)里的点子可能更合适。关于给予支持的沟通方式，请参阅[沟通技巧](/caregiving/communication-tips/)；更多点子请参阅[101 个活动点子](/activities/ideas/)。

伙伴也需要支持。早期是建立您自己的支持网络的好时机；请参阅[照护者的自我照顾](/caregiving/caregiver-self-care/)。
