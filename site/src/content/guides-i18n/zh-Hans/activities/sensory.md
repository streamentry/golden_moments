感官活动调动五种感官：触觉、嗅觉、味觉、听觉和视觉。它们不需要记忆、不需要步骤，也没有正确答案，所以在任何阶段都可以做。在较晚的阶段，它们最为重要。[美国阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/stages-behaviors/late-stage)指出，在晚期，人主要通过感官来感受世界，您可以通过触摸、声音、画面、味道和气味来表达关爱。做好几项安全检查，能让这些活动让每个人都感到放松。

## 什么是适合认知症长者的感官活动？

感官活动是一次围绕一种感官展开的简单体验，比如摸摸布料、闻闻香草或听听雨声。[NHS（英国国家医疗服务体系）](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)指出，较晚阶段的活动往往需要以感官为重点，并提到了音乐、可以触摸和摆弄的物品，以及手部按摩。[美国阿尔茨海默病基金会](https://alzfdn.org/therapeutic-activities-for-3-main-stages-of-alzheimers-disease/)指出，处在晚期的人可能非常需要抱着一样东西来获得安慰。

## 按感官分类的点子

### 触觉

- **手部按摩。**在掌心焐热一点护手霜，从手腕慢慢抚到指尖。[美国国家老龄化研究所](https://www.nia.nih.gov/health/alzheimers-caregiving/care-last-stages-alzheimers-disease)提到，可以用无香型的护肤乳按摩，让人感到舒适。
- **布料篮。**几块大的天鹅绒、灯芯绒、抓绒、缎面和羊毛方布，可以抚摸、折叠，也可以聊一聊。
- **温热的毛巾。**冷天里，用一块温热的湿毛巾擦擦手。先在您自己的手腕上试一下温度。
- **活动围裙或盖腿毯。**上面牢牢缝着大纽扣、拉链、丝带和不同质地的布块。
- **叠一叠、抚一抚。**一篮干净的小方巾或餐巾，可以叠好、摞起来，再重新叠。
- **一样可以抱着的柔软东西。**一条抓绒毯、一个靠垫或一只逼真的毛绒动物，自然地递过去，绝不把它当作玩具。

### 嗅觉

- **新鲜的香草。**把薄荷、迷迭香、罗勒或薰衣草的叶子在指间搓一搓，再递过去。
- **厨房的气味。**附近正在煮的咖啡、正在烤的面包、肉桂，或者正在剥的橙子。
- **鲜花。**从花园或菜市场带几枝新鲜的花回来。
- **熟悉的日用品。**对方一直用的那款肥皂或护肤乳，前提是皮肤能耐受。

### 味觉

- **喜爱的味道。**一小勺对方喜欢的东西，比如苹果泥、蒸蛋羹或冰淇淋，质地要是对方能安全吞咽的。
- **一起烘焙时帮忙。**一起做点心时，尝一尝水果或一点点糖霜。
- **应季的美味。**夏天的西瓜，秋天温热的梨汤，温度要安全。

### 听觉

- **喜欢的音乐。**音量轻柔的熟悉歌曲；请参阅[音乐活动](/activities/music/)。
- **大自然的声音。**雨声、海浪声或鸟鸣。美国国家老龄化研究所指出，音乐、白噪音和大自然的声音似乎能让一些人放松下来。
- **您的声音。**朗读、哼歌或讲一个故事。
- **简单的乐器。**一面手鼓、一个沙锤或一只铃铛，跟着音乐一起敲。

### 视觉

- **看看窗外。**窗外的喂鸟器、放学回家的孩子，或者飘落的雪花。
- **鱼缸或节奏缓慢的视频。**画面轻柔地动，没有很大的声音。
- **大照片。**一次一张清晰的照片，举到视线高度。
- **颜色和图案。**给鲜艳的碎布、花朵或彩色餐巾分类，或者从我们的[涂色画](/games/coloring/)里选一张简单的涂色页。
- **户外。**NHS 建议去有芳香植物、各种质地和水景的感官花园。请参阅[户外和园艺活动](/activities/outdoor-and-gardening/)。

## 怎样制作一个感官盒

1. **选一个主题**，和对方的人生有关：海边、花园、厨房、工作间、针线活。
2. **挑五六件大而安全的物品**，比如一个大贝壳、一把木勺、一条柔软的围巾、一个缝死口的干薰衣草香包，或者一块光滑的木块。
3. **检查每一件物品**，看有没有小部件、尖锐的边缘、松脱的线头，以及任何易碎的东西。
4. **一次拿出一件。**递给对方，描述一下，让对方自己去摸索。
5. **用完后把盒子收起来**，让它保持特别，下次使用前也能再检查一遍物品。

## 安全第一

感官活动很温和，但有几个风险需要注意。有些认知症人士会把不是食物的东西当成食物，而且吞咽可能会随着时间变得更困难；美国国家老龄化研究所提醒，晚期的吞咽问题会增加噎食的风险。

| 风险 | 怎么做 |
| --- | --- |
| 噎食 | 只用大到吞不下去的物品。盒子里不要散放纽扣、珠子、硬币、弹珠或小玩具。只提供照护团队认为质地安全的食物。 |
| 看起来像食物的东西 | 美国国家老龄化研究所建议把护肤乳、肥皂、洗发水和香水锁起来，因为它们可能看起来或闻起来像食物，并把仿真水果拿走。感官用品用完后要收好。 |
| 过敏 | 开始之前，先确认是否对坚果、乳胶、羊毛、植物或香料过敏。 |
| 浓烈的气味 | 避免浓烈的香水和精油，尤其是有哮喘或其他呼吸问题的人。淡淡的天然气味更安全。 |
| 皮肤 | 按摩之前，检查皮肤有没有疼痛、破损或很脆弱的地方。力度要轻，如果对方皱眉缩手就停下。 |
| 温度 | 温热的毛巾和饮品，先在您自己的手腕上试一下。 |
| 尖锐或有毒的物品 | 不用尖锐的工具、玻璃或有毒的手工材料。 |

## 芳香疗法有帮助吗？

很可能没有任何可以测量的帮助。[一篇关于芳香疗法与认知症的 Cochrane 系统综述](https://www.cochrane.org/evidence/CD003150_aromatherapy-dementia)分析了 13 项研究、共 708 人，全部在养老院进行，没有发现令人信服的益处证据。这些研究规模小，结果互相矛盾，副作用也报告得不充分。如果对方喜欢一种淡淡的、熟悉的气味，比如花园里的薰衣草，那就是和对方分享它的好理由。但它不是治疗。

## 怎样提供一项感官活动

- **选一个安静的时刻**，关掉电视。
- **从正面靠近**，叫对方的名字，触碰之前先问一问或先说一声：“我这儿有护手霜。要不要擦擦手？”
- **一次只提供一样东西**，以免让人应付不过来。
- **留意对方的反应。**表情变柔和、双手放松或露出笑容，都是好的迹象。往后缩、皱眉或坐立不安，意味着该停下了。
- **时间短一些。**平静的五分钟，就是一次很好的活动。

一起慢慢呼吸一会儿，比如[平静呼吸](/games/calm-breathing/)，可以是温和的结束方式。更多床边的点子，请参阅[认知症晚期的活动](/activities/late-stage/)；关于傍晚时分的不安，请参阅[傍晚的不安](/caregiving/late-day-restlessness/)。
