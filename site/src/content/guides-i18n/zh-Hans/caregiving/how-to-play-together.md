和认知症长者玩一个好游戏，看起来并不像比赛。它看起来像是两个人挨着坐，指着图片，为一句俗语笑起来，想到什么就聊什么。游戏只是一起度过时光的一个理由。

本指南介绍怎样准备、怎样把握游戏的节奏、出了“错”时该说什么、怎样让任何游戏更简单或稍微难一点、怎样把游戏变成聊天，以及怎样知道什么时候该停下。它适用于我们的[游戏](/games/)，也适用于您家里已有的纸牌、拼图和棋盘游戏。

## 和认知症长者玩游戏，最好的方式是什么？

重在享受，而不是成就。这是[美国阿尔茨海默病协会关于活动的指导](https://www.alz.org/help-support/caregiving/daily-care/activities)的核心建议：建立在对方仍然具备的技能之上，帮对方开个头，难的部分由您来完成，对无伤大雅的活动不要批评或纠正。

实际做起来就是：

- **坐在对方旁边，而不是对面。**并排坐着，你们都能看到屏幕或桌面，帮忙就像是团队合作，而不是在监督。
- **一次只提供一个游戏。**一份选项清单，可能在开始之前就让人觉得像考试。
- **跟着对方走。**如果对方想按自己的顺序点图片，想聊一张图片聊上十分钟，或者玩两轮就停下，那就是今天的游戏。
- **数的是美好的时刻，而不是玩完了几局。**一个微笑、一个故事，或者平静的半小时，才是您想要的结果。

## 开始之前怎样做好准备？

花几分钟做好准备，就能避免大部分被归咎于游戏本身的挫败感。

1. **选对方一天中状态最好的时段。**[美国国家老龄化研究所（NIA）关于调整活动的指导](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)建议，把外出和活动安排在对方一天中状态最好的时段。对很多人来说，那是上午的中段。傍晚往往更难一些；请参阅[傍晚的平静活动](/caregiving/late-day-restlessness/)。
2. **让房间安静下来。**关掉电视和收音机，如果可以就关上门。[家庭照护者联盟（Family Caregiver Alliance）](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建议，在尝试交谈之前，先减少噪音和干扰。
3. **先确认对方舒服。**旁边放一杯喝的，事先去一趟洗手间，坐一把舒服的椅子，戴好眼镜和助听器。
4. **把地方照亮。**明亮、均匀、屏幕上没有反光的光线，会让图片更容易看清。
5. **坐下之前先把游戏准备好。**由您来打开游戏、选好设置、调好音量。然后把屏幕转向对方。关于平板电脑的建议，请参阅[设置平板电脑或手机](/caregiving/tablets-and-screens/)。
6. **把设备立起来。**用一个能让平板立着的支架或保护套，这样谁都不用拿着它，指起来也更方便。

## 怎样邀请对方而不带来压力？

让邀请随意一些，也容易拒绝。下面这些说法通常效果不错：

- “我找到了一些花园的图片。想和我一起看看吗？”
- “您能帮我拼一下这个拼图吗？我卡住了。”
- “今天想看花还是看鸟？”（二选一比开放式的问题更容易回答）
- “我在给您妹妹做一张卡片。这里用什么颜色好呢？”

美国阿尔茨海默病协会建议说明一项活动的目的，比如为朋友做一张卡片，因为有了理由，活动就有了意义。请对方帮忙也很有效，因为这能让对方觉得自己有用。

如果对方说不，就接受。晚点再试，或者换一件别的事。我们的[当对方说“不”时该怎么办](/caregiving/when-they-say-no/)指南有更详细的内容。

## 一个游戏应该玩多久，节奏要多快？

让对方掌握节奏，并按短时间来安排。一起玩的游戏，并没有基于证据的理想时长。平静的两到五分钟，就可以是一项完整的活动。

- **等待的时间比您觉得自然的再长一些。**美国国家老龄化研究所建议给对方更多时间来回应，尽量不要打断。在您出手帮忙之前，先在心里数到十。
- **一次一步。**给一个简短的指示（“点一张图片”），然后等待。用示范代替解释：指一指该点哪里。
- **随时可以暂停。**如果对方停下来聊一张图片，游戏可以等一等。不用着急。
- **让对方看着。**美国国家老龄化研究所指出，有些人更喜欢看，这也是一种正当的选择。

## 答错了应该纠正吗？

不应该。一遍又一遍地温和纠正，即使出于好意，也是在告诉对方：您做不好。美国阿尔茨海默病协会建议，对无伤大雅的活动不要批评或纠正。在游戏里，几乎每个错误都是无伤大雅的。

| 不要说 | 试试说 |
| --- | --- |
| “不对，错了。” | “我们这样试试。”（美国国家老龄化研究所给出的例子） |
| “这两张不一样。再看看。” | 什么都不说，接着轮到下一次；或者说“哦，这两张都是红色的。” |
| “您还记得这是谁吗？” | “跟我说说这张图片吧。” |
| “那个您已经做过了。” | “这个不错。我们再来一次。” |
| “加油，您知道的。” | “要我把结尾显示出来吗？” |

如果一个错误明显让对方感到挫败，就悄悄地帮一把。指出正确的图片，自己来玩一轮，或者下一局把游戏调简单一些。如果一句俗语被接出了一个有趣的“错误”结尾，就跟着笑一笑。对方的结尾说不定更好。

## 怎样让游戏更简单或更难一点？

根据对方当天的情况来调整游戏，而不是根据阶段的标签。同一个人，晚上可能比早上需要更简单的版本。美国国家老龄化研究所的第一条建议，就是让活动符合对方能做到的事，并确保对方感到成功。

| 游戏 | 让它更简单 | 让它稍微难一点 |
| --- | --- | --- |
| [图片配对](/games/picture-pairs/) | 从 4 张图块开始，让图片一直显示 | 增加图块，或者在觉得自在时隐藏图片 |
| [找相同](/games/find-the-same/) | 2 个选项 | 最多 4 个选项 |
| [一起分类](/games/sort-together/) | 您拿着图片，对方指出篮子 | 对方自己点图片和篮子 |
| [图片拼图](/games/picture-puzzle/) | 4 块拼图，先聊聊整张图片 | 9 块拼图 |
| [接俗语](/games/finish-the-saying/) | 显示结尾，然后一起说出来 | 让对方在点击之前先说出结尾 |
| [大字找词](/games/word-search/) | 打印出来，一起找一个词，指出它的第一个字 | 让对方选下一个要找的词 |
| [涂色画](/games/coloring/) | 您挑两种颜色，对方从中选一种 | 对方自己选所有颜色 |
| [聊天卡片](/games/conversation-cards/) | 只是一起看看图片 | 使用卡片上的开放式话题 |
| [照片配对](/games/photo-pairs/) | 几张大家都喜爱的家庭照片 | 加入更多照片 |
| [图片宾果](/games/picture-bingo/) | 每位参与者身边坐一位帮手 | 参与者自己在卡片上做标记 |
| [平静呼吸](/games/calm-breathing/) | 只是坐着一起看 | 跟着慢慢地呼吸 |

游戏太难的迹象：长时间停顿，看起来是担心而不是在思考；反复说“我不行”；把设备推开；或者因为出错而难过。游戏可能太简单的迹象：感到无聊，或者对方说它太幼稚。如果是这样，请尊重对方的感受，换一个感觉更像成年人做的事，比如大字找词、用真实照片做的拼图，或者聊聊一张和对方以前的行业有关的图片。

## 怎样把游戏变成聊天？

把每张图片都当作聊天的邀请，无论对方说什么，都当作好答案。对很多家庭来说，这是一起玩时最美好的部分。

- **问开放式、没有错误答案的问题。**“您注意到了什么？”“您喜欢哪一个？”“跟我说说像这样的厨房吧。”
- **自己先分享。**“我奶奶以前也养过一只这样的狗。”您的故事会让对方更容易分享自己的故事。
- **顺着岔开的话题走。**如果一张汽车的图片引出了一段关于自驾出游的故事，那这个故事就是今天的活动。让游戏先暂停着。
- **不要核对事实。**在怀旧中，愉快的聊天比准确的细节更重要。如果故事和上次讲的不一样，就享受这个新版本。
- **使用内置的话题。**[接俗语](/games/finish-the-saying/)在每句俗语之后都会给出一个聊天话题，[聊天卡片](/games/conversation-cards/)正是为此而设计的。[照片配对](/games/photo-pairs/)使用您自己的家庭照片，往往能引出最丰富的故事。

更多点子请参阅我们的[怀旧活动](/activities/reminiscence/)和[沟通小技巧](/caregiving/communication-tips/)指南。

## 什么时候该停下？

一出现疲倦或难过的迹象就停下，最好再早一点。美国阿尔茨海默病协会建议，当注意力减退或挫败感上升时，就停下或换一项活动。

留意这些迹象：

- 打哈欠、身子往下滑，或者目光从屏幕上移开；
- 坐立不安、站起来，或者说想走；
- 叹气、回答变得很简短，或者说“我做不好这个”；
- 乱点一气，或者把设备推开；
- 想哭、烦躁，或者情绪突然变化。

怎样好好地结束：

- **用简单的事收尾。**最后配上一对对方能配上的，或者最后欣赏一张图片。
- **把理由放在自己身上。**“我想喝杯茶了。我们就先到这里吧？”这样就不会暗示对方做得不好。
- **转向身体活动或让人放松的事。**散一小会儿步、吃点东西、叠衣服或听音乐。
- **说一句温暖的话。**“我很喜欢和您一起做这个。”不要夸对方“做对了”，只表达一起度过时光的快乐。

提早结束、改变计划，或者放下游戏只是坐在一起，都是好结果。

## 可以在小组里或通过视频通话一起玩吗？

可以，只需要多做一点准备。在小组里，人数控制在几个人，让帮手坐在需要帮助的人旁边，并选择一个大家有共同焦点的游戏。[图片宾果](/games/picture-bingo/)有可打印的卡片和适合小组的屏幕叫号器。更多内容请参阅[养老院小组活动](/activities/care-home-groups/)。

视频通话时，通话另一端的人可以描述一张图片，由房间里的人来指和点。通话时间要短，内容要熟悉。我们的[电话与视频通话](/activities/phone-and-video-calls/)指南里有更多小建议。

## 如果游戏就是玩不起来怎么办？

有些日子什么都不顺，这既不说明您有问题，也不说明对方有问题。把游戏收起来，换一天中的另一个时段、换一个游戏，或者干脆不玩游戏。很多好的活动都和屏幕无关：音乐、叠毛巾、翻相册，或者散一小会儿步。浏览我们的[活动点子](/activities/ideas/)，获取更多灵感。
