“我想回家。”对很多家庭来说，这是最难听到的一句话，尤其是当您照护的人明明就坐在自己家的客厅里。这很常见，在认知症的任何阶段都可能出现，而且有平静、实用的回应方法。本指南介绍这句话常常意味着什么、该说什么、哪些活动能在当下帮上忙，以及怎样保证安全。

## 认知症长者为什么总是要回家？

通常，“家”更多是一种感觉，而不是一个地方。英国阿尔茨海默病协会（Alzheimer’s Society）把它描述为一种舒适和安全的感觉，或者过去的一个家，而不是眼前这栋房子。认知症会让熟悉的房间看起来很陌生，人也可能觉得自己回到了生命中更早的时期，那时的家是童年的老屋，或者是养育孩子的地方。

这句话也可能是在表示别的地方此刻不对劲：对方饿了、渴了、要上厕所、疼痛、太热或太冷、累了、孤单、害怕，或者被噪音弄得不知所措。[美国国家老龄化研究所](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/coping-agitation-aggression-and-sundowning)把疼痛、噪音、孤独、作息改变和药物都列为躁动不安的原因。

## 对方说要回家时，我该说什么？

回应感受，而不是字面的话。[家庭照护者联盟（Family Caregiver Alliance）](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建议，不要试图说服对方他错了：对方的感受是真实的，所以先用安慰和让对方放心来回应，再温和地转移注意力。

常常有帮助的说法：

- **说出对方的感受。**“听起来您是想家了。”
- **让对方放心。**“您在这儿很安全，我陪着您。”[美国阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/stages-behaviors/anxiety-agitation)建议用一句简单的话：“您在这儿很安全。”
- **邀请对方回忆。**“跟我说说您的家吧。您家的厨房是什么样的？”问遥远的往事，通常比问今天的事让人更自在。
- **提议一起做点什么。**“我们先喝杯茶吧”，或者“您能帮我叠一下这些毛巾吗？”

温和的语气，再加上轻轻搭在手臂上的一只手（如果对方喜欢被触碰），往往比言语更有力。

## 应该避免什么？

- **争辩或解释。**“您现在就住这儿”或者“这里已经是您的家 40 年了”，是在要求对方接受认知症让人很难接受的事，也可能让对方觉得自己被说错了。
- **考问。**“您不记得了吗？”或者“地址是什么？”只会增加压力。
- **生气地堵住门。**如果对方往外走，请保持镇定，陪着对方一起走。一起短短地走一走，往往能让这股冲动平息。
- **催促。**先给对方时间说说家，再转换话题。

## 能在当下帮上忙的活动

在您接住了对方的感受之后，一项平静、熟悉的活动可以转移对方的注意力，而不是把这份感受打发掉。

1. **看家和家人的照片。**一页页翻着，说说自己的感受（“看那座花园”），而不是提问。在手机或平板电脑上，[照片配对](/games/photo-pairs/)能把您自己的家庭照片变成一个温和的配对游戏，照片也只留在您的设备上。
2. **聊聊家。**[聊天卡片](/games/conversation-cards/)提供了关于房子、厨房、邻居和节日的开放式话题，没有标准答案。
3. **放对方喜欢的音乐。**美国国家老龄化研究所把舒缓的音乐列为让人平静下来的方法之一。请参阅我们的[音乐活动](/activities/music/)。
4. **吃点心或喝点东西。**饥饿和口渴可能表现得像坐立不安。一杯茶或一样爱吃的小点心，也是在家时的一个小小仪式。
5. **出去散步，或者到外面坐一坐。**活动身体和日光都有帮助，尤其是在一天中比较早的时候。
6. **交给对方一件熟悉的活儿。**叠衣服、整理餐具或者浇花，能找回料理一个家的感觉。
7. **把一切放慢。**关掉电视，减少噪音和强光，再一起做一次[平静呼吸](/games/calm-breathing/)的小停顿。

如果一个办法行不通，晚些时候再试另一个。安静地坐在一起，也是好的结果。

## 检查一下能解决的原因

| 检查 | 可以试试 |
| --- | --- |
| 饿了或渴了 | 递上一杯喝的和一点小点心 |
| 要上厕所 | 平静地、不大惊小怪地问一问要不要去洗手间 |
| 疼痛或不舒服 | 留意皱眉、捂着身体某个部位或便秘等迹象，并告诉对方的医生 |
| 太热或太冷 | 加减一件衣服，或调整室温 |
| 嘈杂或拥挤 | 换到更安静的房间，关掉电视 |
| 累了或刺激过多 | 休息，调暗灯光，放轻柔的音乐 |
| 傍晚 | 请看下面关于日落综合征的部分 |

英国阿尔茨海默病协会建议简单记一份日志，写下对方什么时候会一再要回家，比如饭前、有客人来之后或黄昏时。找到规律，就更容易提前安排。

## 说一句善意的谎言可以吗？

这确实是个有争议的问题，善良的家庭也会得出不同的结论。英国阿尔茨海默病协会表示没有唯一正确的答案：不实之言可能让一些人更加猜疑，所以要判断什么对对方最有利，并且前后一致。Penn Memory Center（宾夕法尼亚大学记忆中心）联合主任的看法是，实话是默认的选择，只有当对方无法承受某个具体的实情时，才可以用一句温和的不实之言，而且绝不能嘲笑对方眼中的现实。

很多照护者发现走中间路线管用：先用诚实的安慰和转移注意（“我们今晚就待在这里，我就在您身边”），而不去争论哪里才是家。

## 如果每天下午或晚上都这样呢？

在傍晚开始或加重的躁动不安，常被称为日落综合征（sundowning）。[美国国家老龄化研究所](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/coping-agitation-aggression-and-sundowning)建议保持稳定的作息，每天晒太阳、活动身体，减少傍晚过晚的小睡，傍晚之后不要摄入咖啡因或酒精。在天黑之前把灯打开，也会有帮助。我们的[傍晚平静活动](/caregiving/late-day-restlessness/)指南里有更多内容。

## 对方想离开时，怎样保证安全

总说要回家，可能会发展成走失。[美国阿尔茨海默病协会](https://www.alz.org/help-support/caregiving/stages-behaviors/wandering)估计，认知症长者中有六成会至少走失一次。

**提前做好准备：**

- 一个写有对方姓名和您的电话的身份或医疗信息手环，并在衣服上做标记。[美国国家老龄化研究所](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/coping-alzheimers-behaviors-wandering-and)提到了美国的 MedicAlert 与阿尔茨海默病协会合办的 Safe and Found 项目，可能需要付费。您所在的地方也许有类似的防走失手环、定位设备或社区登记服务，可以向当地的医疗机构、社区或认知症支持组织咨询。
- 门铃提示器或报警器，把门锁装在较高或较低的位置。永远不要把对方独自反锁在屋里。
- 一张近期的近照，以及一份对方可能去的地方的清单，比如以前的住处或工作单位。
- 告诉可信赖的邻居，并把您的电话留给他们。

**如果对方走失：**马上开始寻找；美国阿尔茨海默病协会指出，很多人是在 1.5 英里（约 2.4 公里）范围内找到的。如果 15 分钟内还没找到，请拨打当地紧急电话（例如 110 报警），并说明对方有认知症。如果任何人处于危险之中，请立即拨打当地急救电话（例如 120 或 110）。

## 什么时候应该联系医生？

如果这种一再要回家的情况或意识混乱是突然出现的，或者在几小时或几天内明显加重，请尽快联系对方的医生。[美国国家老龄化研究所](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/alzheimers-caregiving-managing-personality-and)指出，突然出现或迅速变化的行为，尤其是在感染或换药之后，应当马上检查。突然的意识混乱可能是谵妄，[NHS（英国国家医疗服务体系）](https://www.nhs.uk/symptoms/confusion/)表示需要紧急处理；泌尿道感染是老年人中常见的原因。

在下次就诊时，把一种持续的规律也告诉医生，同样有帮助，因为疼痛、情绪低落、睡眠问题或药物副作用，都可能起一定作用。
